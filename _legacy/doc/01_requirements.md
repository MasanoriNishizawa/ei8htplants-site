# 要件定義

## 1. プロジェクト概要

**プロジェクト名**: ei8ht plants 公式サイト  
**URL**: https://ei8htplants.onrender.com  
**目的**: 植物ブランド「ei8ht plants」の公式 Web サイト。イベント告知・ギャラリー公開・WS予約受付・お問い合わせ受付を一元管理する。

---

## 2. ブランド構成

| ブランド | Instagram | 説明 |
|---|---|---|
| ei8ht plants | @ei8ht.plants | メインブランド |
| Habitat Oides | @habitatoides | ワークショップ主体ブランド |
| HUE by ei8ht plants | - | サブブランド |

---

## 3. ユーザー区分

| 区分 | 説明 |
|---|---|
| 一般ユーザー | 認証不要。公開ページ閲覧・WS予約・お問い合わせ送信が可能 |
| 管理者 | ID/パスワードでログイン。管理画面から全データを参照・操作可能 |

---

## 4. 機能要件

### 4.1 公開ページ

| No. | 機能 | 詳細 |
|---|---|---|
| F-01 | ホーム | 直近イベントの表示、ギャラリーマーキー |
| F-02 | イベント一覧 | 開催予定・過去のイベント切り替え表示 |
| F-03 | WS予約フォーム | 日付・時間帯選択、参加人数（残席チェック付き）、二重送信防止 |
| F-04 | 予約完了モーダル | 送信後にポップアップ表示、閉じるとイベント一覧へ |
| F-05 | 予約キャンセル | メール内リンクから予約内容確認 → キャンセル実行 |
| F-06 | お問い合わせ | 名前・メール・件名・本文を受付 |
| F-07 | コンセプトページ | ブランドコンセプトの静的表示 |
| F-08 | ギャラリー | ブランド別に Google Drive の画像を表示 |
| F-09 | Specimen | 植物標本の一覧表示 |
| F-10 | ブランドページ | ei8ht plants / Habitat Oides / HUE の個別ページ |
| F-11 | Collaborations | コラボレーション案件の一覧 |

### 4.2 管理画面

| No. | 機能 | 詳細 |
|---|---|---|
| A-01 | ログイン/ログアウト | ID/パスワード認証、セッション管理 |
| A-02 | イベント管理 | 一覧・新規作成・編集・削除 |
| A-03 | WS予約一覧 | 全予約の確認、イベント絞り込み、キャンセル済み除外フィルター |
| A-04 | 予約キャンセル | 管理者による任意予約のキャンセル処理 |
| A-05 | 予約メモ | 各予約にフリーテキストのメモを付与（スプレッドシートに保存） |
| A-06 | 参加履歴 | メールアドレスで同一顧客の過去予約を一覧表示 |
| A-07 | 予約表表示 | イベント別・時間帯別の集計表、PDF ダウンロード |
| A-08 | お問い合わせ一覧 | 受信した問い合わせの確認 |

### 4.3 メール通知

| トリガー | 送信先 | 内容 |
|---|---|---|
| WS予約完了 | 予約者 | 予約確認・キャンセルリンク付き |
| WS予約完了 | habitatoides@gmail.com | 新規予約通知 |
| WS予約キャンセル | 予約者 | キャンセル完了確認 |
| WS予約キャンセル | habitatoides@gmail.com | キャンセル通知 |

---

## 5. 非機能要件

| 項目 | 要件 |
|---|---|
| ホスティング | Render（無料プラン、シングルプロセス） |
| レスポンス | ページ初回ロードはキャッシュ活用で高速化 |
| タイムゾーン | 全タイムスタンプは JST（UTC+9）で記録 |
| メール配信 | Gmail API（OAuth2）を使用。SMTP はクラウド環境でブロックされるため不使用 |
| データ永続化 | Google Sheets。サーバー再起動でもデータは消えない |
| 認証セキュリティ | Cookie ベースのセッション（署名済み）、パスワード空文字はログイン不可 |
| API ドキュメント | 無効化（`docs_url=None`、外部公開しない） |

---

## 6. 制約・前提

- Google Sheets をデータベースとして使用するため、同時書き込み競合は考慮しない（単一管理者運用）
- 画像は Google Drive に格納し、サムネイル API 経由で表示
- Render の無料プランはスリープあり（初回アクセス遅延 ~30s）
- インメモリキャッシュのため複数インスタンスへのスケールは不可
