## WS予約シート（`WS予約`）

初回予約時に自動作成。`_ensure_cancel_columns()` が列の不足を自動補完する。

| 列 | 列名 | 型 | 説明 |
|---|---|---|---|
| A | タイムスタンプ | YYYY-MM-DD HH:MM:SS (JST) | 受付日時 |
| B | イベント名 | テキスト | イベントシートの「イベント名」と一致 |
| C | お名前 | テキスト | |
| D | メール | メールアドレス | 確認・キャンセルメールの送信先 |
| E | 希望日 | YYYY-MM-DD | |
| F | 希望時間帯 | HH:MM-HH:MM | 例: `11:00-12:00` |
| G | 参加人数 | 数値文字列 | 残席計算に使用 |
| H | お持ち込み | テキスト | 例: `植木鉢, 植物` |
| I | 備考 | テキスト | 自由記入 |
| J | キャンセルトークン | UUID v4 | 予約時に生成。キャンセルリンクで使用 |
| K | キャンセル済み | TRUE / "" | キャンセル済みは `TRUE` |
| L | キャンセル理由 | テキスト | |
| M | キャンセル日時 | YYYY-MM-DD HH:MM:SS (JST) | |
| N | メモ | テキスト | 管理者フリーメモ |

**残席計算**: B・E・F列で絞り込み、K列が`TRUE`の行を除いてG列を合計  
**キャンセル処理**: J列でトークンを検索し、K・L・M列を更新  
**メモ更新**: N列の指定行を `update_cell()` で直接書き込み

## 注意事項

- **イベント名は変更不可**: WS予約シートのB列と完全一致で紐づくため、予約後にイベント名を変更すると集計がずれる
- **日付フォーマット**: Sheets が自動で `/` 区切りに変換することがある。`parse_date()` でハイフン・スラッシュ両対応
- **列の手動削除禁止**: コードが固定インデックスで参照している列を削除するとクラッシュする
