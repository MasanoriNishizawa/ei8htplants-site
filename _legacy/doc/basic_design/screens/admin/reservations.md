# 画面設計：WS予約一覧

## 基本情報

| 項目 | 値 |
|---|---|
| URL | `/admin/reservations` |
| テンプレート | `templates/admin/admin_reservations.html` |
| 認証 | 必須 |

---

## レイアウト

```
┌──────────────────────────────────────────────────────┐
│  サマリーカード（現在・今後のイベント、終了日昇順）       │
│  ┌──────────┐ ┌──────────┐                          │
│  │イベントA  │ │イベントB  │  ← クリックで予約表へ    │
│  │  3名     │ │  7名     │  （終了翌日に自動消去）   │
│  └──────────┘ └──────────┘                          │
│                                                      │
│  [▾ 過去のイベント] ← クリックで展開リスト表示        │
├──────────────────────────────────────────────────────┤
│  [絞り込みセレクト]  [□ キャンセル済を除く]  N件      │
├──────────────────────────────────────────────────────┤
│ 受付日│イベント│お名前│連絡先│希望日│時帯│人│持込│備考│メモ│操作│
│ ・・・                                               │
└──────────────────────────────────────────────────────┘
```

---

## テーブル列詳細

| 列 | 表示内容 | 備考 |
|---|---|---|
| 受付日 | タイムスタンプの日付部分（YYYY-MM-DD） | |
| イベント | イベント名（max-width でトランケート） | hover で全文 |
| お名前 | 参加履歴ページへのリンク | |
| 連絡先 | メールアドレス（トランケート） | hover で全文 |
| 希望日 | | |
| 時帯 | 希望時間帯 | |
| 人 | 参加人数 | |
| 持込 | お持ち込みバッジ | |
| 備考 | （トランケート） | hover で全文 |
| メモ | テキストエリア + [保存] ボタン | AJAX保存、ページ遷移なし |
| 操作 | [キャンセル] ボタン または [キャンセル済] バッジ | |

---

## フィルター

| フィルター | 動作 |
|---|---|
| イベント絞り込みセレクト | 選択変更で即リロード（`?event=xxx`） |
| キャンセル済を除く | チェック変更で即リロード（`?exclude_cancelled=1`） |

---

## サマリーカードの表示条件

- `終了日 >= 今日` のイベントのみカード表示（キャンセル済み除く合計人数）
- `終了日 < 今日` のイベントは「過去のイベント」ボタン内に折りたたみ
- カードは終了日昇順（近い順に左）で並ぶ

---

## クエリパラメータ

| パラメータ | 説明 |
|---|---|
| `event` | イベント名でフィルタ（空=全件） |
| `exclude_cancelled` | `1` のときキャンセル済み行を除外 |
