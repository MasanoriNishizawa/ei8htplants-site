# 画面設計：お問い合わせ一覧

## 基本情報

| 項目 | 値 |
|---|---|
| URL | `/admin/contacts` |
| テンプレート | `templates/admin/admin_contacts.html` |
| 認証 | 必須 |

---

## レイアウト

```
┌────────────────────────────────────────────┐
│  topbar: [Events] [WS予約] [お問い合わせ*]  │
├────────────────────────────────────────────┤
│  表: 受付日時 / お名前 / メール / 件名 / 内容│
└────────────────────────────────────────────┘
```

---

## 表示内容

- `get_all_contacts_for_admin()` から全件取得
- 新しい順（タイムスタンプ降順）で表示
- 削除・返信機能なし（閲覧のみ）
