# 画面設計：管理画面ログイン

## 基本情報

| 項目 | 値 |
|---|---|
| URL | `/admin/login` |
| テンプレート | `templates/admin/admin_login.html` |
| 認証 | 不要（ログインページ自体） |

---

## レイアウト

```
┌─────────────────────────┐
│  ei8ht plants — Admin   │
├─────────────────────────┤
│  [ユーザーID]           │
│  [パスワード]           │
│  [ログイン]             │
│                         │
│  ※ エラー時:           │
│  IDまたはパスワードが   │
│  違います               │
└─────────────────────────┘
```

---

## 認証ロジック

- ユーザー名: 環境変数 `ADMIN_USER`
- パスワード: 環境変数 `ADMIN_PASS`（空文字の場合はログイン不可）
- 成功: セッションに `admin_authenticated = True` を書き込み `/admin/events` へ
- 失敗: 同ページ再表示（エラーメッセージ付き）
- ログイン済みで `/admin/login` にアクセスした場合: `/admin/events` へリダイレクト
