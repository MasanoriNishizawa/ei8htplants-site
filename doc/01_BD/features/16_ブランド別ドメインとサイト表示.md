# FT-27 — ブランド別ドメインとサイト表示（2026-10-26 追加、同日更新）

## 概要

3つのブランドをそれぞれ専用ドメインで表示する。サイトは同じリポジトリ・Render Web Serviceで動き、アクセスしたドメイン名に応じてフロントエンドが表示するサイトとヘッダー・フッターを選ぶ。

| ドメイン | ブランド | 表示するページ |
|---|---|---|
| `ei8htplants.com` | ei8ht plants | 既存のブランドサイト、ショップ、ジャーナル、管理画面 |
| `habitatoides.com` | Habitat Oides | 独自デザインのホーム `/`、ワークショップ `/workshop`、コラボレーション `/collaborations` |
| `huebyei8htplants.com` | HUE by ei8ht plants | 独自デザインのホーム `/` |

`www` 付きドメインはRender側でルートドメインへ転送する。ドメイン追加やDNSの設定は [Renderのカスタムドメイン手順](https://render.com/docs/custom-domains) に従う。

## 画面と移動

- Habitat Oides と HUE は ei8ht plants の共通テーマを流用せず、ブランドごとに内容・写真・配色・レイアウトを組み立てた独立ホームページを表示する。どちらもブランド専用のヘッダー・フッターを持つ。
- 表示言語は保存済みの利用者設定を優先し、設定がなければブラウザー言語に従う（日本語設定なら日本語、それ以外なら英語）。Habitat Oides は「仕立てる」をテーマに、自生地の景色を一鉢に仕立てる日本語コピーや植物・石・砂・土の紹介を掲載する。HUE は「暮らす」をテーマに、「植物と、暮らす。」を軸とした日本語のヒーローや色・かたち・居場所、植物と過ごす日々の内容を掲載する。各サイトのヘッダーの言語切替で、ナビゲーション、見出し、説明文などを英語表示に変更できる。
- Habitat Oides の日本語ナビは「世界観」「ワークショップ」「コラボレーション」、ワークショップ詳細ページは「概要」「内容」「当日の流れ」「参加費」。HUE の日本語ナビは「HUEの考え方」。英語表示ではそれぞれ Concept / Workshop / Collaboration、About / Contents / Flow / Fee、Concept を表示する。
- 独立ブランドサイトのヘッダーにあるブランド名下のタグラインも選択言語に合わせて切り替える。Habitat Oides は日本語「植物の景色を仕立てる」／英語 “Shape a living landscape”、HUE は日本語「植物と暮らす」／英語 “Live with plants” を表示する。
- ei8ht plants 側のヘッダー／フッターと、各ブランドサイトのヘッダー／フッターにあるブランド切替リンクは、新しいタブで開く。現在のサイトを残したまま別ブランドを見られる。Conceptページ内のブランド紹介カードは各ドメインへ同じタブで移動する。
- Habitat Oides のワークショップ予約導線は、既存サイトのイベント・予約機能を利用する。
- どちらの独立ブランドドメインでも `/admin` を開くと、同じパス・クエリ・フラグメントを保って `https://ei8htplants.com` へ移動する。管理画面は既存ドメインにだけ置く。
- ブランドページの旧URL、および別ブランドのドメイン上で開かれたURLは、対応する正式ドメインへ転送する。

| 開いたホストとパス | 転送先 |
|---|---|
| ei8htplants.com `/habitatoides` | `https://habitatoides.com/` |
| ei8htplants.com `/habitatoides/workshop` | `https://habitatoides.com/workshop` |
| ei8htplants.com `/collaborations` | `https://habitatoides.com/collaborations` |
| ei8htplants.com `/hue` | `https://huebyei8htplants.com/` |
| habitatoides.com `/hue` | `https://huebyei8htplants.com/` |
| huebyei8htplants.com `/habitatoides` | `https://habitatoides.com/` |

通常のページ要求ではサーバーが301を返す。すでにSPAを開いている状態で `habitatoides.com/hue` に移動した場合も、アプリがHUEの正式ドメインへ転送する。転送時はクエリ文字列を引き継ぐ。

### 以前のPWAキャッシュを解除する

ブランドサイトを分ける前に独立ブランドのドメインで使われていたPWA（ホーム画面に追加したサイト）の保存データが、古いei8ht plantsの画面を出すことがある。独立ブランドドメインにアクセスすると、次の処理で古い保存データを解除する。

1. サーバーが旧Service Workerを置き換える解除用Workerを返し、ブラウザに登録させる。
2. 解除用Workerが、そのドメインのキャッシュを削除して自身の登録を解除する。
3. 開いているページを再読み込みし、最新のブランドサイトを表示する。
4. 独立ブランドのHTMLからmanifestと通常のWorker登録を外し、そのドメインではPWAキャッシュを再作成しない。

この処理はei8htplants.comのPWAには適用しない。

## 実装ファイル

- `frontend/src/lib/siteHost.ts`（ホスト名とサイト設定の対応）
- `frontend/src/sites/ei8htplants/site.ts`（既存サイトの設定）
- `frontend/src/sites/habitat-oides/site.tsx`（Habitat Oides のページ構成と設定）
- `frontend/src/sites/hue/site.tsx`（HUE のページ構成と設定）
- `frontend/src/components/BrandSiteLayout.tsx`（独立ブランド用ヘッダー・フッター）
- `frontend/src/App.tsx`（ドメイン別ルートと管理画面への転送）
- `backend/app/main.py`（旧URLからの301転送）
- `backend/app/routes/seo.py`（ホスト名に応じた検索向け情報）
- `frontend/src/pages/brands/HabitatOides.tsx`・`Hue.tsx`（各ブランド独自のホーム内容）

検索結果・SNSカード、robots.txt、sitemap.xml のドメイン別動作は [FT-26 検索エンジン・SNS 向けの情報](15_検索エンジン・SNS向け情報.md) を参照。
