# FT-10 — 取扱店管理

## 概要

取扱店の一覧表示・追加・編集・削除機能。ブランドチェックボックスによる複数ブランド紐付けと、編集モーダルによるインライン編集をサポートする。

## 使用ページ

| ページID | ページ名 | 操作 |
|---|---|---|
| [PG-06](../pages/public/06_Stockists.md) | Stockists（公開） | 一覧取得（エリア別グループ・ブランドチップ表示） |
| [PG-A04](../pages/admin/04_Stockists.md) | 取扱店管理（Admin） | 一覧・追加・編集・削除 |

## 実装ファイル

- `frontend/src/pages/Stockists.tsx`
- `frontend/src/pages/admin/Stockists.tsx`
- `backend/app/routes/stockists.py`

## API

| 操作 | メソッド | パス |
|---|---|---|
| 一覧取得 | GET | `/api/stockists` |
| 追加 | POST | `/api/stockists` |
| 編集 | PATCH | `/api/stockists/{id}` |
| 削除 | DELETE | `/api/stockists/{id}` |

## データモデル

```ts
interface Stockist {
  id: string
  name: string
  area: string | null
  address: string | null
  url: string | null
  brands: string[]          // ['ei8ht plants', 'Habitat Oides', 'HUE'] から選択
  display_order: number
}
```

## ブランドチェックボックス（BrandCheckboxes）

Admin Stockists ページ内の共有コンポーネント。

```tsx
function BrandCheckboxes({ value, onChange }: { value: string[]; onChange: (v: string[]) => void })
```

- `BRANDS = ['ei8ht plants', 'Habitat Oides', 'HUE']` の3項目
- チェック済みの場合はリストから除去、未チェックの場合は追加

## 追加フロー

```
追加フォーム送信
    │
    ▼
POST /api/stockists { name, area, address, url, brands }
    │
    ▼
display_order = 現在の件数で DB INSERT
    │
    ▼
load() で一覧再取得、フォームリセット
```

## 編集フロー

```
「編集」ボタンクリック
    │
    ▼
setEditing(stockist) + setEditForm(既存値でフォームを初期化)
    │
    ▼
編集モーダル表示（fixed オーバーレイ）
    │
    ▼
フォーム送信
    │
    ▼
api.stockists.patch(id, body)    （PATCH /api/stockists/{id}）
    │
    ▼
setEditing(null) でモーダルを閉じる
load() で一覧再取得
```

## 削除フロー

```
「削除」ボタンクリック → confirm → DELETE /api/stockists/{id} → load()
```
