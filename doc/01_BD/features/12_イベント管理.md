# FT-12 — イベント管理

## 概要

Adminイベントの一覧表示・作成・編集・削除（CRUD）機能。ブランドの複数選択、画像ファイルのアップロード（複数可）、URL スラッグ、日ごとの開催時間、ワークショップの時間枠（WSセッション）の設定に対応する。開催予定と過去の区別は終了日（無ければ開始日）から自動で決まる（2026-10-22 に記述を今の画面に合わせた）。

## 画像の追加

- 「+ 追加」の枠を押して画像ファイルを選ぶ（複数まとめて選べる）。選ぶとすぐにアップロードし、終わると一覧に並ぶ
- 各画像の「×」で外せる。アップロード中は保存ボタンが「アップロード中...」になり押せない
- 保存するときは、アップロードが終わった画像の URL だけを送る

## ワークショップの時間枠（WSセッション）

- 「ワークショップあり」に印を付けると、「予約必要」と「WSセッション（各回の時間・定員）」の欄が出る
- 「+ 追加」で1行ずつ足す（時間の例: `10:00〜11:30`、定員）。行がなければ時間指定なしで予約を受け付ける
- 「自動設定」は、開催時間が「10:00〜17:00」のような形のとき、開始の1時間後から終了の1時間前まで、1時間ごと・定員4名の枠を作る
- 保存すると、イベントの保存のあとに `PUT /api/events/{id}/sessions` で時間枠を保存する

## 管理情報の確認・編集フロー（2026-10-16 変更）

```
イベント一覧の「管理情報」ボタン（またはイベント編集画面の「管理情報を編集」）
    │
    ▼
確認画面 /admin/events/:id/admin-info
    イベント・管理情報・収支を読み込んで表示（収支は読めなくても表示する）
    │「編集」ボタン
    ▼
編集画面 /admin/events/:id/admin-info/edit
    │「保存する」→ PUT /api/events/{id}/admin-info と収支の出店料・宿泊費の保存
    │  成功 → 確認画面へ（ブラウザの履歴は置き換え）。確認画面に「保存しました」を3秒表示
    │  失敗 → 編集画面に留まり「保存に失敗しました。もう一度お試しください。」
    │「← 戻る」→ 確認画面へ（保存していない変更があれば確認ダイアログ）
    ▼
確認画面
```

- 確認画面の「← 戻る」は、最初に確認画面を開いた画面（イベント一覧・イベント編集画面・ダッシュボード）へ戻る。編集画面を行き来しても、この行き先は引き継がれる
- 2026-10-21 から、ダッシュボードの「出店料の支払い」「今後の搬入予定」の行からも確認画面を開ける（[PG-A01](../pages/admin/01_Dashboard.md)）
- 2026-10-21 から、編集画面で保存していない変更があるときは、サイドメニュー（スマホのメニューも）のリンクやログアウトを押したときにも確認ダイアログを出す（「キャンセル」なら移動しない）。ブラウザの「戻る」は対象外
- 画面の見た目・表示のしかたの詳細は [PG-A02](../pages/admin/02_Events.md)、処理の詳細は [DD-03 フロントエンドロジック](../../02_DD/03_フロントエンドロジック.md) の15節（編集画面）・19節（確認画面）を参照

## 削除フロー

```
削除ボタンクリック → confirm → 処理中にする（全部の行の複製・削除を押せなくする）
  → DELETE /api/events/{id}
      ├─ 成功 → 一覧からその行を外す
      └─ 失敗 → 一覧はそのまま、上に「削除に失敗しました（理由）」
  → 処理中を戻す
```

- 複製も同じく処理中は全部の行の複製・削除を押せない（続けて押して同じイベントが2つできるのを防ぐ）。成功したら一覧を読み直し、失敗したら「複製に失敗しました（理由）」を出す（2026-10-22 追加）
- 一覧の読み込みに失敗したときは「イベントの読み込みに失敗しました（理由）」を出す（「予定なし」と見分けられるようにする）

## イベントサイト編集（AdminEventSite。2026-10-22 追記）

イベント一覧の「サイト」から開く画面（`/admin/events/:id/site`）。イベント専用ページ（[PG-20](../pages/public/20_EventSite.md)）の中身を入れる。

- **読み込みに失敗したとき**: 入力欄を出さずに、赤い枠で「イベントの読み込みに失敗しました（理由）」と「再読み込み」ボタンだけを出す。空の入力欄のまま「保存」を押して、入れてあった中身を空で上書きしてしまうのを防ぐため。「再読み込み」を押すと読み込み直す（2026-10-22 追加。それまでは失敗しても空の入力欄が出ていた）
- **保存に失敗したとき**: 赤い枠で「保存に失敗しました（理由）」を出す。入力は残るので、もう一度「保存」を押せる
- **保存に成功したとき**: 「保存しました」を少しの間出し、公開ページが最新を読み直すための印を同じブラウザに残す（[PG-20](../pages/public/20_EventSite.md) の「表示内容」）
- **アーカイブのギャラリー画像 URL**: 1行に1つの URL を書く欄。入力中は改行や空の行をそのまま残し、欄から離れたとき・保存するときに、前後の空白を取って空の行を除いた URL の一覧にする（2026-10-22 変更。それまでは1文字打つたびに空の行を消していたため、Enter で改行できなかった）
- 項目名と入力欄を結び付けて、項目名を押すと入力欄に移る・読み上げソフトが項目名を読むようにした
