# FT-12 — イベント管理

## 概要

Adminイベントの一覧表示・作成・編集・削除（CRUD）機能。ブランドの複数選択、画像URLの動的追加、過去フラグによる分類に対応する。

| ページID | ページ名 | 操作 |
|---|---|---|
| [PG-A02](../pages/admin/02_Events.md) | イベント管理 | 一覧・削除 |
| PG-A02（EventForm） | イベント作成・編集フォーム | 作成・編集（`/admin/events/new` / `/admin/events/:id/edit`） |
| PG-A02（EventAdminInfoView） | 管理情報の確認画面 | 搬入・宿泊・出店料（支払い状況）・出店要項・メモを読みやすく表示（`/admin/events/:id/admin-info`、2026-10-16 追加） |
| PG-A02（EventAdminInfo） | 管理情報の編集画面 | 搬入・宿泊・出店料・出店要項の入力。保存すると確認画面に戻る（`/admin/events/:id/admin-info/edit`、2026-10-16 に URL を変更） |

## API

| 操作 | メソッド | パス |
|---|---|---|
| 一覧取得（開催予定） | GET | `/api/events?past=false` |
| 一覧取得（過去） | GET | `/api/events?past=true` |
| 詳細取得 | GET | `/api/events/{id}` |
| 作成 | POST | `/api/events` |
| 更新 | PUT | `/api/events/{id}` |
| 削除 | DELETE | `/api/events/{id}` |
| 管理情報の取得 | GET | `/api/events/{id}/admin-info` |
| 管理情報の保存 | PUT | `/api/events/{id}/admin-info` |
| ダッシュボード用の管理情報の一覧（2026-10-21 追加） | GET | `/api/events/admin-info/dashboard` |

## フォーム状態

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| name | string | ○ | イベント名 |
| start_date | string | ○ | 開始日（ISO date） |
| end_date | string | — | 終了日 |
| time | string | — | 開催時間帯 |
| location | string | ○ | 会場名 |
| booth_number | string | — | ブース番号 |
| address | string | — | 住所 |
| official_url | string | — | 公式URL |
| brands | string[] | — | 選択ブランド（複数選択可） |
| has_workshop | boolean | ○ | WS有無 |
| ws_requires_reservation | boolean | ○ | 予約制（has_workshopがtrueの場合のみ表示） |
| is_past | boolean | ○ | 過去フラグ |
| imageUrls | string[] | — | 画像URL配列（動的追加） |

## 画像URL入力

- `imageUrls` state は `['']`（空1件）で初期化
- 最後の入力欄に値を入力すると新しい空欄が自動追加
- 各入力欄に「×」ボタン（最終行は非表示）で個別削除
- 送信時に `imageUrls.filter(Boolean)` で空文字を除外

## 作成フロー

```
/admin/events/new にアクセス（id パラメータなし）
    │
    ▼
空フォームを表示
    │
    ▼
フォーム送信 → POST /api/events { ...form, image_urls: urls }
    │
    ▼
navigate('/admin/events')
```

## 編集フロー

```
/admin/events/:id/edit にアクセス
    │
    ▼
api.events.get(id) でデータ取得 → フォームに初期値をセット
    │
    ▼
フォーム送信 → PUT /api/events/{id} { ...form, image_urls: urls }
    ※ バックエンドで event_images を全削除して再INSERT
    │
    ▼
navigate('/admin/events')
```

## 管理情報の確認・編集フロー（2026-10-16 変更）

```
イベント一覧の「管理情報」ボタン（またはイベント編集画面の「管理情報を編集」）
    │
    ▼
確認画面 /admin/events/:id/admin-info
    イベント・管理情報・収支を読み込んで表示（収支は読めなくても表示する）
    │「編集」ボタン
    ▼
編集画面 /admin/events/:id/admin-info/edit
    │「保存する」→ PUT /api/events/{id}/admin-info と収支の出店料・宿泊費の保存
    │  成功 → 確認画面へ（ブラウザの履歴は置き換え）。確認画面に「保存しました」を3秒表示
    │  失敗 → 編集画面に留まり「保存に失敗しました。もう一度お試しください。」
    │「← 戻る」→ 確認画面へ（保存していない変更があれば確認ダイアログ）
    ▼
確認画面
```

- 確認画面の「← 戻る」は、最初に確認画面を開いた画面（イベント一覧・イベント編集画面・ダッシュボード）へ戻る。編集画面を行き来しても、この行き先は引き継がれる
- 2026-10-21 から、ダッシュボードの「出店料の支払い」「今後の搬入予定」の行からも確認画面を開ける（[PG-A01](../pages/admin/01_Dashboard.md)）
- 2026-10-21 から、編集画面で保存していない変更があるときは、サイドメニュー（スマホのメニューも）のリンクやログアウトを押したときにも確認ダイアログを出す（「キャンセル」なら移動しない）。ブラウザの「戻る」は対象外
- 画面の見た目・表示のしかたの詳細は [PG-A02](../pages/admin/02_Events.md)、処理の詳細は [DD-03 フロントエンドロジック](../../02_DD/03_フロントエンドロジック.md) の15節（編集画面）・19節（確認画面）を参照
