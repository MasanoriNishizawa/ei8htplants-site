# FT-07 — ブランドサブナビゲーション

## 概要

各ブランドページとワークショップページで使用するセクション連動型サブナビゲーション。`IntersectionObserver` によりスクロール位置を検出し、アクティブなセクションのナビ項目をハイライトする。

## 実装ファイル

各ブランドページコンポーネント（共通パターン）

## 構成要素

### サブナビゲーションバー

```
<nav className="brand-subnav">
  <div className="brand-subnav-inner">
    <a href="#section" className={active === id ? 'subnav-active' : ''}>
      Section Label
    </a>
    ...
  </div>
</nav>
```

- `position: fixed; top: 60px`（ヘッダー高さ分オフセット）
- `.hero-wrapper` の中に配置（ヒーローと一体化した見た目）
- `subnav-active` クラスで下線 + 色変化

### スクロール連動

```
IntersectionObserver({
  rootMargin: '-55% 0px -45% 0px'
})
```

- 各セクションの `id` に `ref` を設定
- セクションがビューポートの中心付近（上55%〜下45%）に入ったときに `isIntersecting` が発火
- `setActive(e.target.id)` でアクティブセクションを更新

### スムーズスクロール

- ナビリンクの `onClick` で `e.preventDefault()` + `element.scrollIntoView({ behavior: 'smooth' })`

## 状態管理

| state | 型 | 初期値 | 説明 |
|---|---|---|---|
| `active` | string | `''` | 現在アクティブなセクションID |
| `sectionRefs` | `Record<string, HTMLElement \| null>` | `{}` | セクション要素への参照 |

## CSS クラス（`index.css`）

| クラス | 説明 |
|---|---|
| `.brand-subnav` | サブナビ固定バー（background / border / z-index） |
| `.brand-subnav-inner` | 内部のフレックスコンテナ |
| `.subnav-active` | アクティブ項目スタイル（color + border-bottom） |
| `.hero-wrapper` | サブナビ + ヒーローをラップするコンテナ（padding-top でナビ高さを確保） |
| `.brand-section` | 各セクション（min-height 設定でIntersectionが安定して発火） |
| `.scroll-hint-line` | ヒーロー下部のスクロール誘導アニメーションライン |
