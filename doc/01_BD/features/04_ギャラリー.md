# FT-04 — ギャラリー

## 概要

ギャラリー画像の表示と管理の機能。公開ページはブランド別フィルタータブ、グリッドレイアウト、ライトボックス（クリック拡大表示）で構成される。管理画面（[PG-A03](../pages/admin/03_Gallery.md)）では、画像ファイルを選んで追加（ALT テキストとブランドは任意）・削除・▲▼ボタンでの並べ替えができる（2026-10-22 に概要へ管理画面の機能を追記）。

## 使用ページ

| ページID | ページ名 | 用途 |
|---|---|---|
| [PG-01](../pages/public/01_Home.md) | Home | ギャラリーマーキー（横スクロール自動アニメーション） |

## ブランドフィルタータブ

### 表示タブ

| ラベル（画面では大文字で出る） | brand パラメータ |
|---|---|
| All | （パラメータなし） |
| ei8ht plants | `ei8ht plants` |
| Habitat Oides | `Habitat Oides` |
| HUE by ei8ht plants | `HUE` |

- タブにはブランドの正式名（`lib/brands.ts` の `name`）を出し、サーバーへは短い表記（`shortName`）に直して問い合わせる。管理画面のギャラリーはブランドを短い表記（`HUE`）で保存しているため（2026-10-22 変更。それまでは正式名「HUE by ei8ht plants」で問い合わせていたため、HUE のタブに写真が1枚も出なかった）
- 注意: 本番のデータに、ブランドが正式名「HUE by ei8ht plants」で保存された写真があると、その写真は HUE のタブに出ない（「All」には出る）。あるかどうかは確かめていない（[課題表](../../03_PM/04_課題・リスク管理表.md) の I-15）

### 動作

1. タブクリック → `activeBrand`（正式名。All は `null`）を更新し、拡大表示を閉じる
2. 正式名を短い表記に直した値（`activeShortName`）が変わると、`useApi` が `api.gallery.list(activeShortName)` を呼ぶ。切り替える前の古い応答が後から届いても捨てる
3. All のときはパラメータなしで全件取得
4. バックエンドで `brand` クエリパラメータがある場合は `WHERE brand = ?` フィルタリング
5. 読み込み中は「読み込み中...」（英語表示では「Loading...」）、失敗したときは「読み込めませんでした」の案内と再読み込みのボタン（`LoadError`）、0件のときは「まだ写真が追加されていません。」を出す（失敗を0件と見せない）

## ギャラリーグリッド

- CSS クラス `.gallery-grid` / `.gallery-item`（`frontend/src/index.css`）
- `aspect-ratio: 1/1`、`object-fit: cover` で正方形トリミング
- `loading="lazy"` で遅延読み込み
- 各 `.gallery-item` をクリックで `setLightbox(url)` 呼び出し

---

## ライトボックス

### 動作フロー

```
画像クリック
    │
    ▼
setLightbox(url) → lightbox state に URL を設定
    │
    ▼
オーバーレイ表示（fixed, zIndex: 2000, 黒背景 rgba(0,0,0,0.95)）
    │
    ├─ 拡大画像表示（maxWidth: 90%, maxHeight: 85%, objectFit: contain）
    ├─ × ボタン（右上）
    ├─ オーバーレイ背景クリック → setLightbox(null)
    └─ Escキー → setLightbox(null)
```

### 後ろの画面のスクロールを止める

- 拡大表示（`components/ImageLightbox.tsx`）を開いている間は、共通のフック `hooks/useBodyScrollLock.ts` でページ本体のスクロールを止め、閉じると元に戻す（2026-10-22 に共通のフックにまとめた）
- スマホのメニューを開いたまま写真を拡大したときのように、2つ以上の部品が同時に止めていても、最後の1つが閉じるまでは止めたままにする（途中で勝手にスクロールできるようにならない）

## ホームのマーキー

- `api.gallery.list()` で全件取得（ブランドフィルターなし）
- 取得した配列を2倍に複製（`[...gallery, ...gallery]`）して無限ループを実現
- CSS `@keyframes marquee` で translateX アニメーション（80秒周期）
- 両端に linear-gradient マスクを適用してフェードアウト演出

---

## データ取得

- `api.gallery.list(brand?)` → GET `/api/gallery?brand=` （[FT-02](02_APIクライアント.md)）
- フィルター変更のたびに再取得し `setLoading(true)` でローディング表示
