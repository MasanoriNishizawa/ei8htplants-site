# FT-11 — 予約ステータス管理

## 概要

ワークショップ予約一覧の表示と、ステータスのインライン変更機能。ステータスはカラーバッジで視覚化し、セレクトボックスからワンクリックで更新できる。ステータスを `confirmed` に変更した時点でキャンセルトークンを発行し、キャンセルリンクをメール送信する。

## ステータス定義

|---|---|---|---|
| `pending` | 未確認 | `#fff3cd` | `#856404` |

## 更新フロー

```
セレクトボックス変更（onChange）
    │
    ▼
setUpdating(id) → セレクトを disabled に
    │
    ▼
api.reserve.updateStatus(id, status)    （PATCH /api/reserves/{id} { status }）
    │
    ├─ 成功 ──→ setRows: サーバー応答でローカル state を更新
    │
    └─ 失敗 ──→ setRows: 楽観的更新（サーバー応答なしでローカルのみ変更）
        ※ バックエンドで _sync_reserved_count が例外を投げても 200 を返すため、
          フロントエンドの try/catch は通信エラー時の保護として機能する
```

## confirmed 時のサーバー側処理（副作用）

`status = 'confirmed'` かつ `cancel_token` が未設定の場合:

1. 8桁ランダム数字のキャンセルトークンを生成（`secrets.choice(string.digits)` × 8）
2. `workshop_reservations.cancel_token` に保存
3. `_sync_reserved_count(session_id)` でデノーマライズ値を更新
4. `_send_cancel_link_email()` でキャンセルリンクメールを送信

**キャンセルトークンは初回確定時のみ生成**。再確定しても既存のトークンを維持する（メール送信済みリンクが無効にならないようにするため）。

## キャンセルメール仕様

- **from**: `ei8ht plants <{CONTACT_FROM_EMAIL}>`
- **subject**: `[Habitat Oides] ワークショップ予約が確定しました: {イベント名}`
- **本文**: キャンセルID（数字8桁）+ キャンセルURL（`https://ei8htplants.com/cancel?id={token}`）

## 表示項目（Reservations.tsx / EventReservations.tsx 共通）

| カラム | 説明 |
|---|---|
| 受付日 | `created_at` を ja-JP 日付フォーマット |
| お名前 | `name` |
| メール | `email`（`mailto:` リンク） |
| 電話 | `phone`（null の場合 `-`） |
| 予約日 | `preferred_date`（null の場合 `-`） |
| 予約時間 | `preferred_time`（null の場合 `-`） |
| WSセッション | `session_id` に紐付く `time_label`（null の場合 `-`） |
| 人数 | `participants` |
| 持込 | `bring_plant` / `bring_pot`（あり/なし） |
| 備考 | `note`（null の場合 `-`） |
| ステータス | カラーバッジ + セレクトボックス |
