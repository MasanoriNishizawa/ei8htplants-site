# FT-05 — お問い合わせフォーム

## 概要

お問い合わせフォームの送信機能。入力値のバリデーション、バックエンド経由でのメール送信（Resend）、DBへの保存を行う。

## 使用ページ

| ページID | ページ名 | 用途 |
|---|---|---|
| [PG-05](../pages/public/05_Contact.md) | Contact | お問い合わせフォーム本体 |

## 実装ファイル

`frontend/src/pages/Contact.tsx`

## フォーム項目

| フィールド | 型 | 必須 | バリデーション |
|---|---|---|---|
| お名前 | text | ○ | `required`（HTML5） |
| メールアドレス | email | ○ | `type="email"` + `required` |
| メッセージ | textarea | ○ | `required` |

## 状態管理

| state | 型 | 初期値 | 説明 |
|---|---|---|---|
| `form` | `{name, email, message}` | 各空文字 | フォーム入力値 |
| `status` | `'idle' \| 'loading' \| 'done' \| 'error'` | `'idle'` | 送信状態 |

## 送信フロー

```
フォーム送信（onSubmit）
    │
    ▼
setStatus('loading') → ボタンを無効化・「送信中...」表示
    │
    ▼
api.contact.send({ name, email, message })
    │                               （POST /api/contact）
    ├─ 成功 ──→ setStatus('done')
    │              ▼
    │           「お問い合わせを受け付けました」表示
    │           フォームは非表示
    │
    └─ 失敗 ──→ setStatus('error')
                   ▼
               エラーメッセージ表示・フォームは維持
```

## バックエンド処理（`/api/contact`）

1. `contacts` テーブルに `{name, email, message}` を INSERT
2. Resend API でメール送信
   - `from`: `noreply@ei8htplants.com`
   - `to`: `info@ei8htplants.com`
   - `reply_to`: 送信者のメールアドレス
   - `subject`: `[ei8ht plants] お問い合わせ: {name}`
