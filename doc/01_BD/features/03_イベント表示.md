# FT-03 — イベント表示

## 概要

イベントカードのレンダリング機能。ページ・用途に応じて 2 種類のコンポーネントを使い分ける。

| コンポーネント | 主な用途 |
|---|---|
| `EventPreview.tsx` | /official/events 一覧グリッド・公式ホームの直近イベント（横並びレイアウト） |

イベント専用ページ（`/official/events/:id`）の写真は、上の部品ではなくページ本体の `frontend/src/pages/EventSite.tsx` が表示する（下の「EventSite の写真」を参照）。

---

## EventPreview コンポーネント

### 使用ページ

| ページID | ページ名 | 用途 |
|---|---|---|
| [PG-01](../pages/public/01_Home.md) | Home | 直近イベント1件（horizontal=true で横並び） |
| [PG-02](../pages/public/02_Events.md) | Events | 全イベント一覧グリッド |

### 実装ファイル

`frontend/src/components/EventPreview.tsx`

### Props

| prop | 型 | 説明 |
|---|---|---|
| `event` | `Event` | 表示するイベントデータ |
| `horizontal` | boolean | true のときホーム向けの横並びレイアウト（デフォルト: false） |

### 表示項目

| 項目 | 条件 |
|---|---|
| 画像スライドショー | images[] が1枚以上ある場合 |
| Workshop バッジ | has_workshop = true の場合（画像右上） |
| ブランドバッジ | brands[] 各要素 |
| イベント名 | 常時 |
| 情報ボックス（灰色背景） | 常時（開催日・時間・会場・住所・公式サイトを含む） |
| 開催日 | 常時 |
| 開催時間 | time または daily_times が存在する場合。日ごとに時間が違うときは「5/1（金）10:00〜17:00」のように日ごとに改行して出す。英語表示では曜日も英語（「5/1 (Fri) 10:00〜17:00」。2026-10-22 変更。それまでは英語表示でも曜日が日本語だった） |
| 会場名 | 常時 |
| ブース番号 | booth_number が存在する場合 |
| 住所（Google Maps リンク） | address が存在する場合 |
| 公式サイトリンク | official_url が存在する場合 |
| 「詳細を見る」ボタン | hasSite = true の場合（情報ボックスの外、カード下部に1か所のみ表示） |
| ワークショップ終了メッセージ | has_workshop=true かつ is_past=true の場合 |
| ワークショップ予約リンク | has_workshop=true かつ ws_requires_reservation=true かつ is_past=false の場合 |

### 「詳細を見る」ボタンの表示条件（hasSite）

`page_content` フィールドに以下のいずれかが入力されているとき表示する。

- `hero.image_url`（blob: 以外）
- `hero.tagline`
- `hero.subtitle`
- `venue.address`
- `venue.access`
- `concept`
- `lineup`
- `guests`
- `archive.enabled = true`

ボタンは情報ボックスの外側（カード下部）に1つだけ表示する。情報ボックスの内部にはテキストリンクとして重複表示しない（2026-10-15 修正済み）。

### 画像スライドショー

- 左右ボタンまたはタッチスワイプで切り替え
- 左右ボタン（❮ 前へ・❯ 次へ）は写真が2枚以上のときだけ表示する。ボタンは**写真の上下の真ん中**に置く（写真の高さが変わっても常に真ん中。2026-10-20 修正。以前は写真の上端から 40px の位置に固定されていたため、写真が縦長だと上に寄って見えていた）。/events 一覧のカードでも、ホームの Next Event の大きいカードでも同じ
- 複数枚ある場合はドットインジケーター表示（クリック不可）
- 画像クリックでライトボックス（ImageLightbox）を開く
- ライトボックスは「✕」ボタン・画像の外側（黒い背景）・Esc キーのどれでも閉じる。✕ を押したときに閉じる処理が2回動いていた不具合を 2026-10-20 に修正した（見た目の変化はない）

### 「詳細を見る」ボタンの遷移先

`/official/events/{slug}` または `/official/events/{id}`（slug が未設定の場合）

## EventSite の写真（イベント専用ページ `/official/events/:id`）

### 実装ファイル

`frontend/src/pages/EventSite.tsx`

### 写真の切り替え

- 写真は横幅いっぱいに表示し、高さは写真の縦横比に合わせて変わる（写真ごとに高さが違う）
- 写真が2枚以上のときは、左右ボタン（❮ 前へ・❯ 次へ）と点（何枚目かの目印。押せない）を表示する
- 左右ボタンは**写真の上下の真ん中**に置く。「次へ」を押して縦横比の違う写真に切り替わっても、そのつど真ん中に来る（2026-10-20 修正。以前は上端から 40px の位置に固定されていた）
- 写真の上で指を左右に動かす（スワイプ）と前後の写真に切り替わる
- 写真を押すとライトボックス（ImageLightbox）で拡大表示する

### SNS で共有したとき・検索結果での表示（2026-10-21 追加）

イベント専用ページの URL を LINE・X・Facebook などで共有すると、イベント名・説明・1枚目の写真のカードが出る。Google には、イベントの日時・会場を機械が読める形（構造化データ）で伝える（住所が入っているイベントだけ）。サーバーがページを返すときに入れている。詳しくは [FT-26 検索エンジン・SNS 向けの情報](15_検索エンジン・SNS向け情報.md) を参照。

## データ取得

- `api.events.list(false)` — 開催予定イベント取得（[FT-02](02_APIクライアント.md)）
- `api.events.list(true)` — 過去イベント取得（Admin側）
- Home では取得後に `start_date` 昇順でソートして先頭1件を使用
