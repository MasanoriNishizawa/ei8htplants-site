# FT-03 — イベント表示

## 概要

イベントカードのレンダリング機能。ページ・用途に応じて 2 種類のコンポーネントを使い分ける。

| コンポーネント | 主な用途 |
|---|---|
| `EventPreview.tsx` | /events 一覧グリッド・ホームの直近イベント（横並びレイアウト） |
| `EventCard.tsx` | ホームの直近イベント（旧実装。現在は EventPreview が主） |

---

## EventPreview コンポーネント

### 使用ページ

| ページID | ページ名 | 用途 |
|---|---|---|
| [PG-01](../pages/public/01_Home.md) | Home | 直近イベント1件（horizontal=true で横並び） |
| [PG-02](../pages/public/02_Events.md) | Events | 全イベント一覧グリッド |

### 実装ファイル

`frontend/src/components/EventPreview.tsx`

### Props

| prop | 型 | 説明 |
|---|---|---|
| `event` | `Event` | 表示するイベントデータ |
| `horizontal` | boolean | true のときホーム向けの横並びレイアウト（デフォルト: false） |

### 表示項目

| 項目 | 条件 |
|---|---|
| 画像スライドショー | images[] が1枚以上ある場合 |
| Workshop バッジ | has_workshop = true の場合（画像右上） |
| ブランドバッジ | brands[] 各要素 |
| イベント名 | 常時 |
| 情報ボックス（灰色背景） | 常時（開催日・時間・会場・住所・公式サイトを含む） |
| 開催日 | 常時 |
| 開催時間 | time または daily_times が存在する場合 |
| 会場名 | 常時 |
| ブース番号 | booth_number が存在する場合 |
| 住所（Google Maps リンク） | address が存在する場合 |
| 公式サイトリンク | official_url が存在する場合 |
| 「詳細を見る」ボタン | hasSite = true の場合（情報ボックスの外、カード下部に1か所のみ表示） |
| ワークショップ終了メッセージ | has_workshop=true かつ is_past=true の場合 |
| ワークショップ予約リンク | has_workshop=true かつ ws_requires_reservation=true かつ is_past=false の場合 |

### 「詳細を見る」ボタンの表示条件（hasSite）

`page_content` フィールドに以下のいずれかが入力されているとき表示する。

- `hero.image_url`（blob: 以外）
- `hero.tagline`
- `hero.subtitle`
- `venue.address`
- `venue.access`
- `concept`
- `lineup`
- `guests`
- `archive.enabled = true`

ボタンは情報ボックスの外側（カード下部）に1つだけ表示する。情報ボックスの内部にはテキストリンクとして重複表示しない（2026-10-15 修正済み）。

### 画像スライドショー

- 左右ボタンまたはタッチスワイプで切り替え
- 複数枚ある場合はドットインジケーター表示（クリック不可）
- 画像クリックでライトボックス（ImageLightbox）を開く

### 「詳細を見る」ボタンの遷移先

`/events/{slug}` または `/events/{id}`（slug が未設定の場合）

## EventCard コンポーネント（旧）

### 実装ファイル

`frontend/src/components/EventCard.tsx`

### Props

| prop | 型 | 説明 |
|---|---|---|
| `event` | `Event` | 表示するイベントデータ |
| `isNext` | boolean | 直近イベント強調表示 |
| `isHome` | boolean | ホームページ用レイアウト（最大幅制限） |

### 画像スライドショー

- 左右ボタンまたはタッチスワイプで手動切り替え
- 複数枚ある場合はドットインジケーター表示（クリック不可）

---

## データ取得

- `api.events.list(false)` — 開催予定イベント取得（[FT-02](02_APIクライアント.md)）
- `api.events.list(true)` — 過去イベント取得（Admin側）
- Home では取得後に `start_date` 昇順でソートして先頭1件を使用
