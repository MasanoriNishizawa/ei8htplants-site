# FT-09 — お問い合わせ管理

## 概要

管理者がお問い合わせ一覧を確認・既読管理し、管理画面からメールで返信する機能。未読件数バッジ、アコーディオン展開、既読/未読トグル、返信の入力画面を提供する（2026-10-22 に返信の入力画面を追記。それまでは「返信リンク（mailto:）」と書いていた）。

## API

| 操作 | メソッド | パス |
|---|---|---|
| 一覧取得 | GET | `/api/contacts` |
| 既読更新 | PATCH | `/api/contacts/{id}` |
| 返信を送る | POST | `/api/contacts/{id}/reply` |

## データモデル

```ts
interface ContactRecord {
  id: string
  name: string
  email: string
  message: string
  is_read: boolean
  created_at: string
}
```

## 画面構成

### 未読バッジ

- ヘッダー横に未読件数をバッジ表示
- `contacts.filter(c => !c.is_read).length` で算出
- 0件の場合は非表示

### 一覧アイテム

| 要素 | 説明 |
|---|---|
| 未読ドット | `is_read=false` の場合、オレンジドット表示 |
| 背景色 | 未読: `#fef9f0`（薄黄）、既読: `#fffcf6`（通常） |
| 枠線色 | 未読: `#e8c870`（黄）、既読: `#ddd4c0`（通常） |
| 名前・メール | 常時表示 |
| 受信日時 | ja-JP フォーマット（年月日 時:分） |
| 展開アイコン | アコーディオン状態に応じて▼回転 |

### アコーディオン展開

- アイテムクリック → `expanded` state でIDを管理
- 展開時：メッセージ本文（`white-space: pre-wrap`）を表示
- 同じアイテムを再度クリックで閉じる（`expanded === id ? null : id`）

### 既読/未読トグル

```
「既読にする」ボタンクリック（未読の場合）
    │
    ▼
api.contact.markRead(id, true)    （PATCH /api/contacts/{id} { is_read: true }）
    │
    ▼
setContacts でローカル state を楽観的更新
（再fetchなし）
```

- ボタンラベル：未読 → 「既読にする」、既読 → 「未読に戻す」

## 取得フロー

```
コンポーネントマウント
    │
    ▼
api.contact.list()    （GET /api/contacts）
    │
    ▼
setContacts（新着順）
setLoading(false)
```

### 返信（2026-10-22 追記）

```
各お問い合わせの「返信」ボタンを押す
    │
    ▼
返信の入力画面（画面の上に重ねて出す）
    見出し: 「返信: {メールアドレス}」
    件名: 初めは「Re: ei8ht plants お問い合わせ」
    本文: 初めは「{名前} 様 / お問い合わせいただきありがとうございます。」
    │「送信する」
    ▼
api.contact.reply(id, 件名, 本文)    （POST /api/contacts/{id}/reply）
    │
    ├─ 成功 → 入力画面を閉じ、そのお問い合わせを既読にする
    │         「{メールアドレス} に返信を送信しました。」を4秒表示
    └─ 失敗 → 「返信の送信に失敗しました」を3秒表示（入力画面は開いたまま）
```

- 返信メールは ei8ht plants 名義で送り、本文の最後に「このメールは送信専用です」の案内が付く
- 「キャンセル」・「×」・入力画面の外側を押すと、送らずに閉じる
