# FT-24 — AIチャット

## 概要

Gemini 1.5 Flash を使った植物相談・ワークショップ案内チャット機能。
植物の育て方・管理に関する相談と、ワークショップ・予約に関する質問に対応する ei8ht plants AIコンシェルジュ。
会話履歴はセッション内のみ保持し、DBへの保存は行わない。
バイリンガル対応（質問の言語に合わせて日本語または英語で回答）。

## 状態管理

| state | 型 | 説明 |
|---|---|---|
| `messages` | `Message[]` | 会話履歴（role: `'user'` または `'model'`、content: 文字列） |
| `input` | `string` | テキストエリアの入力値 |
| `loading` | `boolean` | API呼び出し中フラグ（送信ボタン・テキストエリアのdisabled制御） |

## 送信フロー

```
ページ表示
    │
    ▼
useEffect（初回のみ）: ウェルカムメッセージを messages にセット（role='model'）
    │
    ▼
ユーザーがテキストエリアに入力
    Enter（Shift+Enterは改行）または [送信] ボタンクリック
    │
    ▼
send()
    │
    ├─ input が空、または loading=true → 何もしない（早期 return）
    │
    ├─ userMsg = { role: 'user', content: input } を messages に追加
    ├─ setInput('') — 入力欄クリア
    ├─ setLoading(true)
    │
    ▼
    POST /api/chat  { messages: [...履歴 + userMsg] }
    │
    ├─ 200 → { reply: string } → messages に { role: 'model', content: reply } を追加
    └─ エラー → messages にエラーメッセージを追加（バイリンガル対応）
    │
    ▼
    setLoading(false)

メッセージ追加時（初回ウェルカムを除く）:
    chatAreaRef.current.scrollTop = scrollHeight
    // チャットエリア内を最下部へ自動スクロール
```

## バックエンド処理（`POST /api/chat`）

1. `GEMINI_API_KEY` が未設定の場合 → `503 Chat is not available`
2. `genai.configure(api_key=GEMINI_API_KEY)` で Gemini SDK を初期化
3. `gemini-1.5-flash-latest` モデルを `system_instruction=SYSTEM_PROMPT` で生成
4. リクエストの `messages` から最後のメッセージを分離し、それ以前を `history`（Gemini形式）として渡す
5. `chat_session.send_message(最後のメッセージ.content)` を呼び出し
6. 成功 → `{ reply: response.text }` を返す
7. 例外 → `500 Internal Server Error`

## システムプロンプト概要

- ei8ht plants のAIコンシェルジュとして振る舞う
- 取り扱いブランド（ei8ht plants / HUE / Habitat Oides）の説明を含む
- 予約URL・ワークショップURL・キャンセル手順を案内できる
- 植物の育て方（水やり・日当たり・土・肥料・病害虫）に丁寧に答える
- 分からないことはお問い合わせフォーム（/contact）に案内する
- 質問の言語（日本語/英語）に合わせて回答する

## API仕様

```
POST /api/chat
Request:  { messages: [{ role: 'user' | 'model', content: string }] }
Response: { reply: string }
Errors:   503 (GEMINI_API_KEY未設定), 500 (API呼び出し失敗)
```
