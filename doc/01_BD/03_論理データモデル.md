## 3. エンティティ間の関係

| 関係 | 多重度 | 説明 |
|---|---|---|
| Event — EventImage | 1対多 | 1つのイベントに複数の画像が紐付く |
| Event — WorkshopReservation | 1対多 | 1つのイベントに複数の予約が紐付く |
| Order — OrderItem | 1対多 | 1つの注文に複数の注文明細が紐付く |
| OrderItem — Product | 多対1 | 複数の注文明細が1つの商品を参照（削除時NULL） |
| Article — Product | 多対多 | 記事の関連商品ID（配列）で持つ。中間テーブルは無い（2026-10-22 に修正） |
| GalleryImage | 独立 | イベントとは独立。ブランド属性でフィルタリング |
| Stockist | 独立 | ブランドを属性（配列）として保持 |
| Collaboration | 独立 | イベントとは独立したコンテンツ |
| Contact | 独立 | イベントとは無関係の問い合わせ |
| Product | 独立 | カテゴリー・タグで分類 |

## 4. ブランド属性の設計方針

ブランドは `TEXT[]` 配列として各テーブルに直接格納する（正規化なし）。  
理由: ブランド数は固定3種で変更の可能性が低く、正規化のオーバーヘッドを避けるため。

| ブランド値 | 意味 |
|---|---|
| `'ei8ht plants'` | ei8ht plants ブランド |
| `'Habitat Oides'` | Habitat Oides ブランド |
| `'HUE by ei8ht plants'` | HUE by ei8ht plants ブランド |

物理テーブル定義は `doc/02_DD/05_データベース詳細.md` を参照。
