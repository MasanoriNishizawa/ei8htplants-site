# PG-A21 — チャットQ&A（Admin）

## 概要

AI チャット（[PG-22](../public/22_Chat.md)）にあらかじめ教えておく「よくある質問と回答」を登録・編集・削除する画面（画面の見出しは「AIチャット Q&A 管理」）。有効にした Q&A は、AI への指示文に自動で入る。無効にすると一時的に外せる。

## URL / ルート

`/admin/chat-qa`（サイドメニューから開く。ログインが必要）

## 実装ファイル

`frontend/src/pages/admin/AdminChatQA.tsx`

|---|---|---|
| [FT-01](../../features/01_認証.md) | 認証 | AdminLayout による認証ガード |
| [FT-02](../../features/02_APIクライアント.md) | APIクライアント | API の呼び出し |
| [FT-24](../../features/13_AIチャット.md) | AIチャット | AI に渡す Q&A の管理 |

## 使う API

| 操作 | API | ログイン |
|---|---|---|
| 一覧（無効のものも含む） | `GET /api/chat-qa` | 画面からはログインして送る（API 自体は今は不要） |
| 追加 | `POST /api/chat-qa` | 必要 |
| 更新・有効/無効の切り替え | `PATCH /api/chat-qa/{id}` | 必要 |
| 削除 | `DELETE /api/chat-qa/{id}` | 必要 |

## 画面レイアウト（スマホ）

左のメニューは「☰」で開く（管理画面共通）。中身は次のように縦に並ぶ。

```
┌──────────────────────────────┐
│ AIチャット Q&A 管理 [+ 追加] │
│ （説明文）                   │
│ ┌─────────────────────────┐  │
│ │ Q: 予約は必要ですか？   │  │
│ │ A: ワークショップは…    │  │
│ │ 表示順: 1               │  │
│ │ [無効化][編集][削除]    │  │
│ └─────────────────────────┘  │
└──────────────────────────────┘
```

## 操作

| 操作 | 動き |
|---|---|
| 「+ 追加」 | 空の入力欄（表示順 0・有効）を開く |
| 「編集」 | その Q&A の内容を入力欄に入れて開く |
| 「保存」 | 質問か回答が空なら「質問と回答を入力してください」と出して止める。保存できたら入力欄を閉じて一覧を読み直す。失敗したら入力欄の中に「保存に失敗しました（理由）」と出す |
| 「無効化」「有効化」 | すぐに切り替えて保存する。無効の Q&A は薄く表示され、AI への指示文に入らない |
| 「削除」 | 「削除しますか？」の確認のあと消す |

- 一覧は表示順の小さい順に並ぶ。表示順は AI に渡す順でもある
- 1件も無いときは「Q&A がまだ登録されていません。」と出る。読み込みに失敗したときは「Q&A の読み込みに失敗しました（理由）」と出る
- 押している間、同じ Q&A のボタンは二重に押せない

## 保存していない変更の確認（2026-10-23 追加）

- 追加・編集のフォームを開いて、開いたときから内容を変えたときに、サイドメニュー・ログアウト・再読み込みで確認が出る
- フォームを開いている間は Esc キーでも閉じる（2026-10-23 追加）。そのままフォームの **[キャンセル]**・Esc、ほかの Q&A の **[編集]**、**[+ 追加]** を押したときも、「保存していない変更があります。破棄して閉じますか？」と確認する
- 保存に成功するとフォームが閉じるので、確認は出ない
