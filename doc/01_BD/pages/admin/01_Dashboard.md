# PG-A01 — Admin Dashboard

## 概要

Admin画面のダッシュボード。上から順に、件数のカード（未読お問い合わせ・未発送の注文・公開中のイベント）、「出店料の支払い」、「今後の搬入予定」、各管理機能へのナビゲーションカードを表示する。

「出店料の支払い」と「今後の搬入予定」は 2026-10-21 に追加した。イベントの管理情報（出店料・支払い期限・搬入・搬出・ホテル）を、イベントを1つずつ開かなくても見られるようにしたもの。

## URL / ルート

`/admin`（index route）

## 実装ファイル

- `frontend/src/pages/admin/Dashboard.tsx`（画面）
- `frontend/src/pages/admin/dashboardFormat.ts`（「出店料の支払い」「今後の搬入予定」の絞り込み・並べ替え・日付の表示。2026-10-21 追加）

## 出店料の支払い（2026-10-21 追加）

出店料をまだ払っていないイベントを、急ぐ順に並べる。

**出すイベント**: 管理情報の「支払い済み」に印が付いていないイベントのうち、出店料（0円より多い）か支払い期限のどちらかが入っているもの。出店料が0円で期限も無いイベントは出さない。すでに終わったイベントでも、未払いなら出す。

**並び順**:

| 順 | 状態 | 行の見た目 | ラベル |
|---|---|---|---|
| 1 | 期限切れ（支払い期限が今日より前） | 薄い赤の背景・赤い枠。支払い期限の文字も赤 | 期限切れ |
| 2 | 期限まで7日以内（今日が期限の日も含む） | 薄い黄色（クリーム色）の背景・黄色の枠。支払い期限の文字は濃い黄色 | 期限間近 |
| 3 | 期限まで8日以上 | 白い背景 | なし |
| 4 | 支払い期限が入っていない | 白い背景。支払い期限は「未入力」 | 期限未設定 |

同じ状態の中では支払い期限の早い順、期限の無いものどうしは開始日の早い順。

**1行に出す内容**:

| 項目 | 表示の例 | 補足 |
|---|---|---|
| イベント名 | 秋の植物市 | 横に状態のラベル |
| 開催日 | 2026年10月24日（土）〜10月25日（日） | 1日だけのときは開始日だけ。同じ年なら終了日の年を省く |
| 出店料 | 14,000円 | 入っていなければ「未入力」 |
| 支払い方法 | 事前振込 | 入っていなければ「未入力」 |
| 支払い期限 | 2026年10月18日（日）（3日超過） | 残りの日数を「あと3日」「今日まで」「3日超過」で添える |

## 今後の搬入予定（2026-10-21 追加）

開始日が今日から60日先までのイベントを、開始日の早い順に並べる（今日・60日後に始まるものも含む）。すでに始まったイベントは搬入が済んでいるので出さない。

| 項目 | 表示の例 | 補足 |
|---|---|---|
| イベント名 | 秋の植物市 | |
| 開催日 | 2026年10月24日（土）〜10月25日（日） | 出店料の支払いと同じ形 |
| 会場 | 代々木公園 | イベントの会場 |
| 搬入 | 2026年10月24日（土） 08:00 | 管理情報の搬入日時 |
| 搬出 | 2026年10月25日（日） 17:00 | 管理情報の搬出日時 |
| ホテル | 〇〇ホテル | 管理情報の宿泊ホテル名 |

入っていない項目は、どれも薄い色で「未入力」と出す。

## 2つの一覧の共通の動き（2026-10-21 追加）

- 行を押すと、そのイベントの **管理情報の確認画面**（`/admin/events/:id/admin-info`）が開く。確認画面の「← 戻る」でダッシュボードに戻る
- 「今日」は使っている端末（PC・スマホ）の日付
- 一覧は件数のカードとは別に読み込む。片方の読み込みに失敗しても、もう片方と管理メニューは表示される
- ダッシュボードを開くたびに読み込み直す

| 状態 | 表示 |
|---|---|
| 読み込み中 | 読み込み中... |
| 読み込みに失敗 | 読み込みに失敗しました。時間をおいて再度お試しください。（赤字） |
| 出店料の支払いが0件 | 未払いの出店料はありません |
| 今後の搬入予定が0件 | 今日から60日以内に始まるイベントはありません |

データは `GET /api/events/admin-info/dashboard` から読む（[DD-06 API仕様](../../../02_DD/06_API仕様.md)）。絞り込み・並べ替えは `frontend/src/pages/admin/dashboardFormat.ts`。

## AdminLayout 共通構造

全Admin画面は `AdminLayout.tsx` の `<Outlet>` としてレンダリングされる。  
`AdminLayout` がセッション確認・ログインフォーム・サイドバー・ログアウトを担当。  
詳細は [FT-01 認証](../../features/01_認証.md) を参照。
