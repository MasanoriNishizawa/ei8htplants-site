# PG-A01 — Admin Dashboard

## 概要

Admin画面のダッシュボード。各管理機能へのナビゲーションカードを一覧表示する。

## URL / ルート

`/admin`（index route）

## 実装ファイル

`frontend/src/pages/admin/Dashboard.tsx`

## 使用機能（FT紐付け）

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-01](../../features/01_認証.md) | 認証 | AdminLayout による認証ガード（全Admin共通） |

## 画面レイアウト

```
┌────────────────────────────────────────────┐
│ Sidebar（固定）    │ メインコンテンツ      │
│  ei8ht admin       │  ダッシュボード       │
│  ──────────────    │                       │
│  ダッシュボード    │  ┌────────┐┌────────┐ │
│  分析 ↗            │  │イベント││ギャラリ│ │
│  イベント          │  └────────┘└────────┘ │
│  ギャラリー        │  ┌────────┐┌────────┐ │
│  取扱店            │  │取扱店  ││WS予約  │ │
│  WS予約            │  └────────┘└────────┘ │
│  コラボレーション  │  ┌────────┐┌────────┐ │
│  お問い合わせ      │  │コラボ  ││お問合せ│ │
│  （ほかの項目）    │  └────────┘└────────┘ │
│  ──────────────    │                       │
│  ログアウト        │                       │
└────────────────────────────────────────────┘
```

サイドバーの「分析 ↗」（2026-10-17 追加）は、管理画面の中のページではなく、分析ダッシュボード（`https://ei8htplants-analytics.streamlit.app`。Streamlit Community Cloud で公開）を新しいタブで開くリンク。開いた先では管理画面と同じアカウントでもう一度ログインする。詳しくは [画面遷移図](../../02_画面遷移図.md) の「管理画面（AdminLayout.tsx）」と [FT-25 分析ダッシュボード](../../features/14_分析ダッシュボード.md) を参照。

## ナビゲーションカード

| ラベル | 遷移先 | 説明 |
|---|---|---|
| イベント管理 | `/admin/events` | イベントの追加・編集・削除 |
| ギャラリー管理 | `/admin/gallery` | 画像のアップロード・削除 |
| 取扱店管理 | `/admin/stockists` | 取扱店の追加・編集 |
| WS予約一覧 | `/admin/reservations` | ワークショップ予約の確認・ステータス管理 |
| コラボレーション | `/admin/collaborations` | コラボ記事の追加・削除 |
| お問い合わせ | `/admin/contacts` | お問い合わせ内容の確認 |

## AdminLayout 共通構造

全Admin画面は `AdminLayout.tsx` の `<Outlet>` としてレンダリングされる。  
`AdminLayout` がセッション確認・ログインフォーム・サイドバー・ログアウトを担当。  
詳細は [FT-01 認証](../../features/01_認証.md) を参照。
