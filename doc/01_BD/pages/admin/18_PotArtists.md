# PG-A18 — 鉢作家管理（Admin）

## 概要

鉢作家の名前を登録・削除する画面。ここで登録した名前は、[PG-A17 販売価格計算](17_PriceCalc.md) の Habitat Oides のタブで「鉢作家」の選択肢になる。

## URL / ルート

`/admin/pot-artists`（サイドメニューから開く。ログインが必要）

## 実装ファイル

`frontend/src/pages/admin/AdminPotArtists.tsx`

## 使用機能（FT紐付け）

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-01](../../features/01_認証.md) | 認証 | AdminLayout による認証ガード |
| [FT-02](../../features/02_APIクライアント.md) | APIクライアント | API の呼び出し |

## 使う API

| 操作 | API | ログイン |
|---|---|---|
| 一覧 | `GET /api/pot-artists` | 不要 |
| 追加 | `POST /api/pot-artists` | 必要 |
| 削除 | `DELETE /api/pot-artists/{id}` | 必要 |

```
┌─────────────────────────────┐
│ 鉢作家管理                  │
│ [鉢作家名を入力    ] [追加] │

│ │ 作家B            [削除] │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

## 操作

| 操作 | 動き |
|---|---|
| 名前を入れて「追加」 | 一覧の最後に足す。名前が空のときは押せない。追加中は「追加中...」。失敗したら入力欄の下に赤字でメッセージを出す |
| 「削除」 | 「この鉢作家を削除しますか？」の確認のあと消す。失敗したらメッセージを出す |
| 「再読み込み」 | 一覧の読み込みに失敗したときだけ出る。一覧を読み込み直す |

- 一覧の読み込みに失敗したときは、一覧の代わりに赤い枠で「鉢作家の読み込みに失敗しました（理由）」と「再読み込み」ボタンを出す。「鉢作家が登録されていません。」とは出さない（2026-10-22 追加。それまでは失敗すると未登録のように見えた）。（理由）の部分には、ログインの期限切れ・見つからない・入力の誤りなどのわけが入る（[DD-07 エラーハンドリング](../../../02_DD/07_エラーハンドリング.md) の「管理画面の失敗の文言」）

- 登録した順に並ぶ。1件も無いときは「鉢作家が登録されていません。」と出る
- 削除しても、販売価格計算の登録リストに残っている作家名は消えない（リストには名前を文字で保存しているため）

## 保存していない変更の確認（2026-10-23 追加）

名前の欄に何か入れているときに、サイドメニュー・ログアウト・再読み込みで確認が出る。追加に成功すると欄が空に戻るので、確認は出ない。
