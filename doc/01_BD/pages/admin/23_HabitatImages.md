# PG-A23 — Habitat Oides 画像（Admin）

## 概要

Habitat Oides のトップページ（[PG-09](../public/09_HabitatOides.md)。`habitatoides.com` の `/`）で、動きのある演出に使う画像を枠ごとに設定する画面（サイドメニューの「Habitat Oides 画像」）。2026-11-02 追加。

枠は全部で12個ある（一番上の画像5枠・サイン1枠・動くオブジェクト6枠）。ここで保存した画像は、プロジェクト内に置いた画像より優先して公開ページに出る。

同じ12枠は、トップページを見ながら画像をクリックして差し替える [PG-A24 ページ画像の編集](24_PageEditor.md) の「Habitat Oides」のタブでも変えられる（どちらで保存しても同じ所に保存される）。

## URL / ルート

`/admin/habitat-images`（サイドメニューから開く。ログインが必要）

## 公開ページに出る画像の決まり方

枠ごとに、次の順で最初に見つかったものを出す。

1. この画面（または [PG-A24](24_PageEditor.md)）で保存した画像
2. プロジェクト内に置いた画像（上の表の「プロジェクト内の画像」）
3. どちらもないとき: 大きさだけ確保した薄い点線の枠（空の枠）を出す。**サインだけは何も出さない**

プロジェクト内に画像を置く手順は [PG-09 Habitat Oides](../public/09_HabitatOides.md) の「プロジェクト内に画像を置く手順」を参照。

## カードの見方

- プレビュー: 保存した画像（または選んだばかりで未保存の画像）を出す。一番上の画像は横長（16:10）に切り抜いて出し、サイン・オブジェクトは全体が見えるように縮めて出す。透過した画像が分かるよう、後ろに薄い格子の模様を敷く
- 画像がないときは「未設定」と、その下に次のどれかが出る
  - 「プロジェクト内の画像（パス）を表示中」: 公開ページにはプロジェクト内の画像が出ている
  - 「プロジェクト内の画像もないため、空の枠を表示中」: 公開ページには薄い点線の枠が出ている
  - 「プロジェクト内の画像もないため、サインは表示しません」: サインの枠だけ

## 操作

| 操作 | 動き |
|---|---|
| 「画像を選ぶ」 | JPEG・PNG・WebP・GIF の画像を選ぶと、すぐにアップロードしてプレビューに出す（アップロード中は「アップロード中…」）。この時点では公開ページは変わらない |
| 「画像を外す」 | 画像があるときだけ出る。プレビューを空にする（保存すると、公開ページはプロジェクト内の画像、なければ空の枠に戻る） |
| 「変更を取り消す」 | 保存していない変更があるときだけ出る。最後に保存した状態に戻す |
| 「画像を保存」 | 保存していない変更があるときだけ押せる（保存中は「保存中…」）。保存すると「画像を保存しました。」、外して保存すると「画像を外しました。」と出て、公開ページに出るようになる |

- 保存は枠ごと。ほかの枠の変更は一緒には保存されない
- アップロード・保存に失敗したときは、そのカードに赤い文字で「画像のアップロードに失敗しました（理由）」「保存に失敗しました（理由）」が出る。（理由）の部分は [DD-07 エラーハンドリング](../../../02_DD/07_エラーハンドリング.md) の「管理画面の失敗の文言」と同じ
- 最初の読み込みに失敗したときは「画像の設定を読み込めませんでした。再読み込みしてください（読み込めるまで保存はできません）。」と出て、画像を選ぶこと・外すこと・保存ができなくなる（間違って空の値で上書きしないため）
- 読み込み中は「読み込み中…」と出る

## 保存していない変更の確認

どれか1つの枠で、選んだ画像や外した状態をまだ保存していないときに、サイドメニュー・ログアウト・再読み込みで確認が出る（管理画面共通の仕組み。[ユーザーマニュアル](../../../05_OP/03_ユーザーマニュアル.md) の「22. 保存していない変更の確認」）。
