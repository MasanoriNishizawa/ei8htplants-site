# PG-A05 — WS予約管理（Admin）

## 概要

全イベントのワークショップ予約をまとめて見る管理画面。「今後の開催」「過去の開催」のタブで分け、イベントで絞り込み、状態（受付済・キャンセル）を変えられる。予約なしで来た人を「当日参加」として登録したり、予約表を印刷（PDF に保存）したりできる。2026-10-22 に今の画面に合わせて作り直した。

## URL / ルート

`/admin/reservations`

| URL の後ろに付けるもの | 意味 |
|---|---|
| `?event_id=イベントのID` | 開いたときにそのイベントで絞り込む |
| `?past=1` | 開いたときに「過去の開催」のタブにする |

## 実装ファイル

- `frontend/src/pages/admin/Reservations.tsx`
- `frontend/src/lib/reservationConstants.ts`（状態の表示名と色）

## 使う API

| 操作 | API |
|---|---|
| 予約の一覧 | `GET /api/reserves` |
| イベントの一覧（今後・過去） | `GET /api/events?past=false`・`GET /api/events?past=true` |
| 時間枠の一覧 | `GET /api/events/{id}/sessions`（当日参加では `?date=` 付き） |
| 状態の変更 | `PATCH /api/reserves/{id}` |
| 当日参加の登録 | `POST /api/reserve/walkin` |

## 画面レイアウト（PC）

```
┌──────────────────────────────────────────────────────┐
│ [今後の開催] [過去の開催]                            │
├──────────────────────────────────────────────────────┤
│ WS予約一覧                                           │
│  [すべてのイベント ▼] [当日参加を追加] [PDF で印刷]  │
│  全N件 / N名                                         │
├───────┬────────────────────────┬────┬────────────────┤
│ 受付日│お名前                  │人数│ステータス      │
├───────┼────────────────────────┼────┼────────────────┤
│ 10/1  │山田 太郎 [メール未送信]│2名 │[受付済 ▼]      │
│ 10/2  │鈴木 花子               │1名 │[キャンセル ▼]  │
└───────┴────────────────────────┴────┴────────────────┘
```

- 表の列は 受付日・お名前・メール・電話・希望日・予約時間・人数・持込・備考・ステータス（上の図は一部だけ描いている）
- 「すべてのイベント」のときだけ、表の先頭に「イベント」の列が出る
- 確認メールを送れなかった予約は、名前の横に「メール未送信」と出る
- 予約は希望日 → 予約時間の順に並ぶ
- 予約が無いときは「予約はありません。」と出る
- 上の「全N件 / N名」は、表示中の予約のうちキャンセル以外の件数と参加人数の合計（2026-10-22 変更。それまでは「N 件 / 合計 N 名」でキャンセルも数えていた。イベント別の予約画面と同じ数え方にそろえた）
- 状態の変更に失敗したときは、画面の上に赤い枠で「ステータスの変更に失敗しました。元の状態のままです（理由）」と出し、状態は変えない。キャンセルから受付済に戻すときに時間枠が満席なら「満席のため受付済に戻せません。元の状態のままです（理由）」と出す（2026-10-22 変更。それまでは失敗しても画面の上だけ状態が変わっていた）

## 操作

| 操作 | 動き |
|---|---|
| タブ「今後の開催」「過去の開催」 | ワークショップのあるイベントの予約だけを、今後・過去で分けて出す。タブを変えるとイベントの絞り込みは「すべて」に戻る |
| イベントの選択 | そのイベントの予約だけを出す。開いたとき、URL で指定が無く、今日開催中のワークショップがあれば、そのイベントで自動で絞り込む |
| 状態の選択（受付済・キャンセル） | すぐに保存する。キャンセルにすると、予約者にキャンセルのメールが届く（[FT-11](../../features/11_予約ステータス管理.md)） |
| 当日参加を追加（今後の開催のタブだけ） | 下の「当日参加の登録」 |
| PDF で印刷 | 表示中の予約を新しいタブに印刷用の表で出し、印刷の画面を開く（下の「印刷」） |

## 当日参加の登録

```
┌─────────────────────────────────────────┐
│ 当日参加を追加                          │
│ イベント [-- 選択 -- ▼]                 │
│ 参加日   2026-10-24（複数日のときだけ） │
│ 時間枠   [10:00〜11:00　残2枠 ▼]        │
│ 参加人数 [1名 ▼]                        │
│                  [キャンセル] [登録]    │
└─────────────────────────────────────────┘
```

- 開いたとき、今日開催中のワークショップが1つだけならそのイベントを選んだ状態で開く
- 参加日は今日（日本時間）に決まる。時間枠はその日の空きを「残N枠」と出し、満席の枠は選べない
- 時間枠があるイベントでは時間枠を選ばないと登録できない。参加人数は残りの枠の数まで選べる
- 「登録」で `POST /api/reserve/walkin` を送る。名前「当日参加」・状態「受付済」で登録し、メールは送らない

## 印刷

「PDF で印刷」は、表示中の予約が1件以上あるときに出る。

- イベントを選んでいて時間枠があるとき: 日付ごと → 時間枠ごとに予約を並べ、各時間枠に「予約人数 / 定員」と、定員に足りない分の「空枠」の行を出す。予約人数と空枠の数は、キャンセルした予約を除いて数える（キャンセルの行は表には出る。2026-10-22 変更。それまではキャンセルも数えたため、空枠が少なく出ていた）。2日目以降は新しいページから印刷する。どの時間枠にも当てはまらない予約は最後に「セッション未指定」として出す
- それ以外: 予約をそのまま並べる
- 表の列は 受付日・お名前・メール・電話・予約時間・人数・持込・備考・ステータス。上に出力日・予約件数・合計人数を出す（この予約件数・合計人数は、印刷した予約をすべて数える。キャンセルも含むので、画面の「全N件 / N名」と違うことがある）
