# PG-A03 — ギャラリー管理（Admin）

## 概要

ギャラリー画像の追加・削除・並べ替えを行う管理画面。画像ファイルを選んでアップロードし、ALTテキスト・ブランド（どちらも任意）を指定して登録できる（2026-10-22 に記述を修正。画像 URL を入力する欄は無い）。

## URL / ルート

`/admin/gallery`

## 実装ファイル

`frontend/src/pages/admin/Gallery.tsx`

## 使用機能（FT紐付け）

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-01](../../features/01_認証.md) | 認証 | AdminLayout による認証ガード |
| [FT-02](../../features/02_APIクライアント.md) | APIクライアント | `api.gallery.list()`・`api.gallery.add()`・`api.gallery.updateOrder()`・`api.gallery.delete()`・`api.upload()` 呼び出し |
| [FT-04](../../features/04_ギャラリー.md) | ギャラリー | 画像グリッド表示・ブランド紐付け |

## 追加フォーム

| フィールド | 説明 |
|---|---|
| 画像（必須） | ファイルアップロード（クリックで選択、プレビュー表示） |
| ALTテキスト（任意） | テキスト入力 |
| ブランド（任意） | セレクトボックス（選択なし / ei8ht plants / Habitat Oides / HUE）。選択肢は `lib/brands.ts` の短い表記。HUE は「HUE」として保存する（公開ページの HUE のタブもこの値で絞り込む） |

## ブランドフィルター（管理画面内）

- `[すべて] [ei8ht plants] [Habitat Oides] [HUE]` ボタン行
- クライアントサイドフィルタリング（`images.filter(img => img.brand === brandFilter)`）
- `images.indexOf(img)` で元配列のインデックスを取得し、フィルタ中でも並び替えが正しく動作する

## 追加・削除・並び替えフロー

- **追加**: 「+」の枠で画像ファイルを選ぶ → `POST /api/upload` で保存 → 「追加」で `POST /api/gallery { url, alt, brand }` → 一覧再取得
- **削除**: `×` ボタン（右上）→ confirm → `DELETE /api/gallery/{id}` → ローカル state から除去
- **並び替え**: `▲▼` ボタン → `display_order` の swap（となりの画像と2件とも `PATCH /api/gallery/{id}` で `{ display_order }` を送る）→ 一覧再取得

## 画像グリッド

- `aspect-ratio: 1/1` 正方形
- 各画像に `brand` バッジ（左下、半透明黒背景）
- `×` ボタン（右上）で削除
- `▲▼` ボタン（右下）で表示順変更（上下ボタンが端の場合は opacity 低下）
- URL無効時は赤いオーバーレイで「URL無効」バッジを表示
