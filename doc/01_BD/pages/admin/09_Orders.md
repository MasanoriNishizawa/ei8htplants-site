# PG-A09 — 注文管理（admin/Orders）

**URL**: `/admin/orders`  
**レイアウト**: `AdminLayout`（要認証）  
**機能**: FT-13

---

## 画面概要

注文の一覧・詳細確認・ステータス更新ページ。

---

## 一覧テーブル

2026-10-22 に今の画面に合わせて書き直した。

| カラム | 内容 |
|---|---|
| 日時 | 注文日（日本時間の年月日） |
| お名前 | 購入者の名前 |
| 都道府県 | お届け先の都道府県 |
| 合計 | ¥ 表記 |
| 状態 | 選ぶ欄（支払済・発送済・配達完了・キャンセル）。選ぶとすぐ保存する。「発送済」を選んだときは下の「発送情報の入力」が出る |
| 操作 | 「詳細」ボタン（注文詳細を画面の上に重ねて出す） |

注文が無いときは「注文がありません。」と出る。

## 状態

| 値 | 表示 | いつ |
|---|---|---|
| `paid` | 支払済 | 注文を受けて決済できたとき（最初の状態） |
| `shipped` | 発送済 | 商品を送ったとき。購入者に発送のお知らせのメールが届く |
| `delivered` | 配達完了 | 届いたことを確かめたとき（メールは送らない） |
| `cancelled` | キャンセル | 取り消したとき（メールは送らない。この画面から Square の返金はしない） |

## 発送情報の入力

「発送済」を選ぶと出る（一覧の選ぶ欄からでも、注文詳細のボタンからでも同じ）。

| 項目 | 内容 |
|---|---|
| 配送会社 | ヤマト運輸 / 佐川急便 / 日本郵便（ゆうパック） / その他 から選ぶ |
| お問い合わせ番号（任意） | 追跡番号（例: `1234-5678-9012`） |

「発送済みにする」を押すと、状態を発送済にして配送会社・追跡番号を保存し、購入者に発送のお知らせを送る。追跡番号を入れていて、配送会社がヤマト運輸・佐川急便・日本郵便のときは、メールに追跡ページの URL も入る。

## 注文詳細

- 見出し「注文詳細」と状態の印
- お客様情報: お名前・メールアドレス・電話番号（あれば）・Square決済ID
- お届け先: 郵便番号・都道府県・市区町村・番地・建物名・部屋番号（あれば。項目名は「建物名・部屋番号」。2026-10-22 に購入画面の入力欄の名前に合わせた。それまでは「建物名・部屋」）・備考（あれば）
- 注文内容: 商品名 × 数量 と金額、小計・送料・合計
- 配送情報（配送会社か追跡番号があるとき）: 配送会社・追跡番号
- ステータス変更: 4つの状態のボタン（今の状態のボタンは押せない）
- 外側を押すと閉じる
