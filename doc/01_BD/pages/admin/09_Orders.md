# PG-A09 — 注文管理（admin/Orders）

**URL**: `/admin/orders`  
**レイアウト**: `AdminLayout`（要認証）  
**機能**: FT-13

---

## 画面概要

注文の一覧・詳細確認・ステータス更新ページ。

---

## 一覧テーブル

| カラム | 内容 |
|---|---|
| 日時 | created_at |
| 注文番号 | ID先頭8桁 |
| 顧客名 | |
| 合計 | ¥ 表記 |
| ステータス | paid / shipped / cancelled |
| 詳細 | アコーディオン展開 |

---

## 詳細（アコーディオン展開）

- 顧客メール・電話・住所・備考
- 注文明細（商品名・単価・数量・小計）
- 送料・合計
- ステータス変更ボタン（shipped / cancelled）
