# PG-A20 — 設計書（Admin）

## 概要

このリポジトリの `doc/` フォルダにある設計書（Markdown のファイル）を、管理画面の中で読む画面。左のツリーでファイルを選ぶと、右に整えた形で表示する。読むだけで、編集はできない。

## URL / ルート

`/admin/docs`（サイドメニューから開く。ログインが必要）

`/admin/docs?path=05_OP/03_ユーザーマニュアル.md` のように、開いている設計書の `doc/` からの場所を `?path=` に入れる（2026-10-23 追加）。

- ファイルを選ぶたびに URL の `?path=` が変わり、ブラウザの履歴に残る。ブラウザの「戻る」「進む」で、前に開いていた設計書に戻れる。`?path=` の無い URL まで戻ると、本文は「目次からファイルを選択してください。」に戻る
- `?path=` 付きの URL を直接開く・人に送ると、その設計書が開いた状態で表示される（ログインが必要）
- 本文の中の設計書へのリンクを押したときも同じく `?path=` が変わる

## 画面レイアウト（スマホ）

左のメニューは「☰」で開く（管理画面共通）。画面の幅が 768px 以下のときは、目次（ツリー）を上、本文を下に縦に並べる（2026-10-23 変更。それまでは左のツリーが幅240のまま残り、本文が狭くなっていた）。

```
┌─────────────────────────────┐
│ [目次を閉じる]              │
│ 設計書                      │
│ ▶ 00_RD                     │
│ ▼ 01_BD                     │
│    00_INDEX                 │
│ ▶ 02_DD                     │
├─────────────────────────────┤
│ 本文                        │
│ （目次の下に、画面の幅      │
│  いっぱいで表示する）       │
└─────────────────────────────┘
```

- 目次の上の **[目次を開く]**・**[目次を閉じる]** で、ツリーを開け閉めする（このボタンはスマホのときだけ出る）
- 最初に開いたとき、`?path=` が無ければ目次を開いておく。`?path=` があれば閉じておく
- 目次からファイルを選ぶと、目次が閉じて、本文の先頭まで画面が動く（見出しまで指定したリンクのときは、その見出しまで動く）
- 本文はページと一緒にスクロールする

## 表示内容と操作

| 操作 | 動き |
|---|---|
| フォルダ（▶）を押す | 開いて中のファイルを出す（▼）。もう一度押すと閉じる |
| ファイルを押す | 中身を読み込んで右に表示する（読み込み中は「読み込み中...」）。選んでいるファイルは背景が薄い緑になる |

## 本文の中のリンク（2026-10-22 追加）

設計書の中のリンクは、`../02_DD/06_API仕様.md#見出し` のように `doc/` の中の場所で書いてある。それまではそのまま押すと管理画面の別の URL に移って何も出なかったため、種類ごとに次のように動かす。

| リンクの種類 | 例 | 押したとき |
|---|---|---|
| 設計書（`.md`）へのリンク | `../../features/01_認証.md` | 画面を移らず、この画面の中でそのファイルを開く。開いているファイルの場所から行き先を求める。左のツリーも、そのファイルを含むフォルダが開いた状態になり、選んだファイルの背景が薄い緑になる |
| 設計書へのリンクで見出しつき | `../../../02_DD/06_API仕様.md#docs` | そのファイルを開き、表示し終えたら、その見出しまで滑らかに動く。同じファイルを開いているときは、読み込み直さずに見出しまで動く |
| 同じファイルの中の見出しへのリンク | `#本文の中のリンク` | URL を変えずに、その見出しまで動く |
| 外部のサイトへのリンク | `https://…` | 新しいタブで開く（開いた先から管理画面を操作されないようにする設定つき） |
| メール・電話のリンク | `mailto:…` | そのまま（ブラウザに任せる） |
| 設計書の外のファイル（ソースコードなど）へのリンク | `../../frontend/src/App.tsx` | 管理画面では開けないので、押しても何も起きない。マウスを合わせると「設計書の外のファイルのため、ここでは開けません（行き先）」と出る |

- 見出しには、GitHub と同じ決まりで目印（id）を付ける（英字は小文字、記号は取り除き、空白は `-`）。同じ文字の見出しが2つ以上あるときは、2つ目から `-1`・`-2` を後ろに付ける
- `doc/` より上を指すリンクは、設計書へのリンクとして扱わない（押しても何も起きない）
- Ctrl（Mac では Command）・Shift などを押しながらのクリックは、ブラウザの動きに任せる
- 本文は Markdown を HTML にしたあと、スクリプトなどを取り除いて（無害化して）から表示し、そのあとでリンクを整える
- 続けて別のファイルを選んだときは、最後に選んだファイルだけを表示する（先に選んだファイルの読み込みが後から終わっても上書きしない）

## そのほか

- ファイル名の `.md` は出さない。`.md` 以外のファイルと、名前が `.` で始まるものはツリーに出さない
- ツリーを読めなかったときは「設計書ツリーの取得に失敗しました」を目次（ツリー）の欄に、ファイルを読めなかったときは「ファイルの取得に失敗しました」を本文の欄に、赤字で出す（2026-10-23 変更。それまでは両方とも本文の欄に出していた）
- 2026-10-22 から、この2つの API は管理者のログインが必要になる。画面は `lib/api.ts` の `api.docs` を通してログインのトークンを付けて読む（[DD-06 API仕様](../../../02_DD/06_API仕様.md) の「Docs」）
