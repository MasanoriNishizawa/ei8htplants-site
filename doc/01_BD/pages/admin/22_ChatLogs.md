# PG-A22 — チャット履歴（Admin）

## 概要

公開サイトの AI チャット（[PG-22](../public/22_Chat.md)）で、利用者が送った質問と AI の返事を見る画面。読むだけの画面。

## URL / ルート

`/admin/chat-logs`（サイドメニューから開く。ログインが必要）

## 実装ファイル

`frontend/src/pages/admin/AdminChatLogs.tsx`

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-01](../../features/01_認証.md) | 認証 | AdminLayout による認証ガード |

## 画面レイアウト（スマホ）

左のメニューは「☰」で開く（管理画面共通）。中身は次のように縦に並ぶ。

```
┌────────────────────────────────┐
│ チャット履歴         200 件    │
│ ┌─────────────────────────┐    │
│ │10/21 14:30 アガベの… ▼  │    │
│ └─────────────────────────┘    │
│ （行を押すと質問と返事が開く） │
└────────────────────────────────┘
```

## 表示内容と操作

| 項目 | 内容 |
|---|---|
| 件数 | 右上に読み込んだ件数（最大200） |
| 各行 | 送った日時（月/日 時:分）・質問の最初の部分・送った人の印（IP アドレスから作った16文字の記号。IP アドレスそのものは保存しない） |
| 行を押す | 「ユーザー」（質問の全文）と「AI」（返事の全文）が開く。もう一度押すと閉じる。開けるのは1件ずつ |

- 1件も無いときは「まだ履歴がありません。」と出る
- 読み込みに失敗したときは「チャット履歴の読み込みに失敗しました（理由）」と出る
- 同じ印の行は、同じ所（同じ IP アドレス）から送られた質問
