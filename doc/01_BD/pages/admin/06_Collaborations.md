# PG-A06 — コラボレーション管理（Admin）

## 概要

コラボレーション記事の追加・削除を行う管理画面。動画・画像はどちらもファイルを選んでアップロードする（2026-10-22 に記述を修正。それまでは URL を入力すると書いていた）。

- 動画: 「動画ファイルを選択 (.mp4 / .mov / .webm)」を押して選ぶ。アップロード中は「アップロード中…」。終わると動画のプレビューと「削除」が出る。失敗したらメッセージを出して空に戻す
- 画像: 「+」の枠を押して選ぶ。終わると枠に画像が出て、横に「削除」が出る
- 一覧の各行の「削除」は確認のあと消す

## URL / ルート

`/admin/collaborations`

## 実装ファイル

`frontend/src/pages/admin/Collaborations.tsx`

## 失敗したとき（2026-10-22 追加）

見出しの下に赤い枠でわけを出す。それまでは一覧の読み込み・追加・削除・画像のアップロードに失敗しても何も出なかった（動画のアップロードの失敗だけは小さな確認の窓で出していた）。

| 場面 | 出る文言 |
|---|---|
| 一覧を読み込めない | コラボレーションの読み込みに失敗しました（理由） |
| 「追加」に失敗 | 追加に失敗しました（理由） |
| 画像のアップロードに失敗 | 画像のアップロードに失敗しました（理由） |
| 動画のアップロードに失敗 | 動画のアップロードに失敗しました（理由） |
| 「削除」に失敗 | 削除に失敗しました（理由） |

（理由）の部分には、ログインの期限切れ・見つからない・入力の誤りなどのわけが入る（[DD-07 エラーハンドリング](../../../02_DD/07_エラーハンドリング.md) の「管理画面の失敗の文言」）

## 保存していない変更の確認（2026-10-23 追加）

追加の欄に何か入れているとき（空のフォームと違うとき）に、サイドメニュー・ログアウト・再読み込みで確認が出る。追加に成功すると欄が空に戻るので、確認は出ない。
