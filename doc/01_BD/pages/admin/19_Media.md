# PG-A19 — メディア管理（Admin）

## 概要

テレビ・動画などへの出演情報（YouTube の動画）を登録・削除する画面（サイドメニューの「メディア管理」。画面の見出しは「メディア出演管理」）。登録した動画は公開ページの [PG-23 Media](../public/23_Media.md)（`/media`）に並ぶ。

## URL / ルート

`/admin/media`（サイドメニューから開く。ログインが必要）

## 実装ファイル

`frontend/src/pages/admin/AdminMedia.tsx`

## 使う API

| 操作 | API | ログイン |
|---|---|---|
| 一覧 | `GET /api/media-appearances` | 不要 |
| 追加 | `POST /api/media-appearances` | 必要 |
| 削除 | `DELETE /api/media-appearances/{id}` | 必要 |

## 操作

| 操作 | 動き |
|---|---|
| 「追加」 | タイトルと YouTube URL は必ず入れる。URL が YouTube の動画の形（`youtube.com/watch?v=`・`youtu.be/`・`youtube.com/embed/`）でないときは「有効なYouTube URLを入力してください」と出して登録しない。登録すると一覧の先頭に入り、入力欄は空に戻る |
| 「確認」 | 新しいタブで YouTube の動画を開く |
| 「削除」 | 「この動画を削除しますか？」の確認のあと消す |

- 一覧の画像は YouTube のサムネイル。公開日（無ければ空）・説明も出す
- 1件も無いときは「まだ登録されていません。」と出る
- 一覧の読み込みに失敗したときは、一覧の代わりに赤い枠で「メディア出演の読み込みに失敗しました（理由）」と「再読み込み」ボタンを出す。「まだ登録されていません。」とは出さない（2026-10-22 追加。それまでは失敗すると未登録のように見えた）。「再読み込み」を押すと一覧を読み込み直す。（理由）の部分には、ログインの期限切れ・見つからない・入力の誤りなどのわけが入る（[DD-07 エラーハンドリング](../../../02_DD/07_エラーハンドリング.md) の「管理画面の失敗の文言」）
- 公開ページでは公開日の新しい順に並ぶ

## 保存していない変更の確認（2026-10-23 追加）

タイトル・YouTube URL・説明・公開日のどれかに何か入れているときに、サイドメニュー・ログアウト・再読み込みで確認が出る。追加に成功すると欄が空に戻るので、確認は出ない。
