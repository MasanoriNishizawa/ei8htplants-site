# PG-A24 — ページ画像の編集（Admin）

## 概要

3ブランドのトップページを、本物と同じ見た目で画面の中に出し、差し替えたい画像をクリックして選んで変える画面（サイドメニューの「ページ画像の編集」）。2026-11-02 追加。

変えた画像はすぐ画面の中のプレビューに出るが、**「保存する」を押すまで公開ページは変わらない**。何枠か変えてから、まとめて保存する。

| タブ | 対象のページ | 差し替えられる画像 |
|---|---|---|
| ei8ht plants | `ei8htplants.com` の `/`（[PG-08](../public/08_Ei8htPlants.md)） | メインの写真・ロゴ（文字）の2枠 |
| Habitat Oides | `habitatoides.com` の `/`（[PG-09](../public/09_HabitatOides.md)） | 一番上の画像5枠・動くオブジェクト6枠の11枠（[PG-A23 Habitat Oides 画像](23_HabitatImages.md) と同じ枠）。右下のサインは差し替えられない（プロジェクト内のファイルだけで出す。[PG-09](../public/09_HabitatOides.md) の「右下のサインを変えるとき」） |
| HUE | `huebyei8htplants.com` の `/`（[PG-11](../public/11_Hue.md)） | 色の写真 01〜06 の6枠（管理画面「サイト画像」と同じ枠） |

## URL / ルート

| URL | 内容 |
|---|---|
| `/admin/page-editor/:brand` | 編集画面。`:brand` は `ei8htplants`・`habitat-oides`・`hue` のどれか |
| `/admin/page-editor` | サイドメニューから開く URL。`/admin/page-editor/ei8htplants` に移る |
| `/admin/page-editor/（上の3つ以外）` | `/admin/page-editor/ei8htplants` に移る |
| `/admin/page-preview/:brand` | 編集画面の中に埋め込んで出すプレビュー（下の「プレビューのしくみ」）。単独で開くこともできるが、ふつうは使わない。ブランドが正しくないときは「プレビューできないページです。」と出る |

どの URL もログインが必要。プレビューの URL は、ログインを確かめたうえで、サイドメニューを出さずにページ本体だけを出す。

## プレビュー

- 表示幅は「PC（1280px）」（高さ 800px）と「スマホ（390px）」（高さ 844px）を上のボタンで切り替える。画面に収まらないときは全体を縮めて出し、下に「PC 幅（1280px）で表示しています（62% に縮小）。」のように出る
- 表示幅は、ブランドのタブを切り替えても引き継ぐ
- 本物のトップページと同じ部品を使う。ただしヘッダー・フッターは出さない
- プレビューの中のリンクやボタンは、押してもページを移動しない（下の「押せるもの」以外）
- プレビューの中では、動きを止める（スプラッシュ・画像の出方の演出・スクロールに合わせた動き・スライダーの自動の切り替え。HUE のスクロールの演出も止める）。Habitat Oides のスプラッシュは出さず、「このタブでもう出した」という記録も残さない

### 押せるもの

| 場所 | 動き |
|---|---|
| 差し替えられる画像 | マウスを乗せると青い枠線と枠の名前が出る。押すとその枠を選び、右にパネルが出る。選んでいる枠は枠線が出たままになる |
| 画像がまだない枠 | 青い点線の枠と枠の名前がいつも出る（空いている枠だと分かるように） |
| Habitat Oides の一番上の画像の「Prev」「Next」 | 押せる。画像のない枠も含めた5枠を順に行き来できる（スマホの幅でも矢印を出す） |

ブランドごとの違い:

- **ei8ht plants**: メインの写真と、見出しの上のロゴ（文字）に枠が重なる
- **Habitat Oides**: 一番上の画像は、表示中の1枚に枠が重なる。右下のサインには枠が重ならず、押しても選べない（差し替えの対象ではない。`sign.svg` があれば公開ページと同じように出る）。動くオブジェクトの帯の見出しは、後ろのオブジェクトを押す邪魔をしない
- **HUE**: 「一鉢から、暮らしを選ぶ。」の6枚の丸い写真に枠が重なる（これが本体）。同じ写真を使う横に流れる3章（01・03・05）と下の読みもののカード（02・04・06）にも枠が重なり、押すと同じ枠を選ぶ（キーボードの Tab ではこちらには移らない）

## 操作

| 操作 | 動き |
|---|---|
| ブランドのタブ | 別のブランドに切り替える。保存していない変更があれば確認が出る（[キャンセル]なら切り替えない）。切り替えると、編集中の画像と選んだ枠は空に戻る |
| 「枠の一覧」のボタン | プレビューで見つけにくい枠もここから選べる。選ぶとプレビューがその枠の所までスクロールする。Habitat Oides の一番上の画像の枠を選ぶと、スライダーがその画像に切り替わる。変えた枠には「変更あり」、保存・アップロードに失敗した枠には「失敗」の札が付く |
| パネルの「画像を選ぶ」 | JPEG・PNG・WebP・GIF の画像を選ぶと、すぐにアップロードしてプレビューに出す（アップロード中は「アップロード中…」） |
| パネルの「画像を外す」 | 管理画面で設定した画像があるときだけ出る。プレビューから外す。下に、外すと何が出るか（「外すと、プロジェクト内の画像（パス）が表示されます。」「外すと、画像のない状態（空の枠）になります。」のどちらか）が出る |
| パネルの「変更を取り消す」 | 保存していない変更があるときだけ出る。その枠を最後に保存した状態に戻す |
| パネルの「閉じる」 | パネルを閉じる（変更は残る） |
| 「保存する」 | 変えた枠だけをまとめて保存する（保存中は「保存中…」）。変更がないとき・読み込み中・アップロード中は押せない |

パネルには、枠の名前・推奨サイズの説明・今の画像（透過した画像が分かるよう薄い格子の模様の上。なければ「画像なし」）と、その画像の出どころ（「管理画面で設定した画像」「プロジェクト内の画像（パス）」「未設定（画像なし）」のどれか）が出る。保存していない変更があると「未保存の変更あり」の札が付く。

### 変更の件数と保存の結果

- 上の右に「変更 N 件（未保存）」が出る（変更がないときは「変更はありません」）
- すべて保存できたとき: 「N 件を保存しました。公開ページに反映されます。」（緑）
- 一部が失敗したとき: 「N 件を保存しました。M 件は保存できませんでした（変更は残っています。枠を選ぶと理由を確認できます）。」（赤）。失敗した枠は変更が残ったままなので、もう一度「保存する」で送り直せる。理由はその枠を選ぶとパネルに赤い文字で出る（[DD-07 エラーハンドリング](../../../02_DD/07_エラーハンドリング.md) の「管理画面の失敗の文言」）

### 読み込みに失敗したとき

「画像の設定を読み込めませんでした。再読み込みしてください（読み込めるまで、画像を選ぶことと保存はできません）。」と出る。プレビューは保存済みの画像で出し続けるが、画像を選ぶ・外す・保存はできない。

## 公開ページに出る画像の決まり方

枠ごとに、次の順で最初に見つかったものを出す（3ブランド共通）。

1. この画面（Habitat Oides は [PG-A23](23_HabitatImages.md) でも）で保存した画像
2. プロジェクト内に置いた画像（ei8ht plants のメインの写真は `/img/ei8htPlants/ei8htplants_hero.jpg`、ロゴは `/img/text-logo-ei8htplants.png`。Habitat Oides は [PG-A23](23_HabitatImages.md) の表。HUE はなし）
3. どちらもないとき: Habitat Oides は薄い点線の枠、HUE は今までどおり色の面

プレビューの中では、1 の代わりに「保存した画像に、この画面で変えた画像を重ねたもの」を使う。

## プレビューのしくみ

編集画面の中に、別のページ（`/admin/page-preview/:brand`）を枠ごと埋め込んで出している。編集画面とプレビューは次の3種類の連絡をやりとりする。

| 向き | 連絡 | 中身 |
|---|---|---|
| プレビュー → 編集画面 | 準備ができた | ブランド |
| 編集画面 → プレビュー | 今の状態 | ブランド・編集中の画像・選んでいる枠・その枠までスクロールするか |
| プレビュー → 編集画面 | 枠を選んだ | ブランド・枠のキー |

ほかのサイトやほかの画面からの連絡を間違って受け取らないよう、受け取る側は次を確かめて、合わないものは使わない。

- 送り元のサイト（オリジン）が同じであること
- 編集画面は「自分が埋め込んだプレビュー」から、プレビューは「自分を埋め込んだ編集画面」から来たものであること
- 連絡の形が決まったとおりであること、ブランドが一致していること
- プレビューは、選んでいる枠のキーがそのブランドの枠であることも確かめる（違えば選んでいない扱い）

詳しくは [DD-03 フロントエンドロジック](../../../02_DD/03_フロントエンドロジック.md) の「72. 管理画面 — ページ画像の編集とプレビュー」。

## 保存していない変更の確認

どれかの枠を変えてまだ保存していないときに、サイドメニュー・ログアウト・再読み込み・ブランドのタブの切り替えで確認が出る（管理画面共通の仕組み。[ユーザーマニュアル](../../../05_OP/03_ユーザーマニュアル.md) の「22. 保存していない変更の確認」）。
