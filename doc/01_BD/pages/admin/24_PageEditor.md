# PG-A24 — ページ画像の編集（Admin）

## 概要

3ブランド（ei8ht plants・Habitat Oides・HUE）と公式サイトのページを、本物と同じ見た目で画面の中に出し、差し替えたい画像をクリックして選んで変える画面（サイドメニューの「ページ画像の編集」）。2026-11-02 追加。

2026-11-05 に、ページの画像を変える管理画面をこの画面だけにした。それまであった「サイト画像」（`/admin/site-images`。HUE の6枚）と「Habitat Oides 画像」（`/admin/habitat-images`。[PG-A23](23_HabitatImages.md)）は廃止し、同じ画像はこの画面で変える。同じ日に、トップページ以外のページと公式サイトにも対応した。

変えた画像はすぐ画面の中のプレビューに出るが、**「保存する」を押すまで公開ページは変わらない**。同じブランドの中なら、ページを切り替えても変えた内容は残り、まとめて保存できる。

### この画面では変えられない画像

| 画像 | 理由・変え方 |
|---|---|
| Habitat Oides の右下のサイン | 変えることがないので、プロジェクト内のファイルだけで出す（[PG-09](../public/09_HabitatOides.md) の「右下のサインを変えるとき」） |
| Habitat Oides の Collaborations の写真 | コラボ記事のデータの写真。管理画面の「コラボレーション」で変える |
| コラボ動画 | 動画は画像の枠にしていない |
| 公式サイトのデータベースから出している写真（商品・記事・イベント・ギャラリー・Media） | それぞれの管理画面（商品管理・記事管理・イベント・ギャラリー・メディア管理）で変える |
| ヘッダー・フッターのロゴ | 全ページ共通の部品なので、この画面の対象にしていない |
| Concept など、固定の画像がないページ | 差し替える画像がないので、ページの選択欄に出さない |

## URL / ルート

| URL | 内容 |
|---|---|
| `/admin/page-editor/:brand/:page?` | 編集画面。`:brand` は `ei8htplants`・`habitat-oides`・`hue`・`official` のどれか。`:page` はページの識別子（ei8ht plants は `home`・`about`、Habitat Oides は `home`・`workshop`、HUE は `home`・`about`・`choose`・`living`、公式サイトは `home`・`brands`）。`:page` を省くとトップページ（`home`）を出す。そのブランドにないページなら `/admin/page-editor/:brand`（トップページ）に移る |
| `/admin/page-editor` | サイドメニューから開く URL。`/admin/page-editor/ei8htplants` に移る |
| `/admin/page-editor/（上の4つ以外のブランド）` | `/admin/page-editor/ei8htplants` に移る |
| `/admin/page-preview/:brand/:page?` | 編集画面の中に埋め込んで出すプレビュー（下の「プレビューのしくみ」）。単独で開くこともできるが、ふつうは使わない。`:page` を省くとトップページを出す。ブランド・ページが正しくないときは「プレビューできないページです。」と出る |
| `/admin/site-images`（廃止） | `/admin/page-editor/hue` に移る（2026-11-05） |
| `/admin/habitat-images`（廃止。[PG-A23](23_HabitatImages.md)） | `/admin/page-editor/habitat-oides` に移る（2026-11-05） |

どの URL もログインが必要。プレビューの URL は、ログインを確かめたうえで、サイドメニューを出さずにページ本体だけを出す。

廃止した2つの画面で保存した画像は、この画面と同じ所（同じキー）に保存されているので、そのまま公開ページに出て、この画面でも見える。移し替えの作業はいらない。

| 操作 | API | ログイン |

## プレビュー

- 表示幅は「PC（1280px）」（高さ 800px）と「スマホ（390px）」（高さ 844px）を上のボタンで切り替える。画面に収まらないときは全体を縮めて出し、下に「PC 幅（1280px）で表示しています（62% に縮小）。」のように出る
- 表示幅は、ブランド・ページを切り替えても引き継ぐ
- 選んだ公開ページと同じ部品を使う。ただしヘッダー・フッターは出さない
- プレビューの中のリンクやボタンは、押してもページを移動しない（下の「押せるもの」以外）
- プレビューの中では、動きを止める（スプラッシュ・画像の出方の演出・スクロールに合わせた動き・スライダーの自動の切り替え。HUE のスクロールの演出も止める）。Habitat Oides のスプラッシュは出さず、「このタブでもう出した」という記録も残さない

### 押せるもの

| 場所 | 動き |
|---|---|
| 差し替えられる画像 | マウスを乗せると青い枠線と枠の名前が出る。押すとその枠を選び、右にパネルが出る。選んでいる枠は枠線が出たままになる |
| 画像がまだない枠 | 青い点線の枠と枠の名前がいつも出る（空いている枠だと分かるように） |
| Habitat Oides の一番上の画像の「Prev」「Next」 | 押せる。画像のない枠も含めた5枠を順に行き来できる（スマホの幅でも矢印を出す） |

ブランドごとの違い:

- **ei8ht plants**: トップページはメインの写真と、見出しの上のロゴ（文字）に枠が重なる。About は一番上のメインの写真と、本文の下のロゴ（文字）に枠が重なる
- **Habitat Oides**: 一番上の画像は、表示中の1枚に枠が重なる。右下のサインには枠が重ならず、押しても選べない（差し替えの対象ではない。`sign.svg` があれば公開ページと同じように出る）。動くオブジェクトの帯の見出しは、後ろのオブジェクトを押す邪魔をしない。「私たちの考え方」の写真とワークショップの欄の写真にも枠が重なる。Workshop のページは「ワークショップについて」の写真に枠が重なる
- **HUE**: トップページは「一鉢から、暮らしを選ぶ。」の6枚の丸い写真に枠が重なる（これが本体）。同じ写真を使う横に流れる3章（01・03・05）と下の読みもののカード（02・04・06）にも枠が重なり、押すと同じ枠を選ぶ（キーボードの Tab ではこちらには移らない）。About・Choose・Living は、見出しの横の写真と3つの読みものの写真に枠が重なる。見出しの写真と同じ番号の読みもの（Choose の 03・Living の 04）は、押すと同じ枠を選ぶ（Tab では移らない）。枠は写真全体に重なる
- **公式サイト**: トップページは一番上のメインの写真と、ブランドの帯の3枚のカードに枠が重なる。ブランドの帯は、公開ページではマウスを乗せたカードが広がるが、プレビューではマウスを乗せても広がらず、**選んでいる枠のカードが広がる**（ブランドの写真の枠を選んでいないときは先頭の ei8ht plants のカード）。Our Brands は3枚のカードに枠が重なる（マウスを乗せたときに写真が大きくなる動きは止める）

HUE の「枠の一覧」には、今のページに出ている写真だけが出る（About は 01・02・03・05、Choose は 01・03・05、Living は 02・04・06）。1枚の写真を使うページは、01・03・05 がトップページ・About・Choose、02 がトップページ・About・Living、04・06 がトップページ・Living。

## 操作

| 操作 | 動き |
|---|---|
| 「編集するページ」の選択欄 | 同じブランドの中で、別のページに切り替える。保存していない変更は残り、確認は出ない。選んでいた枠が切り替えた先のページにないときは、パネルを閉じる。選択欄の各ページは「ページ名（公開時の URL） - 変更 N 件」の形で出る（そのページに変更がなければ「 - 変更 N 件」は付かない）。選択欄の横に「公開時の URL: …」が出る |
| ブランドのタブ | 別のブランドのトップページに切り替える。保存していない変更があれば確認が出る（[キャンセル]なら切り替えない）。切り替えると、編集中の画像と選んだ枠は空に戻る |
| 「枠の一覧」のボタン | プレビューで見つけにくい枠もここから選べる。選ぶとプレビューがその枠の所までスクロールする。Habitat Oides の一番上の画像の枠を選ぶと、スライダーがその画像に切り替わる。変えた枠には「変更あり」、保存・アップロードに失敗した枠には「失敗」の札が付く |
| パネルの「画像を選ぶ」 | JPEG・PNG・WebP・GIF の画像を選ぶと、すぐにアップロードしてプレビューに出す（アップロード中は「アップロード中…」） |
| パネルの「画像を外す」 | 管理画面で設定した画像があるときだけ出る。プレビューから外す。下に、外すと何が出るか（「外すと、プロジェクト内の画像（パス）が表示されます。」「外すと、画像のない状態（空の枠）になります。」のいずれか。公式サイトの HUE は下記の専用案内）が出る |
| パネルの「変更を取り消す」 | 保存していない変更があるときだけ出る。その枠を最後に保存した状態に戻す |
| パネルの「閉じる」 | パネルを閉じる（変更は残る） |
| 「保存する」 | このブランドで変えた枠を、どのページで変えたものもまとめて保存する（保存中は「保存中…」）。変更がないとき・読み込み中・アップロード中は押せない |

パネルには、枠の名前・推奨サイズの説明・今の画像（透過した画像が分かるよう薄い格子の模様の上。なければ「画像なし」）と、その画像の出どころ（「管理画面で設定した画像」「プロジェクト内の画像（パス）」「未設定（画像なし）」のどれか）が出る。保存していない変更があると「未保存の変更あり」の札が付く。

公式サイトの HUE 紹介画像を外すと、公式トップは HUE のロゴ、Our Brands は HUE の「色の写真 01」（`hue-color-01`）を出す。写真01も未設定なら Our Brands の背景写真は出さない。パネルの「今の画像」と出どころも、選択中のページで出る代わりの画像に合わせる。「画像を外す」の下には、この2ページでの違いを案内する。

複数のページで使っている枠を選ぶと、パネルに「この写真は HUE の他のページでも使われます（トップページ・About（HUEについて）・Choose（一鉢の選び方））。」のような案内が出る（かっこの中は、その枠を使っているページ全部。今のページも入る。ei8ht plants の文字ロゴは「この画像は…」）。その枠を変えると、案内に出たページ全部の画像が変わる。案内が出るのは次の枠。

- HUE の色の写真 01〜06（その番号を使っているページだけを出す）
- ei8ht plants のロゴ（文字）（トップページ・About）
- 公式サイトのブランド紹介の写真3枚（トップページ・Our Brands）

### 変更の件数と保存の結果

- 上の右に「変更 N 件（未保存）」が出る（変更がないときは「変更はありません」）。N はこのブランドの全ページの合計で、複数のページで使う枠は1件と数える
- すべて保存できたとき: 「N 件を保存しました。公開ページに反映されます。」（緑）
- 一部が失敗したとき: 「N 件を保存しました。M 件は保存できませんでした（変更は残っています。枠を選ぶと理由を確認できます）。」（赤）。失敗した枠は変更が残ったままなので、もう一度「保存する」で送り直せる。理由はその枠を選ぶとパネルに赤い文字で出る（[DD-07 エラーハンドリング](../../../02_DD/07_エラーハンドリング.md) の「管理画面の失敗の文言」）

### 読み込みに失敗したとき

「画像の設定を読み込めませんでした。再読み込みしてください（読み込めるまで、画像を選ぶことと保存はできません）。」と出る。プレビューは保存済みの画像で出し続けるが、画像を選ぶ・外す・保存はできない。

## 公開ページに出る画像の決まり方

枠ごとに、次の順で最初に見つかったものを出す（4サイト共通）。

1. この画面で保存した画像
2. プロジェクト内に置いた画像（上の「ページごとの枠」の表。`pageImageSlots.ts` と `habitatMotionSlots.ts` の `localSrc`）
3. どちらもないとき: Habitat Oides のトップページの動く画像は薄い点線の枠、HUE の色の写真は今までどおり色の面

公式サイトの「ブランド紹介の写真（HUE）」だけは、プロジェクト内の画像がないので、保存していないときは今までどおりの出し方になる。

- トップページのブランドの帯: HUE のロゴを大きく出す
- Our Brands のカード: HUE の色の写真 01（`hue-color-01`）を出す。つまり「ブランド紹介の写真（HUE）→ 色の写真 01」の順

プレビューの中では、1 の代わりに「保存した画像に、この画面で変えた画像を重ねたもの」を使う。

## プレビューのしくみ

編集画面の中に、別のページ（`/admin/page-preview/:brand/:page?`）を枠ごと埋め込んで出している。編集画面とプレビューは次の3種類の連絡をやりとりする。

| 向き | 連絡 | 中身 |
|---|---|---|
| プレビュー → 編集画面 | 準備ができた | ブランド・ページ |
| 編集画面 → プレビュー | 今の状態 | ブランド・ページ・編集中の画像・選んでいる枠・その枠までスクロールするか |
| プレビュー → 編集画面 | 枠を選んだ | ブランド・ページ・枠のキー |

ほかのサイトやほかの画面からの連絡を間違って受け取らないよう、受け取る側は次を確かめて、合わないものは使わない。

- 送り元のサイト（オリジン）が同じであること
- 編集画面は「自分が埋め込んだプレビュー」から、プレビューは「自分を埋め込んだ編集画面」から来たものであること
- 連絡の形が決まったとおりであること、ブランドとページが一致していること
- プレビューは、選んでいる枠のキーがそのページの枠であることも確かめる（違えば選んでいない扱い）

詳しくは [DD-03 フロントエンドロジック](../../../02_DD/03_フロントエンドロジック.md) の「72. 管理画面 — ページ画像の編集とプレビュー」。

## 保存していない変更の確認

どれかの枠を変えてまだ保存していないときに、サイドメニュー・ログアウト・再読み込み・ブランドのタブの切り替えで確認が出る（管理画面共通の仕組み。[ユーザーマニュアル](../../../05_OP/03_ユーザーマニュアル.md) の「22. 保存していない変更の確認」）。同じブランドの中でページを切り替えるときは、変更が残るので確認は出ない。

**今ある制限**（2026-11-05 時点。管理画面全体に前からある制限で、今回は直していない。将来の改善候補）: ブラウザの「戻る」「進む」のボタンで移ったときは確認が出ない。たとえば、ブランドのタブで別のブランドに移ってから画像を変え、保存しないままブラウザの「戻る」で前のブランドに戻ると、確認なしで変えた内容が消える。変えたあとは「保存する」を押してから移る。
