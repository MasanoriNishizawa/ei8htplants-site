# PG-A08 — 商品管理（admin/Products）

**URL**: `/admin/products`  
**レイアウト**: `AdminLayout`（要認証）  
**機能**: FT-13

---

## 画面概要

商品のCRUD管理ページ。一覧テーブルと編集モーダルで構成される。右上の「+ 商品追加」で新しい商品のモーダルを開く。一覧は公開・非公開をすべて出す（`GET /api/products?all=true`。2026-10-22 から、この全件の取得はログインが必要）。

---

## 一覧テーブル

| カラム | 内容 |
|---|---|
| 画像 | サムネイル 48×48px |
| 商品名 | |
| カテゴリー | 未設定は "—" |
| 価格 | ¥ 表記 |
| 在庫 | 0の場合赤字 |
| 状態 | 公開中 / 非公開（押すとすぐ切り替えて保存） |
| 操作 | 編集 / 削除ボタン（削除は「「商品名」を削除しますか？」の確認のあと） |

商品が無いときは「商品がありません。」と出る。

---

## 編集モーダル

| フィールド | 型 | 備考 |
|---|---|---|
| 商品名 | テキスト | 必須 |
| 価格（円・税込） | 数値 | 必須 |
| 在庫数 | 数値 | 必須 |
| 本文・画像 | BlockEditor | heading/text/image ブロック |
| カテゴリー | ラジオボタン | 未設定 + 9カテゴリー |
| タグ | テキスト + Enter追加 | 複数可 |
| 公開する | チェックボックス | |

モーダルの見出しは「商品追加」または「商品編集」。下に「キャンセル」「保存」。

---

## 特記事項

- `description` フィールドは BlockEditor JSON 文字列として保存
- 画像は BlockEditor の image ブロック経由でアップロード（Supabase images バケット）
- `image_urls` は BlockEditor の image ブロック URL を同期

## 2026-10-23 の変更

- 編集の画面（モーダル）は、**[キャンセル]**・画面の外側・Esc キーのどれで閉じるときも、開いたときから内容を変えていれば「保存していない変更があります。破棄して閉じますか？」と確認する。保存中は閉じない。日本語入力の変換中の Esc では閉じない
- スマホ（幅 768px 以下）で一覧の表が横にスクロールするときも、「操作」（編集・削除）の列を右端に止めて表示する（`.admin-sticky-col`）
