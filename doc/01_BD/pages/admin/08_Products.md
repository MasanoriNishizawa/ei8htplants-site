# PG-A08 — 商品管理（admin/Products）

**URL**: `/admin/products`  
**レイアウト**: `AdminLayout`（要認証）  
**機能**: FT-13

---

## 画面概要

商品のCRUD管理ページ。一覧テーブルと編集モーダルで構成される。

---

## 一覧テーブル

| カラム | 内容 |
|---|---|
| 画像 | サムネイル 48×48px |
| 商品名 | |
| カテゴリー | 未設定は "—" |
| 価格 | ¥ 表記 |
| 在庫 | 0の場合赤字 |
| 状態 | 公開中 / 非公開（クリックでトグル） |
| 操作 | 編集 / 削除ボタン |

---

## 編集モーダル

| フィールド | 型 | 備考 |
|---|---|---|
| 商品名 | テキスト | 必須 |
| 価格（円・税込） | 数値 | 必須 |
| 在庫数 | 数値 | 必須 |
| 本文・画像 | BlockEditor | heading/text/image ブロック |
| カテゴリー | ラジオボタン | 未設定 + 9カテゴリー |
| タグ | テキスト + Enter追加 | 複数可 |
| 公開する | チェックボックス | |

---

## 特記事項

- `description` フィールドは BlockEditor JSON 文字列として保存
- 画像は BlockEditor の image ブロック経由でアップロード（Supabase images バケット）
- `image_urls` は BlockEditor の image ブロック URL を同期
