# PG-A17 — 販売価格計算（Admin）

## 概要

仕入れ値から販売価格の目安（仕入れ値の2倍）を計算し、決めた価格を「登録リスト」に残す画面（サイドメニューの「販売価格計算」。画面の見出しも「販売価格計算」。2026-10-22 にメニューに合わせた。それまで見出しは「販売金額計算」だった）。ブランドごとにタブで分かれている。

## URL / ルート

`/admin/price-calc`（サイドメニューから開く。ログインが必要）

## 実装ファイル

`frontend/src/pages/admin/PriceCalc.tsx`

## 使う API

| 操作 | API | ログイン |
|---|---|---|
| 鉢作家の一覧（Habitat Oides の選択肢） | `GET /api/pot-artists` | 不要 |
| 登録リストの一覧 | `GET /api/price-calc-entries` | 必要 |
| 登録 | `POST /api/price-calc-entries` | 必要 |
| 削除 | `DELETE /api/price-calc-entries/{id}` | 必要 |

## タブごとの入力と計算

| タブ | 入力 | 元値（コスト） | 推奨販売価格 |
|---|---|---|---|
| ei8ht plants | 植物名・種別（仕入れ / 実生）・仕入れ値、または種子20粒あたりの金額 | 仕入れなら仕入れ値。実生なら種子20粒の金額 ÷ 20（1粒あたりの金額を下に出す） | 元値 × 2 |
| Habitat Oides | 植物名・植物仕入れ値・鉢仕入れ値・鉢作家（選ばないときは「量産鉢」） | 植物仕入れ値 + 鉢仕入れ値 | 元値 × 2 |
| HUE | なし | — | 「HUE の計算機は準備中です。」と出る |

- 「任意価格（推奨価格を上書き）」に入れると、その金額で登録する（「登録価格: ¥…」と出る）
- 「登録」ボタンは、植物名と元値（と価格）が入っているときだけ押せる。登録するとリストの先頭に入り、入力欄は空に戻る
- 鉢作家の選択肢は [PG-A18 鉢作家管理](18_PotArtists.md) で登録したもの

## 失敗したとき（2026-10-22 追加）

見出しの下に赤い枠でわけを出す。それまでは読み込みに失敗しても何も出なかった（鉢作家の一覧・登録リストが空に見えた）。

| 場面 | 出る文言 |
|---|---|
| 鉢作家の一覧を読み込めない | 鉢の作家の読み込みに失敗しました（理由） |
| 登録リストを読み込めない | 登録リストの読み込みに失敗しました（理由） |
| 「登録」に失敗 | 登録に失敗しました（理由） |
| 「削除」に失敗 | 削除に失敗しました（理由） |

（理由）の部分には、ログインの期限切れ・見つからない・入力の誤りなどのわけが入る（[DD-07 エラーハンドリング](../../../02_DD/07_エラーハンドリング.md) の「管理画面の失敗の文言」）

## 登録リスト

- 新しい順に並ぶ。列は 植物名と鉢作家（無ければ「量産鉢」）・ブランド・元値・販売価格・削除
- 「削除」は「この登録を削除しますか？」の確認のあと消す
- 1件も無いときは「まだ登録されていません。」と出る
- 登録リストは計算の記録で、ショップの商品の価格（[PG-A08 商品管理](08_Products.md)）には自動で反映しない

## 保存していない変更の確認（2026-10-23 追加）

- 開いているタブの入力欄（植物名・仕入れ値・鉢の値段・鉢作家・任意価格など）のどれかに何か入れているときに、サイドメニュー・ログアウト・再読み込みで確認が出る
- ブランドのタブを切り替えるときも、書きかけがあれば「保存していない変更があります。破棄して移動しますか？」と確認する（タブを切り替えると入力が消えるため）
