# PG-A14 — 全体の収支（Admin）

## 概要

全イベントの収支を一覧表示する管理画面（サイドメニューの「収支」の下の「全体の収支」）。合計サマリーと各イベントの売上・支出・収支・支払いの状況を表示し、イベント別収支編集へのリンクを提供する。

## URL / ルート

`/admin/finances`

## データ取得フロー

```
マウント時:
    1. api.events.list(false)・api.events.list(true)・api.events.getAllFinances() を並列取得
       （GET /api/events?past=false・?past=true・GET /api/events/finances）
    2. イベントごとに収支を探す → 収支未入力のイベントは null
    3. computeFinances(fin, hasWorkshop) で各イベントの収支を計算
    4. 全イベントの合計を算出しサマリーに表示
```

## computeFinances の仕様

`frontend/src/lib/finance.ts` の `computeFinances` 関数で計算（2026-10-22 に `lib/api.ts` から移した。参加費・資材費・割合・燃費の数値は `lib/constants.ts`）。

| フィールド | 計算式 |
|---|---|
| transport（移動費） | `round((distance × 2 / 10) × gas_price)` |
| totalExpense（支出合計） | `booth_fee + transport + expressway_toll + accommodation + other_expenses` |
| wsSales（WS売上） | `has_workshop ? ws_participants × 1000 : 0` |
| wsCost（WS資材費） | `has_workshop ? ws_participants × 700 : 0` |
| salesShare | `round((sales - wsSales - totalExpense) × 0.2)`（payment_flag 時のみ。マイナスのときもそのまま） |
| wsShare | `round(wsSales × 0.7)`（payment_flag 時のみ） |
| paymentAmount（手伝い支払い金額） | `salesShare + wsShare`（payment_flag 時のみ） |
| net（収支） | `sales - totalExpense - wsCost - paymentAmount`（payment_flag が無いときは paymentAmount は 0） |

2026-10-22 に今のコードに合わせて直した（WS資材費を追加し、salesShare を 0 で止めない形にした）。

## 各行の表示

- 収支データあり: 売上・支出合計・収支を金額表示
- 収支データなし: 各列をグレー「-」で表示
- 「編集」ボタン: `/admin/events/{id}/finances` へ遷移

## 読み込みに失敗したとき（2026-10-22 追加）

見出し「収支一覧」の下に赤い枠で「収支の読み込みに失敗しました（理由）」と出す。それまでは失敗しても何も出ず、イベントが無いように見えた。（理由）の部分には、ログインの期限切れ・見つからない・入力の誤りなどのわけが入る（[DD-07 エラーハンドリング](../../../02_DD/07_エラーハンドリング.md) の「管理画面の失敗の文言」）

## 表の列（2026-10-22 追記）

今の画面の表の列は イベント・日付・売上・支出・収支・支払対象（手伝いの支払いの対象か: あり / なし）・WS支払（ワークショップ分を手伝いに払ったか: 済 / 未）・編集。上の図は一部の列だけ描いている。関連する集計は [PG-A15 支払い集計](15_HelperPayment.md)・[PG-A16 ワークショップ集計](16_WsSummary.md)。

## 収支合計の内訳（2026-10-23 追加）

合計のカードの下に、収支合計の計算の式を小さく出す。「売上合計 − 支出合計」だけでは収支合計と合わないため、引いている項目を示す。

```
収支合計 = 売上 ◯円 − 支出 ◯円 − WS 資材費 ◯円 − 手伝いへの支払い ◯円
WS 売上は売上に含めて入力するため、別に足していません。手伝いへの支払いは「支払対象: あり」のイベントの分です。
```

- 金額は、収支を入れたイベントの合計（WS 資材費・手伝いへの支払いは `computeFinances` の `wsCost`・`paymentAmount` の合計）
- WS 資材費が 0 円のときは「− WS 資材費」を出さない。手伝いへの支払いが 0 円のときも出さない
- 手伝いへの支払いの合計がマイナス（手伝いのあるイベントが赤字で、手伝いが赤字を分担した）のときは、「＋ 手伝いの赤字の分担 ◯円」として足す
