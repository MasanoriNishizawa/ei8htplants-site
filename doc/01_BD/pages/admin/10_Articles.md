# PG-A10 — 記事管理（admin/Articles）

**URL**: `/admin/articles`  
**レイアウト**: `AdminLayout`（要認証）  
**機能**: FT-14

---

## 画面概要

ジャーナル記事のCRUD管理ページ。一覧と編集モーダルで構成。

---

## 一覧

右上の「+ 記事追加」で新しい記事のモーダルを開く。一覧は公開・非公開をすべて出す（`GET /api/articles?all=true`。2026-10-22 から、この全件の取得はログインが必要）。

| カラム | 内容 |
|---|---|
| 画像 | サムネイル |
| タイトル | |
| タグ | |
| 公開日 | 初めて公開した日（未公開なら空） |
| 状態 | 公開中 / 非公開（押すとすぐ切り替えて保存） |
| 操作 | 編集 / 削除（「「タイトル」を削除しますか？」の確認のあと） |

記事が無いときは「記事がありません。」と出る。

---

## 編集モーダル

| フィールド | 型 | 備考 |
|---|---|---|
| タイトル | テキスト | 必須 |
| 本文・画像 | BlockEditor | heading/text/image ブロック |
| タグ | テキスト + Enter追加 | フィルタリング用 |
| 関連商品（記事から購入できる商品） | 商品ごとのチェックボックス（画像・名前・価格。在庫0は「売り切れ」） | 記事末尾に商品カードとして表示 |
| 公開する | チェックボックス | 印を付けて保存すると公開。初めて公開したときにサーバーが公開日（`published_at`）を自動で入れる |

公開日を手で入れる欄は無い（2026-10-22 に表から削除。それまでは「公開日時（datetime-local）」と書いていた）。モーダルの見出しは「記事追加」または「記事編集」。下に「キャンセル」「保存」。

---

## 特記事項

- `content` は BlockEditor JSON 文字列
- `image_urls` は BlockEditor の image ブロック URL を自動抽出
- 関連商品は記事の `product_ids` 列（商品 ID の一覧）に保存する（2026-10-22 に修正。それまでは中間テーブル `article_product_links` と書いていたが、そのテーブルは無い）
- JournalArticle 公開ページで商品カードを末尾に表示

## 2026-10-23 の変更

- 編集の画面（モーダル）は、**[キャンセル]**・画面の外側・Esc キーのどれで閉じるときも、開いたときから内容を変えていれば「保存していない変更があります。破棄して閉じますか？」と確認する。保存中は閉じない。日本語入力の変換中の Esc では閉じない。関連商品のチェックは、選んだ順番が違うだけなら変更とみなさない
