# PG-A16 — ワークショップ集計（Admin）

## 概要

ワークショップの参加人数と、手伝いの人に払うワークショップ分の金額（1人700円）を年度ごとにまとめ、払ったかどうかを記録する画面（サイドメニューの「収支」の下の「ワークショップ集計」）。

## URL / ルート

`/admin/ws-summary`（サイドメニューから開く。ログインが必要）

## 実装ファイル

`frontend/src/pages/admin/AdminWsSummary.tsx`

## 使用機能（FT紐付け）

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-01](../../features/01_認証.md) | 認証 | AdminLayout による認証ガード |
| [FT-02](../../features/02_APIクライアント.md) | APIクライアント | API の呼び出し |
| FT-23（機能設計書は未作成） | 収支 | ワークショップ分の支払いの集計と記録 |

## 使う API

| 操作 | API | ログイン |
|---|---|---|
| 過去のイベントの一覧 | `GET /api/events?past=true` | 不要 |
| 全イベントの収支 | `GET /api/events/finances` | 必要 |
| 支払い済みの保存 | `PUT /api/events/{id}/finances` | 必要 |

## 表示内容と操作

| 項目 | 内容 |
|---|---|
| 対象のイベント | 過去のイベント（終了したイベント）のうち、「ワークショップあり」で、収支の WS 参加人数（`ws_participants`）が1人以上のもの |
| 年度 | 開始日が4月〜12月ならその年、1月〜3月なら前の年の年度。新しい年度から並ぶ |
| 件数 | 収支に入れた WS 参加人数 |
| 金額 | 件数 × 700円 |
| 支払い済み | 印を付ける・外すと、すぐにそのイベントの収支（`ws_payment_done`）に保存する。保存中はその行の印を押せない。支払い済みの行は薄い緑になる |
| 合計の行 | 件数と金額の合計、支払い済みの金額の合計 |

- 対象のイベントが無いときは「ワークショップのデータがありません。」と出る
- 読み込みに失敗したときは、説明文の下に赤い枠で「データの読み込みに失敗しました（理由）」と出し、「ワークショップのデータがありません。」は出さない（2026-10-22 追加。それまでは失敗しても何も出ず、データが無いように見えた）
- 「支払い済み」のチェックの保存に失敗したときは、赤い枠で「支払い状況の保存に失敗しました（理由）」と出し、チェックは元のままにする。保存している間はそのチェックを押せない。（理由）の部分には、ログインの期限切れ・見つからない・入力の誤りなどのわけが入る（[DD-07 エラーハンドリング](../../../02_DD/07_エラーハンドリング.md) の「管理画面の失敗の文言」）
- 支払い済みの印は [PG-A14 全体の収支](11_Finances.md) の「WS支払」の列（済 / 未）にも出る
- 金額の1人700円は、画面の説明文のとおり手伝いの金額として出している。全体の収支の計算でも、ワークショップの参加人数 × 700円を支出（資材費）として引いている（[PG-A14](11_Finances.md)）
