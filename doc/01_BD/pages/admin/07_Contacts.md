# PG-A07 — お問い合わせ管理（Admin）

## 概要

お問い合わせの一覧確認・既読管理・返信を行う管理画面。未読件数バッジとアコーディオン展開で操作性を高める。返信は管理画面の入力画面からメールで送る（2026-10-22 に記述を今の画面に合わせた）。

## URL / ルート

`/admin/contacts`

## 実装ファイル

`frontend/src/pages/admin/Contacts.tsx`

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-01](../../features/01_認証.md) | 認証 | AdminLayout による認証ガード |
| [FT-02](../../features/02_APIクライアント.md) | APIクライアント | `api.contact.list()` / `api.contact.markRead()` / `api.contact.reply()` 呼び出し |

│                                      │

## 返信の入力画面（2026-10-22 追加）

「返信」ボタンを押すと、画面の上に重ねて出る。

```
┌───────────────────────────────────────┐
│ 返信: mail@example.com            [×] │
│ 件名                                  │
│ [Re: ei8ht plants お問い合わせ      ] │
│ 本文                                  │
│ ┌───────────────────────────────────┐ │
│ │ 鈴木 太郎 様                      │ │
│ │                                   │ │
│ │ お問い合わせいただき              │ │
│ │ ありがとうございます。            │ │
│ └───────────────────────────────────┘ │
│                [キャンセル][送信する] │
└───────────────────────────────────────┘
```

- 「送信する」で `POST /api/contacts/{id}/reply` を送る。送れたら入力画面を閉じ、そのお問い合わせを既読にして「{メールアドレス} に返信を送信しました。」を4秒出す
- 送れなかったら「返信の送信に失敗しました」を3秒出す
- 「キャンセル」「×」、入力画面の外側、Esc キーで閉じる（送らない）。件名・本文を開いたときから変えていれば「保存していない変更があります。破棄して閉じますか？」と確認する。送信中は閉じない（2026-10-23 にほかの編集画面とそろえた）
- お問い合わせが1件も無いときは「お問い合わせはありません。」と出る
