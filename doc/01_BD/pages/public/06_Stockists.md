# PG-06 — Stockists

## 概要

取扱店の一覧ページ。エリア別グループ表示と、各店舗が取り扱うブランドのカラーチップを表示する。

## URL / ルート

`/stockists`

## 実装ファイル

`frontend/src/pages/Stockists.tsx`

## 使用機能（FT紐付け）

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-02](../../features/02_APIクライアント.md) | APIクライアント | `api.stockists.list()` 呼び出し |
| [FT-10](../../features/10_取扱店管理.md) | 取扱店管理 | 一覧取得・エリアグループ化・ブランドチップ表示 |

## 画面レイアウト

```
┌─────────────────────────────────┐
│ ページヘッダー（"STOCKISTS"）   │
├─────────────────────────────────┤
│ エリアグループ 1（例: 東京）    │
│  ─────────────────────────────  │
│  店舗A                         │
│  住所テキスト                  │
│  [ei8ht plants] [Habitat Oides] │
│  ─────────────────────────────  │
│  店舗B                         │
│  ...                           │
├─────────────────────────────────┤
│ エリアグループ 2（例: 大阪）    │
│  ...                           │
├─────────────────────────────────┤
│ 卸問い合わせ案内ノート          │
│  「取扱のご相談はお問い合わせ  │
│    フォームより...」            │
└─────────────────────────────────┘
```

## 状態管理

| state | 型 | 説明 |
|---|---|---|
| `stockists` | `Stockist[]` | 取得した取扱店一覧 |
| `loading` | boolean | ローディング中フラグ |

## エリアグルーピング

- `stockists.reduce` で `area`（または `'その他'`）をキーにグループ化
- `Object.entries(byArea)` でエリア別に表示

## ブランドチップ表示

| ブランド | 背景 | 文字 |
|---|---|---|
| ei8ht plants | `#e8f0e8` | `#2d4a2d` |
| Habitat Oides | `#dde4f5` | `#1e3272` |
| HUE | `#f5ead8` | `#6b3c1a` |

- `brands[]` が空の場合はチップを表示しない

## 画面遷移

| 操作 | 遷移先 |
|---|---|
| 店舗名クリック（URLがある場合） | 店舗サイト（外部、新しいタブ） |
| 「お問い合わせフォーム」リンク | `/contact` |
