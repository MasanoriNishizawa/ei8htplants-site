# PG-22 — Chat（AI コンシェルジュ）

**URL**: `/chat`
**レイアウト**: `Layout`
**機能**: FT-24
**実装ファイル**: `frontend/src/pages/Chat.tsx`

---

## 画面の目的

植物の育て方やワークショップ・予約についての質問に、AI が答えるページ。ヘッダーのナビには無く、`/chat` 以外の公開ページの右下に出る「AI Concierge」ボタン（スマホでは「AI」）から開く。2026-10-22 に画面 ID を PG-13 から PG-22 に変えた（PG-13 は予約キャンセルの画面）。

## 使う API

| 操作 | API | ログイン |
|---|---|---|
| 質問を送って返事を受け取る | `POST /api/chat` | 不要 |

## 操作

| 操作 | 動き |
|---|---|
| 入力して Enter・「送信」 | 質問を送る。Shift + Enter は改行。日本語の変換中の Enter では送らない。入力は2,000文字まで |
| 返事を待つ間 | 送信ボタンは押せず、返事待ちの印を出す |

## 返事の代わりに出す案内

| 場面 | 案内 |
|---|---|
| 送る回数の上限（1分間に10回）を超えた | 「メッセージの送信回数が上限に達しました。しばらく経ってからもう一度お試しください。」 |
| 入力の条件に合わない | 「メッセージを送れませんでした。内容を短くするか、ページを開き直してください。」 |
| AI が答えを返さなかった | 「うまくお答えできませんでした。言い方を変えてもう一度お試しください。」 |
| そのほかの失敗 | 「申し訳ありません、エラーが発生しました。しばらく経ってからもう一度お試しください。」 |

- 会話はページを開いている間だけ残る（開き直すと最初のあいさつだけになる）
- 返事の中の URL はリンクになる（新しいタブで開く）
- 画面の言語（日本語・英語）に合わせて、あいさつ・案内の言葉が変わる
- 質問と返事は管理画面の「チャット履歴」（[PG-A22](../admin/22_ChatLogs.md)）で見られる
- 仕組みの詳細は [FT-24 AIチャット](../../features/13_AIチャット.md)
