# PG-02 — Events

## 概要

開催予定イベントの一覧ページ。全イベントをグリッドレイアウトで表示し、各カードでイベント詳細・予約導線を提供する。

## URL / ルート

`/events`

## 実装ファイル

`frontend/src/pages/Events.tsx`

## 使用機能（FT紐付け）

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-02](../../features/02_APIクライアント.md) | APIクライアント | `api.events.list(false)` 呼び出し |
| [FT-03](../../features/03_イベント表示.md) | イベント表示 | `EventCard` で各イベントを表示 |

## 画面レイアウト

```
┌─────────────────────────────────┐
│ ページヘッダー                  │
│  ・"EVENTS" 見出し              │
├─────────────────────────────────┤
│ イベントグリッド（.events-grid）│
│  ┌──────┐ ┌──────┐ ┌──────┐   │
│  │ Card │ │ Card │ │ Card │   │
│  └──────┘ └──────┘ └──────┘   │
│  ・ローディング中は「読み込み中」│
│  ・0件の場合は「予定はありません」│
└─────────────────────────────────┘
```

## データ取得

| データ | API |
|---|---|
| イベント一覧 | `api.events.list(false)`（開催予定のみ） |

- マウント時に1回取得
- `setLoading(true/false)` でローディング制御

## 状態管理

| state | 型 | 説明 |
|---|---|---|
| `events` | `Event[]` | 取得したイベント一覧 |
| `loading` | boolean | ローディング中フラグ |

## CSS

- グリッドレイアウト：`.events-grid`（`index.css` に定義）
- レスポンシブ：モバイルで1カラム、デスクトップで複数カラム

## 画面遷移

| 操作 | 遷移先 |
|---|---|
| 予約ボタンクリック（EventCard内） | `/reserve?event_id={id}` |
| 公式URLクリック | 外部サイト（新しいタブ） |
