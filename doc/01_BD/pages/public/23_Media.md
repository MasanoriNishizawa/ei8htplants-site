# PG-23 — Media（出演情報）

**URL**: `/official/media`
**レイアウト**: `Layout`
**機能**: —
**実装ファイル**: `frontend/src/pages/Media.tsx`

---

## 画面の目的

テレビ・動画などへの出演情報を、YouTube の動画のカードで並べるページ。ヘッダーのナビの「Media」から開く。中身は管理画面の「メディア管理」（[PG-A19](../admin/19_Media.md)）で登録する。

## 使う API

| 操作 | API | ログイン |
|---|---|---|
| 出演情報の一覧 | `GET /api/media-appearances` | 不要 |

## 表示内容

- 公開日の新しい順に並ぶ。カードは画面の幅に合わせて並ぶ数が変わる（1枚の幅はおよそ 320px 以上）
- カード: YouTube のサムネイルと再生の印・公開日（年と月。日本語なら「2026年10月」）・タイトル・説明
- カードを押すと、新しいタブで YouTube の動画を開く
- 1件も無いときは「まだ登録されていません。」と出る。読み込みに通信の失敗などで失敗したときは「読み込めませんでした。通信状況をご確認のうえ、もう一度お試しください。」と「再読み込み」ボタンを出す
- 画面の言語に合わせて見出し（出演情報 / Appearances）が変わる
