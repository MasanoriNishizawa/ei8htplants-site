# PG-13 — CancelReservation

## 概要

ワークショップ予約のキャンセルページ。確定メールに記載されたキャンセルID（8桁数字）を入力して予約をキャンセルする。認証不要。

## URL / ルート

`/cancel`  
`/cancel?id={cancel_token}` — メールのリンクからアクセスした場合、IDを自動入力

## 実装ファイル

`frontend/src/pages/CancelReservation.tsx`

## 画面レイアウト

```
┌─────────────────────────────────┐
│ ページヘッダー                  │
│  ・ラベル「Habitat Oides」      │
```

## 状態遷移

| status | 表示内容 |
|---|---|
| `idle` | 初期状態（フォーム表示） |
| `loading` | ボタン disabled、「処理中...」 |
| `done` | キャンセル完了メッセージ |
| `already` | 「すでにキャンセル済み」（400） |
| `notfound` | 「IDが見つかりません」（404） |
| `error` | 「エラーが発生しました」（その他） |

## API

`api.reserve.cancel(token)` → `POST /api/reserve/cancel { token }`

- `200`: キャンセル成功
- `400`: すでにキャンセル済み
- `404`: トークンが存在しない

## キャンセルトークン仕様

- 8桁のランダム数字（`secrets.choice(string.digits)` × 8）
- 管理者が予約を `confirmed` に変更した時点で生成・保存
- 同トークンが過去イベントで使われていた場合、最新の未キャンセル予約を対象にする
- トークンは一度生成されたら変わらない（再確定でも新トークンを発行しない）
