# PG-17 — OrderComplete（ご注文完了）

**URL**: `/order/complete`
**レイアウト**: `StoreLayout`
**機能**: FT-13
**実装ファイル**: `frontend/src/pages/OrderComplete.tsx`

---

## 画面の目的

注文と決済が終わったあとに出すお礼のページ。購入手続き（[PG-16](16_Checkout.md)）から移るときに、注文 ID・名前・メールアドレスを受け取って表示する。検索結果には出さない（noindex）。

## 使う API

| 操作 | API | ログイン |
|---|---|---|
| なし（購入手続きの画面から受け取った情報だけで表示する） | — | — |

## 画面レイアウト（PC）

```
┌──────────────────────────────────────────────────────────────┐
│             {名前} 様、ご注文ありがとうございます            │
│                 注文番号                                     │
│                 1A2B3C4D                                     │
│     ご注文を受け付けました。                                 │
│     mail@example.com に確認メールをお送りします。            │
│     発送が完了しましたら、改めてメールでお知らせいたします。 │
│     ご不明な点は お問い合わせフォーム よりご連絡ください。   │
│          [ショップに戻る]  [トップへ]                        │
└──────────────────────────────────────────────────────────────┘
```


## 表示内容

| 部分 | 内容 |
|---|---|
| 見出し | 名前があれば「{名前} 様、ご注文ありがとうございます」、無ければ「ご注文ありがとうございます」 |
| 注文番号 | 注文 ID の先頭8文字を大文字にしたもの（確認メールの注文番号と同じ）。注文 ID が無ければ出さない |
| 確認メールの案内 | メールアドレスがあれば「{メールアドレス} に確認メールをお送りします。」、無ければ「ご登録いただいたメールアドレスに確認メールをお送りします。」 |
| ボタン | 「ショップに戻る」（`/shop`）・「トップへ」（`/`） |

- ページを開き直すと、受け取った情報が消えるため、注文番号と名前は出なくなる（注文そのものには影響しない）
