# PG-19 — JournalArticle（記事のページ）

**URL**: `/official/journal/:id`
**レイアウト**: `StoreLayout`
**機能**: FT-14, FT-13
**実装ファイル**: `frontend/src/pages/JournalArticle.tsx`

---

## 画面の目的

ジャーナルの記事1つを読むページ。記事で紹介した商品（関連商品）を最後に並べ、そこからカートに入れられる。

## 使う API

| 操作 | API | ログイン |
|---|---|---|
| 記事を1件読む | `GET /api/articles/{id}` | 不要（2026-10-22 から、ログインしていないときは公開中の記事だけ返す） |
| 関連商品を探す | `GET /api/products`（公開中の商品の一覧から、記事の関連商品を選ぶ） | 不要 |

## 表示内容

| 部分 | 内容 |
|---|---|
| 一番上の画像 | 本文の最初の画像。無ければ記事の1枚目の画像。画像が無いときは文字だけ |
| 日付 | 公開日（英語の書き方。例: October 1, 2026） |
| 本文 | 見出し・文章・画像のブロックを順に出す。本文が空で画像が2枚以上なら、2枚目からを2列で並べる |
| 記事で紹介した商品 | 管理画面で選んだ関連商品のうち公開中のもの。画像・名前・価格と「カートに入れる」（在庫0なら「売り切れ」） |
| カートのボタン | カートに1点以上あるとき右下に「カート (数)」。押すと購入手続き |

- 記事が無いときは「記事が見つかりません。」と出る。読み込みに通信の失敗などで失敗したときは「読み込めませんでした。通信状況をご確認のうえ、もう一度お試しください。」と「再読み込み」ボタンを出す
- 商品の画像・名前を押すと商品のページ（[PG-15](15_ShopProduct.md)）へ移る
