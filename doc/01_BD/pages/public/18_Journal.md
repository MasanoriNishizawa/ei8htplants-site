# PG-18 — Journal（記事一覧）

**URL**: `/journal`  
**レイアウト**: `StoreLayout`  
**機能**: FT-14

---

## 画面概要

ジャーナル記事の一覧ページ。雑誌スタイルのレイアウト。記事は植物と暮らしに関するコラムで、末尾に関連商品へのリンクを持つコンテンツマーケティング記事。

---

## セクション構成

### 1. マストヘッド

- "Journal" — 大きなイタリック体セリフフォント（Cormorant Garamond, clamp(48px, 7vw, 84px)）
- ラベル: "ei8ht plants"

### 2. タグフィルタータブ

- 全記事のタグを集計し "All" + 各タグをタブ形式で表示
- アクティブタグをアンダーライン表示
- タグが存在しない場合は非表示

### 3. 記事リスト

**フィーチャー記事（先頭1件）**
- 大きな画像（16/9 → 幅広レイアウト時は 4/3）
- タグピル・タイトル・本文抜粋・"Read Article →" リンク
- 2カラムグリッド（`journal-featured-grid` CSS class）

**残り記事グリッド**
- 1 → 2 → 3カラム（`journal-grid` CSS class）
- カード: 画像（3/2）+ タグピル + 日付 + タイトル + 抜粋 + "Read →"

---

## データ取得

`GET /api/articles` — published_at の降順
