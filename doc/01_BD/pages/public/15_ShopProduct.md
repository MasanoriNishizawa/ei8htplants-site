# PG-15 — ShopProduct（商品の詳しいページ）

**URL**: `/shop/:id`
**レイアウト**: `StoreLayout`
**機能**: FT-13
**実装ファイル**: `frontend/src/pages/ShopProduct.tsx`

---

## 画面の目的

ショップの商品1つを詳しく見せ、カートに入れる・すぐに買うためのページ。ショップの一覧（[PG-14](14_Shop.md)）や記事の関連商品から開く。

## 使う API

| 操作 | API | ログイン |
|---|---|---|
| 商品を1件読む | `GET /api/products/{id}` | 不要（2026-10-22 から、ログインしていないときは公開中の商品だけ返す） |

## 表示内容

| 部分 | 内容 |
|---|---|
| メイン画像 | 本文の最初の画像。本文に画像が無ければ商品の1枚目の画像 |
| 本文 | 管理画面のブロックエディタで作った見出し・文章・画像を順に出す。本文が空で画像が2枚以上あるときは、2枚目からを2列で並べる |
| 在庫 | 「残り N 点」（カートに入れている数があれば「（カート: N）」も）。在庫が0なら「現在売り切れです」でボタンは出ない |
| カートのボタン | カートに1点以上あるとき、右下に「カート (数)」を出す。押すと購入手続き（[PG-16](16_Checkout.md)） |

## 操作

| 操作 | 動き |
|---|---|
| 数量の −・+ | 1 から「在庫 − カートに入れている数」まで |
| カートに入れる | カートに足す。1.6秒だけ「カートに追加しました」になる |
| すぐに購入する | カートに足して購入手続き（`/checkout`）へ移る |
| シェアボタン | この商品のページの URL を SNS などで共有する |

- 商品が無いときは「商品が見つかりません。」と出る。読み込みに通信の失敗などで失敗したときは「読み込めませんでした。通信状況をご確認のうえ、もう一度お試しください。」と「再読み込み」ボタンを出す
- カートの中身はこのブラウザに保存する（サーバーには購入手続きのときに初めて送る）
- ページを読み直したときは、保存したカートを1行ずつ確かめ、数量や商品の情報が壊れている行だけを捨てる（`lib/cartContext.ts` の `loadCart`）。画像が登録されていない商品（画像の一覧が空・未設定）は壊れた行とみなさず、画像なしのままカートに残す（2026-10-23 修正。それまでは画像の無い商品を入れて読み直すとカートから消えていた）
