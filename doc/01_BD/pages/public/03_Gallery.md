# PG-03 — Gallery

## 概要

ギャラリー画像の一覧ページ。ブランド別フィルタータブ、正方形グリッド、クリックで拡大表示するライトボックスを提供する。

## URL / ルート

`/official/gallery`

## 実装ファイル

`frontend/src/pages/Gallery.tsx`

## 使用機能（FT紐付け）

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-02](../../features/02_APIクライアント.md) | APIクライアント | `api.gallery.list(brand?)` 呼び出し |
| [FT-04](../../features/04_ギャラリー.md) | ギャラリー | ブランドフィルタータブ・グリッド・ライトボックス |

## 画面レイアウト

```
┌─────────────────────────────────────────────┐
│ ページヘッダー（"GALLERY"）                 │
│  ・薄い灰色の背景 #f5f5f7                   │
├─────────────────────────────────────────────┤
│ ブランドのタブ（文字は大文字で出る）        │
│  ALL / EI8HT PLANTS / HABITAT OIDES /       │
│  HUE BY EI8HT PLANTS（実際は1行に並ぶ）     │
├─────────────────────────────────────────────┤
│ ギャラリーグリッド                          │
│  ┌──┐┌──┐┌──┐┌──┐                           │
│  └──┘└──┘└──┘└──┘                           │
│  （押すと拡大表示）                         │
├─────────────────────────────────────────────┤
│ 拡大表示（ImageLightbox）                   │
│  ・写真を押すと開く                         │
│  ・背景 / × / Esc で閉じる                  │
└─────────────────────────────────────────────┘
```

## 状態管理

| state | 型 | 初期値 | 説明 |
|---|---|---|---|
| `activeBrand` | `string \| null` | `null` | 選択中のタブのブランドの正式名（null は All） |
| `lightboxIdx` | `number \| null` | `null` | 拡大表示している写真の位置（null は閉じている） |
| `data`・`loading`・`error` | `useApi` の戻り値 | — | 写真の一覧・読み込み中か・失敗の内容（2026-10-22 に `useApi` にまとめた） |

- HUE のタブは、サーバーへ「HUE」で問い合わせる（管理画面が「HUE」で保存するため。2026-10-22 変更。それまでは HUE のタブに写真が出なかった）。詳しくは [FT-04](../../features/04_ギャラリー.md) の「ブランドフィルタータブ」
