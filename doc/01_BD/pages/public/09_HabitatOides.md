# PG-09 — Habitat Oides

## 概要

Habitat Oides 専用ドメインの独立ホームページ。ei8ht plants の共通テーマは使わず、風景・素材・植物をテーマにした独自の文章、写真、配色、レイアウトでブランドを紹介する。

## URL / ルート

`https://habitatoides.com/`（以前の `https://ei8htplants.com/habitatoides` は301転送）

## 実装ファイル

`frontend/src/pages/brands/HabitatOides.tsx`

動きの演出の部品（2026-11-02 追加）: `frontend/src/pages/brands/habitatMotion/`（スプラッシュ・スライダー・サイン・画像の出方・縦書きの見出し・動くオブジェクトと、その CSS `habitatMotion.css`）。画像の枠の一覧: `frontend/src/lib/habitatMotionSlots.ts`

## 使用機能（FT紐付け）

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-27](../../features/16_ブランド別ドメインとサイト表示.md) | ブランド別ドメインとサイト表示 | 独立ホーム、専用ヘッダー・フッター、ブランド切替 |

ブランドのテーマは「仕立てる」。表示言語は保存済みの利用者設定を優先し、設定がなければブラウザー言語に従う（日本語設定なら日本語、それ以外なら英語）。ヘッダーの言語切替でいつでも変更できる。日本語表示では「植物の景色を仕立てる」を軸に、自然の景色を一鉢に仕立てること、植物・石・砂・土の組み合わせ、自生地の風景を表現する考え方を紹介する。ヒーローは「自然の景色を、一鉢に仕立てる。」、世界観の見出しは「自然を見つめ、景色を仕立てる。」。素材紹介では植物・石と砂・鉢を説明し、ワークショップでは「手を動かして、景色を仕立てる。」、コラボレーションでは作り手とともに景色を仕立てる物語を伝える。

専用ヘッダーはロゴ、サイト内ナビ、ei8htplants.com の公式サイトへのリンク、他ブランドへの切替リンク、言語切替を表示する。日本語ナビは「世界観」「ワークショップ」「コラボレーション」、英語表示では Concept / Workshop / Collaboration。公式サイトへのリンクは `https://ei8htplants.com/official`。フッターにもブランド切替リンクがあり、他ブランドへは新しいタブで移動する。

| ヘッダー項目 | 実際のリンク先 | 動作 |
|---|---|---|
| 世界観 / Concept | `/#world` | トップページの `id="world"`（私たちの考え方 / Our Point of View）へ移動 |
| ワークショップ / Workshop | `/#workshop` | トップページのワークショップ紹介へ移動 |
| コラボレーション / Collaboration | `/collaborations` | Habitat Oides のコラボレーション一覧へ移動 |

## 動きの演出（2026-11-02 追加）

参考サイト（`https://www.garni.co.jp/`）と同じ種類の動きを入れた。動きの部分のスタイルは `frontend/src/pages/brands/habitatMotion/habitatMotion.css`、部品は同じフォルダの `Habitat〜.tsx` にある（このページを開いたときだけ読み込む）。

| 演出 | 場所 | 動き |
|---|---|---|
| スプラッシュ（最初の演出） | 画面全体 | 白い画面の中央にロゴと「植物の景色を仕立てる」（英語表示では SHAPE A LIVING LANDSCAPE）を出す。ページの読み込みを待ち（最長3秒。それより早く読み込みが終われば、そこで始める）、ロゴが下から上がって上へ抜け、白い幕が上へ縮んで約1.8秒で消える。そのあと本文がふわっと浮かび上がる。**ブラウザのタブごとに1回だけ**（同じタブで開き直しても、もう出さない） |
| 一番上の画像のスライダー | ヒーロー（一番上） | 画像を重ねて置き、フェード（0.4秒）で切り替える。**3秒ごと**に次の画像へ進み、最後の次は最初に戻る。画面の高さいっぱい（ヘッダーの下から画面の下まで）に広げる |
| スライダーの操作 | ヒーローの右下 | 「Prev 01 / 05 Next」。Prev・Next で前後の画像へ移る（押すと、そこから3秒を数え直す）。スマホの幅（767px 以下）では矢印を隠して番号だけを出す |
| スライダーを止める | ヒーロー | マウスがヒーローの上にある間と、キーボードの操作でヒーローの中のボタンなどにフォーカスがある間は、自動の切り替えを止める（離れると再開する） |
| 右下のサイン | 画面の右下に固定 | トップページを見ている間、ブランドのサインの画像を右下に固定して出す。押しても何も起きない（下のリンクなどの邪魔をしない）。画像はプロジェクト内のファイル `sign.svg` だけを使い、管理画面では差し替えない（下の「右下のサインを変えるとき」）。**ファイルがない（読み込めない）ときは何も出さない** |

| 画像の出方（明るさ） | ワークショップの写真 | 画面に入ったとき、白く飛んだ明るさから元の明るさへ戻りながら現れる（1回だけ） |

以前ヒーローの左下に出していた「01 / 03」の文字はなくし、スライダーの番号に置き換えた。

### スライダーの画像の枚数による違い

| 画像の枚数 | 動き |
|---|---|
| 0枚 | ヒーローの背景に、薄い点線の空の枠を出す。番号・操作は出さない |
| 1枚 | その1枚を出すだけ。自動では切り替えず、番号・操作も出さない |
| 2〜5枚 | 3秒ごとに自動で切り替え、右下に番号と操作を出す |

画像がある枠だけを、`habitat-hero-01` から順に並べる（例: 01 と 03 だけに画像があれば「01 / 02」の2枚になる）。

### 「動きを減らす」設定のとき

パソコン・スマホの設定で「視差効果を減らす」「アニメーションを減らす」などを有効にしている人には、次のようにする。

- スプラッシュを出さない
- スライダーは自動で切り替えず、フェードもしない（2枚以上あれば、Prev・Next で手で切り替えられる）
- 画像の出方の演出をせず、最初から表示した状態にする
- オブジェクトをスクロールに合わせて動かさない

### 公式サイトの中で表示されたとき

本番の `ei8htplants.com/habitatoides` は、サーバーが `https://habitatoides.com/` へ転送するので、ふつうはこの表示にはならない。サーバーの転送を通らずに公式サイトの枠の中（`/habitatoides`）で開いたとき（開発中の環境など）は、右下にチャットのボタンがあるため、重ならないように次の3つを上に上げる。habitatoides.com で見たときは上げない。

| 要素 | habitatoides.com | 公式サイトの中 |
|---|---|---|
| スライダーの操作「Prev 01 / 05 Next」 | 下から 24px | 下から 96px |
| 右下のサイン | 下から画面の高さの 2% | 下から 96px |
| ヒーローの右端の縦書きの小さな文字（「植物 · 石 · 土」） | 下から 96px | 下から 150px |

## 画像の枠と、出る画像の決まり方（2026-11-02 追加）

動きの演出に使う画像は、11個の枠に分けて管理する（一番上の画像5枠・動くオブジェクト6枠）。右下のサインは枠に含めない（2026-11-02 変更。下の「右下のサインを変えるとき」）。枠の一覧（名前・推奨サイズ）は [PG-A23 Habitat Oides 画像](../admin/23_HabitatImages.md) を参照。

| 枠 | キー | 出る場所 |
|---|---|---|
| 一番上の画像 01〜05 | `habitat-hero-01`〜`habitat-hero-05` | スライダー |
| オブジェクト 01〜06 | `habitat-object-01`〜`habitat-object-06` | 「景色をつくる素材」の動くオブジェクト |

枠ごとに、次の順で最初に見つかったものを出す。

1. 管理画面（[PG-A23 Habitat Oides 画像](../admin/23_HabitatImages.md) または [PG-A24 ページ画像の編集](../admin/24_PageEditor.md)）で保存した画像
2. プロジェクト内に置いた画像（`frontend/src/lib/habitatMotionSlots.ts` の各枠の `localSrc` に書いたパス）。2026-11-02 時点では「一番上の画像 01」だけに、今までのヒーローの写真 `/img/habitatOides/habitat_oides_hero.jpg` を入れている
3. どちらもないとき: 大きさだけ確保した**薄い点線の枠**（空の枠）を出す。画像を入れる場所を確保しておくため、公開ページでもあえて出している。文字は出さない

ページを開くと、11枠の保存済みの画像を1回でまとめて読む（`GET /api/site-assets?prefix=habitat-`）。読み込めなかったときも止めずに、2 → 3 の順で出す。

「私たちの考え方」とワークショップの写真（`/img/habitatOides/habitat_oides_workshop_main.jpg`）は枠ではなく、今までどおり固定の写真。

### プロジェクト内に画像を置く手順

管理画面からではなく、プロジェクトのファイルとして画像を置くときの手順（開発者向け）。

1. 画像を次のフォルダに、決まったファイル名で置く（`frontend/public` の下に置いたファイルは、公開サイトでは `/img/…` の URL になる）

   | 枠 | 置く場所とファイル名 |
   |---|---|
   | 一番上の画像 | `frontend/public/img/habitatOides/motion/hero/hero-01.jpg`〜`hero-05.jpg` |
   | 動くオブジェクト | `frontend/public/img/habitatOides/motion/objects/object-01.png`〜`object-06.png`（背景を透過した PNG） |

2. `frontend/src/lib/habitatMotionSlots.ts` の `HABITAT_MOTION_SLOTS` の、その枠の `localSrc` に公開 URL を書く（例: `localSrc: '/img/habitatOides/motion/hero/hero-02.jpg'`）。まだ画像がない枠は `null` のまま
3. 拡張子を変えたとき（jpg → webp など）は、`localSrc` のパスも合わせて書き換える
4. フロントエンドをビルドして公開する。管理画面で画像を保存していない枠に、その画像が出る（管理画面で保存した画像のほうが優先）

- 2つのフォルダ（`hero`・`objects`）は 2026-11-02 時点では空（フォルダを残すための空のファイル `.gitkeep` だけ）
- `/img/` の下の画像は、見る人のブラウザなどに長く保存される設定（[DD-04](../../../02_DD/04_バックエンドロジック.md) の「12. SPA フォールバック」のキャッシュ規則）。同じファイル名のまま中身だけ差し替えると、すぐには新しい画像に変わらないことがあるので、差し替えるときはファイル名を変えて `localSrc` も書き換えるとよい

### 右下のサインを変えるとき

右下のサインは変えることがないため、管理画面（[PG-A23](../admin/23_HabitatImages.md)・[PG-A24](../admin/24_PageEditor.md)）には出さず、プロジェクト内のファイルだけで出す（2026-11-02 変更）。変えるときの手順（開発者向け）。

1. 背景を透過した SVG の画像を、ファイル名 `sign.svg` で `frontend/public/img/habitatOides/motion/sign/` に置く（公開サイトでは `/img/habitatOides/motion/sign/sign.svg`。このパスは `frontend/src/lib/habitatMotionSlots.ts` の `HABITAT_SIGN_SRC` に決めてあるので、コードを書き換える必要はない）
2. フロントエンドをビルドして公開する

- ファイルがない、または読み込めないときは、サインは何も出さない（空の枠も出さない）
- 2026-11-02 時点では、`sign` のフォルダは空（`.gitkeep` だけ）なので、サインは出ていない
- 出る位置（右下。公式サイトの中では下から 96px など）は、上の「公式サイトの中で表示されたとき」のとおりで、変えていない
- 以前は管理画面の枠 `habitat-sign` でも差し替えられたが、今は使えない。データベースに以前保存した値が残っていても、表示には使わない

#### サインが画面に出るまでの時間（2026-11-02 追加）

公開サイトでは、`/img/…` の画像を見る人のブラウザや CDN（配信を速くするための中継サーバー）に保存させて、表示を速くしている。サインの出方は、初めて置くときと入れ替えるときで違う。

- **初めて `sign.svg` を置くとき**: ファイルがない間の「見つからない」（404）という応答は保存させないので、デプロイが終わればすぐに出る
- **すでに置いてある `sign.svg` を、同じ名前のまま別の画像に入れ替えるとき**: 見つかった画像は長く保存させるので、見る人の画面では、しばらく古いサインが出ることがある（ブラウザで最大1日、CDN ではさらに長く残ることがある）
- **すぐに入れ替えたいとき**: ファイル名を変えて置き（例: `sign-2.svg`）、`frontend/src/lib/habitatMotionSlots.ts` の `HABITAT_SIGN_SRC` も新しいファイル名に書き換えてから、フロントエンドをビルドして公開する。URL が変わるので、保存されていた古いサインは使われない

## 管理画面「ページ画像の編集」のプレビューでの表示（2026-11-02 追加）

[PG-A24 ページ画像の編集](../admin/24_PageEditor.md) のプレビューの中では、このページを「編集モード」で出す。

- 動き（スプラッシュ・画像の出方・オブジェクトの動き・スライダーの自動の切り替え）をすべて止める
- スライダーには、画像のない枠も含めた5枠を並べる。Prev・Next で行き来でき、画像のない枠は空の枠を出す
- サインには選ぶための枠を付けない（差し替えの対象ではないため）。`sign.svg` があれば公開ページと同じように出し、なければ何も出さない
- 画像には、押すと枠を選べる透明な枠を重ねる
