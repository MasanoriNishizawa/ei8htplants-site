**画面ではない URL（2026-10-21 追加）**

検索エンジン向けのファイルをサーバーが返す。画面はない。

| URL | 内容 |
|---|---|
| `/robots.txt` | 検索エンジンへの案内。管理画面（`/admin`）・予約キャンセル（`/cancel`）・購入手続き（`/checkout`）・注文完了（`/order`）は読まないよう伝える。最後に `sitemap.xml` の場所を書く |
| `/sitemap.xml` | 検索エンジンに知らせる公開ページの一覧（固定ページ・イベント・公開中の記事・公開中の商品） |

詳しくは [FT-26 検索エンジン・SNS 向けの情報](features/15_検索エンジン・SNS向け情報.md) を参照。

## 2. ユーザージャーニー（主要フロー）

### イベント確認 → ワークショップ予約

```
Home
  └─ "次のイベント" カード表示
        └─ [予約] ボタン / /events への導線
              ↓
Events (/events)
  └─ イベントカード確認（場所・日時・画像）
        └─ [予約する] ボタン
              ↓
Reserve (/reserve?event_id=イベントのID)
  └─ 予約フォーム入力（名前・メール・参加人数）
        └─ 送信 → 完了メッセージ
```

```

        └─ "View all collaborations →" リンク
              ↓

  └─ コラボ記事一覧（画像/動画・説明）
```

```

  └─ Header の "Contact" リンク
        ↓

  └─ フォーム入力 → 送信 → 完了メッセージ表示
```

## 4. レイアウト構造

### ブランドサイト（Layout.tsx）

```
┌────────────────────────────────────────┐
│ Header（固定, height: 60px）           │
│  [logo] [nav] [SHOP ボタン] [☰]       │
├────────────────────────────────────────┤
│  main.site-main  padding-top: 60px     │
│  <Outlet />                            │
├────────────────────────────────────────┤
│ Footer                                 │
└────────────────────────────────────────┘
```

- 言語の切り替えボタン（日本語表示では「EN」、英語表示では「JA」）は、PC ではナビの右端、スマホでは「☰」で開くメニューのいちばん下（「Shop」の下）にある。押してもメニューは閉じない（2026-10-22 にスマホのメニューへ追加。それまでスマホでは言語を切り替えられなかった）
- スマホのメニューやブランドの一覧は、Esc キーでも閉じる。メニューを開いている間は後ろのページがスクロールしない
- スマホのメニューを閉じる **×** は、メニューの中の右上（ヘッダーの開くボタンと同じ位置）にある。メニューを開くと × にフォーカスが移り、Tab キーではメニューの中だけを順に回る。× ・メニューの後ろの半透明の幕・Esc のどれでも閉じ、閉じるとフォーカスはヘッダーのメニューボタンに戻る。メニューのリンクを押して移ったあとも、フォーカスはメニューボタンに戻る（2026-10-23 変更）
- 開いている間、メニューは「メニュー」という名前のダイアログとして読み上げられる（`role="dialog"`・`aria-modal`）。後ろのページ（ヘッダーのバーを含む）は操作・読み上げの対象から外す（`inert`）
- メニューを開いたまま画面を PC の幅（769px 以上）に広げると、メニューは自動で閉じる

### ストア（StoreLayout.tsx）

```
┌────────────────────────────────────────────────────┐
│ StoreHeader（固定, height: 56px）                  │
│  [logo] [Shop] [Journal]  [Official Site] [Cart N] │
├────────────────────────────────────────────────────┤
│  main  padding-top: 56px                           │
│  <Outlet />                                        │
├────────────────────────────────────────────────────┤
│ Footer                                             │
└────────────────────────────────────────────────────┘
```

- ショップのヘッダーの右側は「Official Site」（ブランドサイトのトップへ）・言語の切り替え（日本語表示では「EN」、英語表示では「JA」。2026-10-23 追加）・カート。ロゴは縮めない。画面の幅が 480px 以下のときは「Official Site」を隠す（ロゴからもトップへ戻れる）

### 管理画面（AdminLayout.tsx）

```
PC: aside(200px。画面の高さ。項目が収まらないときはメニューの中だけ縦にスクロール) + main(flex:1)
モバイル: ハンバーガー → aside が fixed overlay ドロワーで展開

サイドバー項目: ダッシュボード / 分析 ↗ / イベント / ギャラリー / 取扱店
              / WS予約 / コラボレーション / お問い合わせ
              / 商品管理 / 注文管理 / 記事管理
              / 収支（全体の収支・支払い集計・ワークショップ集計）
              / 販売価格計算 / 鉢作家管理 / メディア管理
              / 設計書 / チャットQ&A / チャット履歴
```

**「分析 ↗」（2026-10-17 追加）**

- 「ダッシュボード」のすぐ下にある。押すと、分析ダッシュボード（`https://ei8htplants-analytics.streamlit.app`）が**新しいタブ**で開く。管理画面のタブはそのまま残る
- 管理画面の中のページではないので、押しても選択中（背景が濃い色）の見た目にはならない
- 文字の横の「↗」は別のタブで開く目印。読み上げソフトには「分析 （新しいタブで開きます）」と伝わる
- 開いた先では、管理画面と同じメールアドレス・パスワードでもう一度ログインする（管理画面のログイン状態は引き継がない）
- 分析ダッシュボードは Streamlit Community Cloud（無料の公開サービス）で動いていて、しばらく使われないと休止する。休止中に開くと起動を待つ必要があり、起こすためのボタン（「Yes, get this app back up!」など）が出たときは押す（2026-10-17 に Render から移した）
- 分析ダッシュボードの中身は [FT-25 分析ダッシュボード](features/14_分析ダッシュボード.md) を参照

## 5. ルーティング定義（App.tsx）

**画面ごとの読み込み（2026-10-21 追加）**: トップページ（`Home`）とレイアウト（`Layout`・`StoreLayout`）は最初に読み込む。それ以外のページ（管理画面の `AdminLayout` と全ページを含む）は、そのページを開いたときに別のファイルとして読み込む。読み込み中は、ヘッダー・フッター・サイドメニューを残したまま、中身の部分にだけ「読み込み中...」と出す。読み込みに失敗したときは「ページを読み込めませんでした。再読み込みしてください。」と「再読み込み」ボタンを出す（詳しくは [DD-03 フロントエンドロジック](../02_DD/03_フロントエンドロジック.md) の「画面ごとの読み込み」）。

**サーバーが返すときのページ情報（2026-10-21 追加）**: どのパスでも、サーバーはページのタイトル・説明・SNS 用の情報を入れた `index.html` を返す。検索結果に出さないパス（`/admin`・`/cancel`・`/checkout`・`/order` 以下、存在しないページ）には noindex（検索結果に出さない印）を入れる（[FT-26](features/15_検索エンジン・SNS向け情報.md)）。
