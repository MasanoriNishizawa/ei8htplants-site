## 2. ユーザージャーニー（主要フロー）

### イベント確認 → ワークショップ予約

```
Home
  └─ "次のイベント" カード表示
        └─ [予約] ボタン / /events への導線
              ↓
Events (/events)
  └─ イベントカード確認（場所・日時・画像）
        └─ [予約する] ボタン
              ↓
Reserve (/reserve?event_id=<uuid>)
  └─ 予約フォーム入力（名前・メール・参加人数）
        └─ 送信 → 完了メッセージ
```

### ブランドページ → コラボレーション確認

```
HabitatOides (/habitatoides)
  └─ Collaboration セクション
        └─ "View all collaborations →" リンク
              ↓
Collaborations (/collaborations)
  └─ コラボ記事一覧（画像/動画・説明）
```

### お問い合わせ

```
任意のページ
  └─ Header の "Contact" リンク
        ↓
Contact (/contact)
  └─ フォーム入力 → 送信 → 完了メッセージ表示
```

### 管理画面（AdminLayout.tsx）

```
PC: aside(200px) + main(flex:1)
モバイル: ハンバーガー → aside が fixed overlay ドロワーで展開

サイドバー項目: ダッシュボード / 分析 ↗ / イベント / ギャラリー / 取扱店
              / WS予約 / コラボレーション / お問い合わせ
              / 商品管理 / 注文管理 / 記事管理
              / 収支（全体の収支・支払い集計・ワークショップ集計）
              / 販売価格計算 / 鉢作家管理 / メディア管理
              / 設計書 / チャットQ&A / チャット履歴
```

**「分析 ↗」（2026-10-17 追加）**

- 「ダッシュボード」のすぐ下にある。押すと、分析ダッシュボード（`https://ei8htplants-analytics.onrender.com`）が**新しいタブ**で開く。管理画面のタブはそのまま残る
- 管理画面の中のページではないので、押しても選択中（背景が濃い色）の見た目にはならない
- 文字の横の「↗」は別のタブで開く目印。読み上げソフトには「分析 （新しいタブで開きます）」と伝わる
- 開いた先では、管理画面と同じメールアドレス・パスワードでもう一度ログインする（管理画面のログイン状態は引き継がない）
- 分析ダッシュボードは使われていないと止まる設定のため、しばらく使っていないと開くまで1分ほどかかる
- 分析ダッシュボードの中身は [FT-25 分析ダッシュボード](features/14_分析ダッシュボード.md) を参照
