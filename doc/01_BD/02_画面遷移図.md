# BD-02 — 画面遷移図・画面UI設計 (Screen Transition & UI Design)

## 1. 画面遷移図

```
[ブラウザURL入力 / リンク]
        │
        ▼
┌───────────────────────────────────────────────────────────────┐
│ Layout（Header + Footer 共通）                                 │
│                                                               │
│  /              → Home ─────────────────────────────────────────┐
│  /events        → Events ──── [予約ボタン] ──► /reserve?event_id │
│  /gallery       → Gallery                                     │
│  /concept       → Concept ── [ブランドリンク] ──►              │
│  /contact       → Contact                                     │
│  /stockists     → Stockists                                   │
│  /collaborations→ Collaborations                              │
│  /reserve       → Reserve                                     │
│                                                               │
│  /ei8htplants         → Ei8htPlants                           │
│  /habitatoides        → HabitatOides ── [WS詳細] ──►          │
│  /habitatoides/workshop → HabitatOidesWorkshop ── [/events]  │
│  /hue                 → HUE                                   │
│                                                               │
└───────────────────────────────────────────────────────────────┘

/admin/* → AdminLayout（認証ガード）
    │
    ├── 未認証 → ログインフォーム（モーダル全画面）
    │
    └── 認証済み → サイドバーナビ + 各Admin画面
                    │
                    ├── /admin               → Dashboard
                    ├── /admin/events        → Events管理
                    │       └── /admin/events/new    → EventForm（新規）
                    │       └── /admin/events/:id/edit → EventForm（編集）
                    ├── /admin/gallery       → Gallery管理
                    ├── /admin/stockists     → Stockists管理
                    ├── /admin/reservations  → Reservations管理
                    ├── /admin/collaborations→ Collaborations管理
                    └── /admin/contacts      → Contacts管理
```

## 2. ユーザージャーニー（主要フロー）

### イベント確認 → ワークショップ予約

```
Home
  └─ "次のイベント" カード表示
        └─ [予約] ボタン / /events への導線
              ↓
Events (/events)
  └─ イベントカード確認（場所・日時・画像）
        └─ [予約する] ボタン
              ↓
Reserve (/reserve?event_id=<uuid>)
  └─ 予約フォーム入力（名前・メール・参加人数）
        └─ 送信 → 完了メッセージ
```

### ブランドページ → コラボレーション確認

```
HabitatOides (/habitatoides)
  └─ Collaboration セクション
        └─ "View all collaborations →" リンク
              ↓
Collaborations (/collaborations)
  └─ コラボ記事一覧（画像/動画・説明）
```

### お問い合わせ

```
任意のページ
  └─ Header の "Contact" リンク
        ↓
Contact (/contact)
  └─ フォーム入力 → 送信 → 完了メッセージ表示
```

## 3. レイアウト構造

### 公開ページ（Layout.tsx）

```
┌────────────────────────────────────────┐
│ Header（固定ヘッダー, height: 60px）   │
│  [logo] [nav: Events Gallery ...] [☰] │
├────────────────────────────────────────┤
│                                        │
│  main.site-main                        │
│  padding-top: 60px                     │
│  min-height: 100vh                     │
│                                        │
│  <Outlet />（各ページのコンテンツ）    │
│                                        │
├────────────────────────────────────────┤
│ Footer                                 │
└────────────────────────────────────────┘
```

### 管理画面（AdminLayout.tsx）

```
┌──────────────────────────────────────────────────┐
│ aside（width: 200px, background: #fffcf6）        │
│  ei8ht admin                                     │
│  [ダッシュボード]                                 │
│  [イベント]                                       │
│  [ギャラリー]                                     │
│  [取扱店]                                         │
│  [WS予約]                                         │
│  [コラボレーション]                               │
│  [お問い合わせ]                                   │
│  ────────────                                    │
│  [ログアウト]                                     │
├──────────────────────────────────────────────────┤
│ main（flex: 1, padding: 40px）                   │
│                                                  │
│  <Outlet />（各Admin画面のコンテンツ）           │
│                                                  │
└──────────────────────────────────────────────────┘
```

### ブランドページ（サブナビ付き）

```
┌────────────────────────────────────────┐
│ Header（60px）                         │
├────────────────────────────────────────┤
│ .hero-wrapper                          │
│  ├── .brand-subnav（固定サブナビ）      │
│  │    [Concept] [Workshop] [...]       │
│  └── .hero-section（ヒーロービジュアル）│

├────────────────────────────────────────┤
```
