### 3.2 WS予約フォーム（`/reserve?row=N`）

```
┌─────────────────────────────────────┐
│  イベント名 / 日付 / 場所             │
├─────────────────────────────────────┤
│  [希望日] セレクト                    │
│  [時間帯] セレクト（日付連動）         │
│  [参加人数] セレクト（残席チェック連動）│
├─────────────────────────────────────┤
│  [お名前]                            │
│  [メールアドレス]                     │
│  [お持ち込み] チェックボックス         │
│  [備考] テキストエリア                │
├─────────────────────────────────────┤
│  [予約を申し込む] ← 送信後スピナー表示  │
└─────────────────────────────────────┘

送信成功後：予約完了モーダル表示
┌─────────────────────────────────────┐
│  予約を受け付けました                  │
│  確認メールをお送りしました             │
│  [閉じる] → /events へ遷移           │
└─────────────────────────────────────┘
```

**残席ロジック**: 日付・時間帯が確定するたびに  
`GET /api/reserve/availability?event_name=&date=&time=` を呼び出し、  
参加人数の選択肢をリアルタイム更新。  
最大定員 `WS_MAX_PARTICIPANTS = 4`。

---

### 3.3 予約キャンセルページ（`/cancel?token=xxx`）

4 つの表示状態を持つ：

| 状態 | 表示内容 |
|---|---|
| `done=1`（キャンセル完了後） | 完了メッセージ + [イベント一覧へ] |
| `token` が無効 | エラーメッセージ + [イベント一覧へ] |
| すでにキャンセル済み | キャンセル済みメッセージ |
| 通常（キャンセル前） | 予約詳細 + キャンセル理由（任意）+ [予約をキャンセルする] |

```
予約詳細表示:
  イベント / お名前 / 希望日 / 時間帯 / 参加人数

[キャンセル理由（任意）テキストエリア]
[予約をキャンセルする] ← confirm() + 二重送信防止
```

### 3.4 管理画面 WS予約一覧（`/admin/reservations`）

```
┌──────────────────────────────────────────────┐
│ [サマリーカード（現在・今後のイベント別、終了日昇順）]│
│ ┌────────┐ ┌────────┐                        │
│ │Event A │ │Event B │  ← クリックで予約表へ    │
│ │ 3 名   │ │ 7 名   │                        │
│ └────────┘ └────────┘                        │
│ [▾ 過去のイベント] ← クリックで展開            │
├──────────────────────────────────────────────┤
│ [絞り込み: セレクト] [□ キャンセル済を除く] N件│
├──────────────────────────────────────────────┤
│ 受付日  イベント  お名前  連絡先  日  時  人 │
│         ・・・                              │
│ メモ[テキストエリア][保存]  [キャンセル]     │
└──────────────────────────────────────────────┘
```

- **お名前**をクリック → 参加履歴ページへ
- **サマリーカード**は終了日が当日を過ぎると翌日に自動消去
- **メモ保存**は AJAX（ページ遷移なし）

### 3.5 予約表（`/admin/reservations/schedule?event=xxx`）

```
┌──────────────────────────────────────┐
│  ← 一覧に戻る   [イベント名] WS予約表  │
│                    [PDF ダウンロード]  │
├──────────────────────────────────────┤
│  10:00-11:00  計 2 名                │
│  ┌──┬──────┬──┬──────┬────┐          │
│  │# │ お名前│人│持込み│備考│          │
│  └──┴──────┴──┴──────┴────┘          │
│                 [小計: 2]            │
│  11:00-12:00  計 1 名                │
│  ┌──┬──────┬──┬──────┬────┐          │
│  └──┴──────┴──┴──────┴────┘          │
└──────────────────────────────────────┘
```

- PDF ダウンロード: `window.print()` + `@media print` でナビ非表示
- ファイル名: ブラウザのページタイトル（`{イベント名}WS予約表`）がデフォルト名
