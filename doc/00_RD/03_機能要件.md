## 5. 機能要件詳細

### 公開サイト

**イベント一覧 (PG-02)**
- API から取得したイベントをカードで表示（開催予定・過去を切り替え）
- ブランド（ei8ht plants / Habitat Oides / HUE by ei8ht plants）・月・ワークショップの有無で絞り込む（FT-03-a。スマホではプルダウンとチェックボックス）
- 開催日・場所・ブランド・ブース番号を表示
- 開催7日以内のイベントに「あとN日」バッジ（当日は「本日開催」）を表示（FT-03-b）
- 写真のスライドショー（複数枚の場合）
- ワークショップありで「予約必要」のイベントは、予約ボタンから `/reserve?event_id=<uuid>` に移る

**ギャラリー (PG-03)**
- ブランド別の絞り込みタブ（All / ei8ht plants / Habitat Oides / HUE）
- タブ切り替え時に API へブランドを渡して取り直す
- 写真を押すと拡大表示。背景クリックまたは Esc キーで閉じる

**お問い合わせ (PG-05)**
- フォーム項目: 名前（必須）・メールアドレス（必須）・メッセージ（必須）
- 送信時: バックエンド経由で DB 保存 + Resend で管理者にメール通知
- 送信完了メッセージを表示

**WS予約 (PG-12)・予約キャンセル (PG-13)**
- URL の `event_id` からイベント情報を取得して表示
- フォーム項目: 名前（必須）・メール（必須）・電話（任意）・参加人数（必須）・備考（任意）
- WS セッションが登録されている場合: 時間枠を選ぶ（残り人数 or 満席の表示付き。満席の枠は選べない）
- 定員を超えたとき: サーバーが 409 を返し、「満席になりました」の画面にする
- 持込チェックボックス: 「植物を持ち込む」「鉢を持ち込む」（任意）
- 送信に成功したら、予約内容を完了画面に表示
- 予約者に確認メール（時間枠・持込・キャンセル用のリンク付き。予約したときの言語）を、Habitat Oides の管理者に通知メールを送る。確認メールが送れなかった予約には「メール未送信」の印を付ける
- 確認メールのリンクから `/cancel` を開くと予約を取り消せる。取り消すとステータスが「キャンセル」になり、キャンセルのお知らせメールを送る

### 管理機能

**ダッシュボード (PG-A01)**
- 未読お問い合わせ・未発送の注文・公開中イベントの数をカードで表示（FT-01-a）。押すとそれぞれの管理画面を開く
- 「出店料の支払い」「今後の搬入予定」を表示（FT-12-b）
- 各管理画面へのカード

**イベント管理 (PG-A02)**
- 開催予定（開始日の早い順）・過去（新しい順）に分けて一覧表示。終了日（無ければ開始日）を過ぎると自動で過去に移る
- 各イベント行に開始日・終了日（複数日開催は「start 〜 end」形式）・会場を表示
- 各イベント行のボタン: 編集・管理情報・画像DL・収支・サイト・予約 N件（`has_workshop=true` のみ。キャンセル以外の件数。WS予約管理を絞り込んで開く）・予約管理（印刷・CSV）（`has_workshop=true` のみ。イベント別予約管理 PG-A12 を開く。2026-10-22 追加）・複製・削除
- 追加・編集の画面: イベント名・URL スラッグ（新規作成ではイベント名から自動で作る。手で書き換えたら自動では変えない。既存のスラッグは変えない）・開始日・終了日・開催時間（複数日は日ごとに変えられる）・会場名・ブース番号・住所・公式サイトURL・販売ブランド・写真（ファイルを選ぶ。複数）・ワークショップあり・予約必要
- 「ワークショップあり」のとき: WS セッションの欄を表示（回ごとに時間・定員。手で追加するか、[自動設定] で開催時間から1時間ごと・定員4名の回を作る）
- イベント保存時にセッション情報を `PUT /api/events/{id}/sessions` で一括更新
- 「複製」で既存イベントをコピー（名前に "(コピー)" を付与。セッション・収支・管理情報・サイトの中身・スラッグ・日ごとの時間は写さない）
- 管理情報: 搬入・搬出・宿泊・出店料（支払い方法・期限・支払い済み）・出店要項（文章と写真）・メモ。確認画面 → 編集画面 → 保存で確認画面に戻る。保存していないまま離れるときは確認を出す。出店料・宿泊費は収支と同じ値にそろえる
- 画像DL: イベントの写真を出どころごとに並べ、1枚ずつ保存する

**収支一覧 (PG-A14)**
- 全イベントを売上・支出・収支の列で一覧表示（新しい順）
- ページ上部に、収支を入れたイベントの合計（売上・支出・収支）と件数を表示
- 「支払対象」（手伝いあり）・「WS支払」（済・未）の列
- 各イベント行に「編集」ボタン（`/admin/events/{id}/finances` へリンク）
- 収支を入れていないイベントは「—」と表示

**WS予約管理 (PG-A05)**
- 「今後の開催」「過去の開催」のタブ。イベントのプルダウンで絞り込む（今日開催のイベントがあれば最初から絞り込む。`?event_id=` でも指定できる）
- 予約は希望日・時間の順に表示。件数と合計人数を表示（キャンセルを除く。2026-10-22 から）
- 時間枠・持込（植物・鉢）・備考を表示。確認メールが送れなかった予約に「メール未送信」の印
- ステータスは「受付済」（`pending`。当日参加の `confirmed` も受付済と表示）・「キャンセル」（`cancelled`）の2つ。プルダウンで変える。キャンセルにするとお客様にお知らせメールを送り、その回の予約数を数え直す。変更に失敗したときは元の状態のまま赤い枠で知らせる（満席の回をキャンセルから戻すときは 409）
- 「当日参加を追加」: イベント・参加日・時間枠・人数を選んで登録（名前は「当日参加」、メールは送らない）
- 「PDF で印刷」で表示中の予約を印刷（時間枠ごとの予約人数・空き枠はキャンセルを除いて数える）
- スマホでは予約をカードで表示し、押すと詳細を下から出す

**イベント収支管理 (PG-A11)**
- イベント別に収支を入力・保存
- 入力項目: 売上・WS 参加人数（ワークショップありのみ）・手伝いあり（支払い計算モード）・出店料・距離（片道）・ガソリン単価・高速代・宿泊費・その他支出（内容付き）・メモ
- 移動費 = `round((距離 × 2 / 10) × ガソリン単価)`
- WS 売上 = 参加人数 × 1,000円、WS 資材費 = 参加人数 × 700円
- 手伝いなし: 収支 = 売上 − 支出合計 − WS 資材費
- 手伝いあり: 支払い金額 = `(売上 − WS売上 − 支出合計) × 20% + WS売上 × 70%`（赤字のときはマイナスのまま）。収支 = 売上 − 支出合計 − WS 資材費 − 支払い金額
- 保存すると開いた元の画面（イベント管理・収支一覧）に戻る

**イベント別予約管理 (PG-A12)**
- イベント一覧の［予約管理（印刷・CSV）］から開く。「← イベント管理」で一覧に戻る
- イベント名・日付・会場をヘッダーに表示
- イベントに紐づく予約だけを表示（`GET /api/reserves?event_id=xxx`）
- 時間枠ごとの絞り込みボタン（各ボタンにキャンセル以外の人数を表示）
- 全体の件数・合計人数（キャンセル以外）を表示
- ステータスをプルダウンで変更できる
- 「予約ページリンクをコピー」: `https://ei8htplants.com/reserve?event_id={id}` をコピー（2秒間「コピーしました」と表示。コピーできなければ URL を出して手でコピーしてもらう）
- 「当日参加を追加」・「印刷」・「CSV」（絞り込みを反映）

**お問い合わせ管理 (PG-A07)**
- 未読件数を見出しの横に表示
- 行を押すと本文を展開
- 既読/未読をボタンで切り替え
- 「返信」ボタンで画面の中に入力欄を開き、件名・本文を直して送信（Resend。送信専用のアドレスから送り、末尾に返信不可の案内を付ける）
- 返信を送ると自動で既読にする

**注文管理 (PG-A09)**
- ステータス: 支払済・発送済・配達完了・キャンセル
- 「発送済」にするときは配送会社（ヤマト運輸・佐川急便・日本郵便（ゆうパック）・その他）と追跡番号（任意）を入れ、お客様に発送のお知らせメールを送る
- キャンセルにしても返金・在庫の戻しは自動では行わない
