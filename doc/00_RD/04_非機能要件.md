# RD-04 — 非機能要件 (Non-Functional Requirements)

IPA「非機能要求グレード」の6分類に沿って定義する。

---

## 1. 可用性 (Availability)

| 項目 | 目標値・方針 |
|---|---|
| サービス稼働時間 | 24時間365日（SaaS依存） |
| 計画外停止目標 (RTO) | 4時間以内に復旧（本番サーバー障害時） |
| データ損失許容時間 (RPO) | Supabaseのバックアップ周期に依存（最大24時間分）。運用フェーズで方針確定 |
| 単一障害点 | Supabaseへの依存度が高い。Supabase障害時はサイト全体が停止する（許容範囲） |
| 本番構成 | Render 上の FastAPI 1つ（画面のファイルも同じサーバーが返す）+ Supabase（外部DB）。冗長化は現フェーズのスコープ外。分析ダッシュボードは Streamlit Community Cloud で別に動かす（休止していると起動を待つ） |

---

## 2. 性能・拡張性 (Performance & Scalability)

| 項目 | 目標値・方針 |
|---|---|
| ページ初期表示 | 3秒以内（LTE相当環境）を目標 |
| API応答時間 | 通常時 500ms以内（Supabase + FastAPI） |
| 同時接続数 | 小規模サイト想定。50同時接続以下を現フェーズのターゲットとする |
| スケールアップ対応 | Supabaseプランのアップグレードで対応可能。アプリコードの変更は不要 |
| 画像配信 | 管理画面でアップロードした写真・動画は Supabase Storage（`images`・`videos`）に置き、その公開 URL を直接参照する。サイト本体のサーバーでは配信しない |
| フロントエンドビルド | Viteによる最適化ビルド。画面ごとにファイルを分けて、開いた画面の分だけ読み込む（2026-10-21〜）。ビルド結果 `frontend/dist/` はリポジトリに含める |

---

## 3. 運用・保守性 (Maintainability)

| 項目 | 方針 |
|---|---|
| コンテンツ更新 | 管理者が非エンジニアでも操作できるAdmin画面を提供。開発者不在でも更新可能 |
| コード管理 | Gitで管理。mainブランチが本番対応コード |
| ログ | uvicorn のアクセスログとサーバーのエラーを標準出力に出す。本番では Render の「Logs」の画面で見る。エラーのログには例外の種類とコードだけを出し、利用者が入力した値（名前・メールアドレスなど）は残さない。予期しない例外だけは、原因を調べるため詳細（traceback）を残す（2026-10-23 記載。課題表に記録） |
| エラー監視 | 現フェーズではエラー監視ツールなし。Render の Logs を手で確認する |
| 依存パッケージ | `requirements.txt` / `package.json` でバージョン固定。定期的なセキュリティアップデートを推奨 |
| ドキュメント | `doc/` 以下に設計書（00_RD〜05_OP）を整備し、引き継ぎを容易にする。管理画面の「設計書」でも読める |

---

## 4. 移行性 (Portability)

| 項目 | 方針 |
|---|---|
| デプロイ先変更 | 接続情報・キーは環境変数（ローカルは `.env`、本番は Render の環境変数）で渡すため、Python が動くほかのホスティングにも移せる |
| フロントエンド | Viteビルド成果物（静的ファイル）であれば、任意のCDNやホスティングサービスに移行可能 |
| データ移行 | Supabase PostgreSQLのpg_dumpでエクスポート可能。新DBへの移行手順は [移行計画書](../05_OP/01_移行計画書.md) を参照 |
| 外部依存 | Resend（メール）を別のサービスに替えるときは、メールを送る処理（`contact.py`・`reserve.py`・`orders.py` など）の修正が必要 |

## 5. セキュリティ (Security)

| 項目 | 方針 |
|---|---|
| 秘匿情報管理 | `.env` ファイルで管理。`.gitignore` に含まれており、リポジトリには絶対にコミットしない |
| 公開クライアントへの情報露出 | フロントエンドには `VITE_SUPABASE_ANON_KEY`（公開安全なanon key）のみ公開。`SERVICE_ROLE_KEY` はバックエンド限定 |
| 管理者認証 | Supabase Auth（メール + パスワード）によるセッション管理。JWTトークンをSupabaseが発行。Supabase で新規登録（サインアップ）を無効にしておく（課題表 I-11 で確認中） |
| API認証 | 管理用の API は、バックエンドの `require_auth` で、画面から送られたログインの証明（Bearer トークン）を Supabase に問い合わせて確かめる。無い・正しくないときは 401。設計書の API（`/api/docs`）も 2026-10-22 のコードからログインが必要（課題表 I-07） |
| XSS対策 | React の標準の表示でエスケープする。例外として、管理画面の「設計書」（AdminDocs）は Markdown を HTML にして表示する（中身は自分たちの `doc/` の文書だけ。表示の前に DOMPurify でスクリプトなどを取り除く）。予約一覧の印刷は HTML を文字で組み立てるため、入力された値を必ず `escapeHtml` で無害化する。CSV は `=`・`+`・`-`・`@` で始まる値に `'` を付け、表計算ソフトで数式として動かないようにする（2026-10-22） |
| SQLインジェクション対策 | Supabase Python SDK経由のパラメータバインディングにより防止 |
| CORS設定 | `localhost:5173`（開発）のみ許可。本番は画面と API が同じドメイン（ei8htplants.com）なので、ほかのドメインを許可する必要はない |
| 回数制限 | 公開の書き込み API（AI チャット・お問い合わせ・WS予約・キャンセル・注文）は、送り元の IP ごとに回数を数え、超えたら 429。送り元の IP は `CF-Connecting-IP` → `X-Forwarded-For` の右端（Render の中継が付け足す、接続してきた相手）→ 接続元の順で決める（Cloudflare・Render の中継の内側でも利用者ごとに数えるため。`X-Forwarded-For` の先頭は利用者が書けるので使わない）。IP は 64 文字まで、覚えておく IP は最大 1 万件（2026-10-23。[DD-06](../02_DD/06_API仕様.md) の「回数制限の送り元 IP」）。Cloudflare を通さず Render の URL に直接送られると制限をすり抜けられる（課題表） |
| アップロード | 管理者だけが使える。種類（JPEG・PNG・WebP・GIF、MP4・MOV・WebM・M4V）と大きさに加えて、ファイルの先頭のバイトで中身が申告どおりかを確かめる。拡張子は種類から決める（画像と偽った HTML などを公開の保存場所に置かせないため。2026-10-22） |
| HTTPS | Render が HTTPS で配信する。サーバーは HSTS・`X-Content-Type-Options`・`X-Frame-Options`・`Referrer-Policy` のヘッダーを付ける |

## 6. システム環境 (System Environment)

### フロントエンド実行環境

| 項目 | 内容 |
|---|---|
| 対応ブラウザ | Chrome・Safari・Firefox の最新版 |
| モバイル対応 | レスポンシブデザイン（スマートフォン・タブレット対応） |
| JavaScript | 必須（React SPAのため）|

### バックエンド実行環境

| 項目 | 内容 |
|---|---|
| OS | Linux（本番・Render）/ macOS（開発） |
| Python | 3.12.9 以上 |
| フレームワーク | FastAPI 0.115.5 + uvicorn 0.32.1 |
| ポート | 8000（開発時）。本番は Render が割り当てる |

### 開発環境

| 項目 | 内容 |
|---|---|
| フロントエンド | Node.js + Vite dev server（port 5173） |
| バックエンド | Python venv + uvicorn --reload（port 8000） |
| DB | Supabase（クラウド）を開発・本番共通で使用 |

### インフラ・外部サービス依存（本番環境）

| サービス | 用途 | 備考 |
|---|---|---|
| Render | サイト本体（FastAPI と画面）の公開 | `main` ブランチへのプッシュで自動デプロイ。無料枠は全サービスで月 750 時間まで |
| Supabase | DB・Auth（管理者ログイン）・Storage（写真・動画） | 全データの置き場所 |
| Resend | メール送信 | ei8ht plants 名義と Habitat Oides 名義で別のキー |
| Square | ショップのカード決済 | 本番・テスト（sandbox）を環境変数で切り替える |
| Google AI Studio (Gemini) | AI チャット | モデルは `gemini-flash-lite-latest` |
| Google Analytics 4 | アクセス解析 | 公開ページに計測タグ。分析ダッシュボードが数字を読む |
| Streamlit Community Cloud | 分析ダッシュボードの公開 | 無料。しばらく使われないと休止する（[公開手順](../05_OP/04_分析ダッシュボードの公開手順.md)） |
| Cloudflare | メールの受信転送（Email Routing） | info@ei8htplants.com・info@habitatoides.com を Gmail に転送 |
