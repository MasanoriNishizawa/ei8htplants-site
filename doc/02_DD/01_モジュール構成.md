| `CartProvider` / `useCart` | カートグローバル状態（localStorage永続化） | Shop, ShopProduct, Checkout |

## 2. フロントエンド モジュール依存グラフ

```
pages/* ──────────────────────────────────────────┐
                                                   ▼
brands/* ──────────────────────────────────────► lib/api.ts
                                                   │
admin/* ────────────────────────────────────────── ┘
                                                   │
components/EventCard.tsx ──────────────────► fetch(BASE + path)
                                                   │
                                                 /api/*
                                                   │
                                           Vite proxy (dev)
                                         FastAPI (port 8000)
```

- `lib/api.ts` が唯一のAPIアクセス窓口。ページは `api.xxx.yyy()` のみを呼ぶ。
- `@supabase/supabase-js` は `admin/AdminLayout.tsx` のみが直接使用（Auth用）。
- CSS は `index.css`（グローバル）+ インラインスタイルの2層構成。Tailwindクラスは一部ページで使用。

## 3. バックエンド モジュール依存グラフ

```
main.py
├── CORSMiddleware (localhost:5173 許可)
├── StaticFiles (本番: frontend/dist/assets, img, favicon)
├── include_router(events.router,  prefix='/api')
├── include_router(gallery.router, prefix='/api')
├── include_router(stockists.router, prefix='/api')
├── include_router(contact.router,  prefix='/api')
├── include_router(reserve.router,  prefix='/api')
└── include_router(collaborations.router, prefix='/api')

routes/events.py
routes/gallery.py      ──── db.py ──── config.py ──── .env
routes/stockists.py          │
routes/contact.py ──── resend SDK
routes/reserve.py
routes/collaborations.py

db.py
├── supabase  = create_client(URL, ANON_KEY)    # 公開読み取り
└── admin_supabase = create_client(URL, SERVICE_ROLE_KEY)  # 管理書き込み
```

- `supabase`（anon）: GET系エンドポイントが使用。RLSのpublic readポリシーに従う。
- `admin_supabase`（service_role）: POST/PUT/PATCH/DELETE が使用。RLSをバイパス。
- 各routeファイルはPydantic `BaseModel` でリクエストバリデーションを行う。

## 4. リクエスト データフロー

```
ブラウザ
  │  fetch('/api/...')
  ▼
Vite devserver (port 5173)  ※開発時のみ
  │  proxyRequest → localhost:8000
  ▼
FastAPI (uvicorn, port 8000)
  │  router dispatch
  ▼
routes/*.py
  │  Pydantic validation
  │  supabase / admin_supabase
  ▼
Supabase (PostgreSQL + RLS)
  │
  ▼  レスポンスJSON
routes/*.py
  │
FastAPI
  │  JSONResponse
  ▼
ブラウザ  lib/api.ts → res.json() → TypeScript型
```

**本番時**: Vite proxyは不要。FastAPI が `frontend/dist` を StaticFiles で配信し、`/{full_path:path}` でSPAのindex.htmlにフォールバック。
