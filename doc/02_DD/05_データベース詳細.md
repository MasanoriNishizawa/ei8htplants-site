## 2. テーブルDDL 全定義

### events

```sql
CREATE TABLE events (
    id               UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
    name             TEXT        NOT NULL,
    start_date       DATE        NOT NULL,
    end_date         DATE,
    time             TEXT,
    location         TEXT        NOT NULL,
    booth_number     TEXT,
    address          TEXT,
    official_url     TEXT,
    brands           TEXT[]      DEFAULT '{}',
    has_workshop     BOOLEAN     NOT NULL DEFAULT false,
    ws_requires_reservation BOOLEAN NOT NULL DEFAULT true,
    is_past          BOOLEAN     NOT NULL DEFAULT false,
    display_order    INTEGER     NOT NULL DEFAULT 0,
    created_at       TIMESTAMPTZ DEFAULT now()
);

-- 008マイグレーション
ALTER TABLE events ADD COLUMN IF NOT EXISTS page_content jsonb;

-- 009マイグレーション
ALTER TABLE events ADD COLUMN IF NOT EXISTS daily_times jsonb;
```

`page_content` 構造（JSONB）:
```json
{
  "hero": { "image_url": "...", "tagline": "...", "subtitle": "..." },
  "venue": { "address": "...", "access": "...", "map_url": "..." },
  "concept": "テキスト",
  "lineup": [{ "title": "...", "description": "...", "image_url": "..." }],
  "workshop": { "title": "...", "description": "...", "note": "..." },
  "guests": [{ "name": "...", "role": "...", "bio": "...", "image_url": "...", "instagram_url": "..." }],
  "archive": { "enabled": true, "title": "...", "message": "...", "gallery": ["url1", "url2"] }
}
```

`daily_times` 構造（JSONB）: `{ "2025-10-01": "11:00〜17:00", "2025-10-02": "10:00〜16:00" }`

### products（010マイグレーション）

```sql
CREATE TABLE products (
    id            UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
    name          TEXT        NOT NULL,
    description   TEXT,                     -- BlockEditor JSON
    price         INTEGER     NOT NULL CHECK (price >= 0),
    stock         INTEGER     NOT NULL DEFAULT 0 CHECK (stock >= 0),
    image_urls    TEXT[]      DEFAULT '{}',
    tags          TEXT[]      DEFAULT '{}',
    is_published  BOOLEAN     NOT NULL DEFAULT false,
    display_order INTEGER     NOT NULL DEFAULT 0,
    created_at    TIMESTAMPTZ DEFAULT now()
);

-- 015マイグレーション
ALTER TABLE products
  ADD COLUMN IF NOT EXISTS category TEXT
    CHECK (category IS NULL OR category IN (
      'アガベ','塊根植物','灌木','サボテン',
      '観葉植物','ハビタットスタイル','ハビタットスタイル資材','園芸資材','鉢'
    ));
```

在庫アトミック減算関数:
```sql
CREATE OR REPLACE FUNCTION decrement_stock(p_product_id uuid, p_quantity integer)
RETURNS boolean LANGUAGE plpgsql AS $$
DECLARE updated integer;
BEGIN
    UPDATE products SET stock = stock - p_quantity
    WHERE id = p_product_id AND stock >= p_quantity;
    GET DIAGNOSTICS updated = ROW_COUNT;
    RETURN updated > 0;
END;
$$;
```

## 3. インデックス

Supabase（PostgreSQL）が自動生成するインデックス:

| テーブル | インデックス | 種別 |
|---|---|---|
| 全テーブル | `id` | PRIMARY KEY（自動） |
| `event_images` | `event_id` | 外部キー制約により自動 |
| `event_finances` | `event_id` | UNIQUE制約により自動 |
| `ws_sessions` | `event_id` | 外部キー制約により自動 |
| `workshop_reservations` | `event_id`, `session_id` | 外部キー（参照） |

追加インデックス（必要に応じて作成を推奨）:

```sql
-- ブランドフィルタリング用
CREATE INDEX IF NOT EXISTS idx_gallery_images_brand
    ON gallery_images (brand);

-- 既読フィルタリング用
CREATE INDEX IF NOT EXISTS idx_contacts_is_read
    ON contacts (is_read);

-- 予約ステータスフィルタリング用
CREATE INDEX IF NOT EXISTS idx_reservations_status
    ON workshop_reservations (status);

-- キャンセルトークン検索用（手動適用）
CREATE INDEX IF NOT EXISTS idx_reservations_cancel_token
    ON workshop_reservations (cancel_token);
```

## 4. Row Level Security (RLS) ポリシー

### events / event_images

```sql
ALTER TABLE events ENABLE ROW LEVEL SECURITY;
CREATE POLICY "public read events" ON events FOR SELECT TO anon USING (true);
CREATE POLICY "service write events" ON events FOR ALL TO service_role USING (true);
```

### gallery_images / stockists / collaborations

同様に `anon` SELECT 可、`service_role` 全操作可。

### ws_sessions

```sql
ALTER TABLE ws_sessions ENABLE ROW LEVEL SECURITY;
CREATE POLICY "public read ws_sessions" ON ws_sessions FOR SELECT TO anon USING (true);
CREATE POLICY "service write ws_sessions" ON ws_sessions FOR ALL TO service_role USING (true);
```

### contacts

```sql
ALTER TABLE contacts ENABLE ROW LEVEL SECURITY;
-- 003マイグレーションで anon INSERT ポリシーを削除済み（全操作は service_role のみ）
CREATE POLICY "service manage contacts" ON contacts FOR ALL TO service_role USING (true);
```

### workshop_reservations

```sql
ALTER TABLE workshop_reservations ENABLE ROW LEVEL SECURITY;
-- anon は INSERT のみ（予約フォーム）
CREATE POLICY "anon insert reservations" ON workshop_reservations
    FOR INSERT TO anon WITH CHECK (true);
-- service_role は全操作（管理画面でのステータス更新・キャンセル処理）
CREATE POLICY "service manage reservations" ON workshop_reservations
    FOR ALL TO service_role USING (true);
```

## 5. データ型・制約の補足

| カラム | 型 | 補足 |
|---|---|---|
| `id` | UUID | `gen_random_uuid()` でランダムUUID v4 |
| `brands` (events/stockists) | `TEXT[]` | PostgreSQL配列型。空配列は `'{}'` |
| `page_content` (events) | `JSONB` | イベント専用サイトのコンテンツ（hero / venue / lineup 等） |
| `daily_times` (events) | `JSONB` | 日付 → 時間帯のマップ `{"2025-10-01": "11:00〜17:00"}` |
| `status` (workshop_reservations) | `TEXT` | CHECK制約なし。`pending` / `confirmed` / `cancelled` をアプリ層で保証 |
| `cancel_token` (workshop_reservations) | `TEXT` | 8桁ランダム数字。初回 confirmed 時に生成・以降不変 |
| `reserved_count` (ws_sessions) | `INTEGER` | デノーマライズ値。`_sync_reserved_count()` で同期、`GET /sessions` でライブ値に上書き |
| `is_read` (contacts) | `BOOLEAN NOT NULL DEFAULT false` | NULL不可。デフォルト未読 |
| `display_order` (各テーブル) | `INTEGER NOT NULL DEFAULT 0` | INSERT時にアプリ層でcount+1を付与 |
