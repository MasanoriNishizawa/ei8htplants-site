## 2. テーブルDDL 全定義

### events

```sql
CREATE TABLE events (
    id               UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
    name             TEXT        NOT NULL,
    start_date       DATE        NOT NULL,
    end_date         DATE,
    time             TEXT,
    location         TEXT        NOT NULL,
    booth_number     TEXT,
    address          TEXT,
    official_url     TEXT,
    brands           TEXT[]      DEFAULT '{}',
    has_workshop     BOOLEAN     NOT NULL DEFAULT false,
    ws_requires_reservation BOOLEAN NOT NULL DEFAULT true,
    is_past          BOOLEAN     NOT NULL DEFAULT false,
    display_order    INTEGER     NOT NULL DEFAULT 0,
    created_at       TIMESTAMPTZ DEFAULT now()
);
```

### event_images

```sql
CREATE TABLE event_images (
    id            UUID  PRIMARY KEY DEFAULT gen_random_uuid(),
    event_id      UUID  NOT NULL REFERENCES events(id) ON DELETE CASCADE,
    url           TEXT  NOT NULL,
    display_order INTEGER NOT NULL DEFAULT 0,
    created_at    TIMESTAMPTZ DEFAULT now()
);
```

### gallery_images

```sql
CREATE TABLE gallery_images (
    id            UUID  PRIMARY KEY DEFAULT gen_random_uuid(),
    url           TEXT  NOT NULL,
    alt           TEXT,
    display_order INTEGER NOT NULL DEFAULT 0,
    created_at    TIMESTAMPTZ DEFAULT now()
);

-- 002マイグレーション
ALTER TABLE gallery_images ADD COLUMN IF NOT EXISTS brand TEXT;
```

### stockists

```sql
CREATE TABLE stockists (
    id            UUID  PRIMARY KEY DEFAULT gen_random_uuid(),
    name          TEXT  NOT NULL,
    area          TEXT,
    address       TEXT,
    url           TEXT,
    display_order INTEGER NOT NULL DEFAULT 0,
    created_at    TIMESTAMPTZ DEFAULT now()
);

-- 002マイグレーション
ALTER TABLE stockists ADD COLUMN IF NOT EXISTS brands TEXT[] DEFAULT '{}';
```

### collaborations

```sql
-- 002マイグレーション
CREATE TABLE IF NOT EXISTS collaborations (
    id            UUID  PRIMARY KEY DEFAULT gen_random_uuid(),
    title         TEXT  NOT NULL,
    partner_name  TEXT,
    description   TEXT,
    video_url     TEXT,
    image_url     TEXT,
    event_date    DATE,
    display_order INTEGER NOT NULL DEFAULT 0,
    created_at    TIMESTAMPTZ DEFAULT now()
);
```

### contacts

```sql
-- 002マイグレーション
CREATE TABLE IF NOT EXISTS contacts (
    id         UUID     PRIMARY KEY DEFAULT gen_random_uuid(),
    name       TEXT     NOT NULL,
    email      TEXT     NOT NULL,
    message    TEXT     NOT NULL,
    is_read    BOOLEAN  NOT NULL DEFAULT false,
    created_at TIMESTAMPTZ DEFAULT now()
);
```

### workshop_reservations

```sql
CREATE TABLE workshop_reservations (
    id           UUID  PRIMARY KEY DEFAULT gen_random_uuid(),
    event_id     UUID  REFERENCES events(id),
    name         TEXT  NOT NULL,
    email        TEXT  NOT NULL,
    phone        TEXT,
    participants INTEGER DEFAULT 1,
    note         TEXT,
    created_at   TIMESTAMPTZ DEFAULT now()
);

-- 002マイグレーション
ALTER TABLE workshop_reservations
    ADD COLUMN IF NOT EXISTS status TEXT NOT NULL DEFAULT 'pending';
```

## 3. インデックス

Supabase（PostgreSQL）が自動生成するインデックス:

| テーブル | インデックス | 種別 |
|---|---|---|
| 全テーブル | `id` | PRIMARY KEY（自動） |
| `event_images` | `event_id` | 外部キー制約により自動 |
| `workshop_reservations` | `event_id` | 外部キー（参照） |

追加インデックス（必要に応じて作成を推奨）:

```sql
-- ブランドフィルタリング用
CREATE INDEX IF NOT EXISTS idx_gallery_images_brand
    ON gallery_images (brand);

-- 既読フィルタリング用
CREATE INDEX IF NOT EXISTS idx_contacts_is_read
    ON contacts (is_read);

-- 予約ステータスフィルタリング用
CREATE INDEX IF NOT EXISTS idx_reservations_status
    ON workshop_reservations (status);
```

## 4. Row Level Security (RLS) ポリシー

### events / event_images

```sql
ALTER TABLE events ENABLE ROW LEVEL SECURITY;
-- 推定ポリシー（001マイグレーション）:
CREATE POLICY "public read events" ON events
    FOR SELECT TO anon USING (true);
CREATE POLICY "service write events" ON events
    FOR ALL TO service_role USING (true);
```

### gallery_images

```sql
ALTER TABLE gallery_images ENABLE ROW LEVEL SECURITY;
CREATE POLICY "public read gallery" ON gallery_images
    FOR SELECT TO anon USING (true);
CREATE POLICY "service write gallery" ON gallery_images
    FOR ALL TO service_role USING (true);
```

### stockists

```sql
ALTER TABLE stockists ENABLE ROW LEVEL SECURITY;
CREATE POLICY "public read stockists" ON stockists
    FOR SELECT TO anon USING (true);
CREATE POLICY "service write stockists" ON stockists
    FOR ALL TO service_role USING (true);
```

### collaborations (002マイグレーション)

```sql
ALTER TABLE collaborations ENABLE ROW LEVEL SECURITY;
CREATE POLICY "public read collaborations" ON collaborations
    FOR SELECT TO anon USING (true);
CREATE POLICY "service write collaborations" ON collaborations
    FOR ALL TO service_role USING (true);
```

### contacts (002マイグレーション)

```sql
ALTER TABLE contacts ENABLE ROW LEVEL SECURITY;
-- anon は INSERT のみ（フォーム送信）
CREATE POLICY "anon insert contacts" ON contacts
    FOR INSERT TO anon WITH CHECK (true);
-- service_role は全操作（管理画面での読み取り・既読更新）
CREATE POLICY "service manage contacts" ON contacts
    FOR ALL TO service_role USING (true);
```

### workshop_reservations

```sql
ALTER TABLE workshop_reservations ENABLE ROW LEVEL SECURITY;
-- anon は INSERT のみ（予約フォーム）
CREATE POLICY "anon insert reservations" ON workshop_reservations
    FOR INSERT TO anon WITH CHECK (true);
-- service_role は全操作（管理画面でのステータス更新）
CREATE POLICY "service manage reservations" ON workshop_reservations
    FOR ALL TO service_role USING (true);
```

## 5. データ型・制約の補足

| カラム | 型 | 補足 |
|---|---|---|
| `id` | UUID | `gen_random_uuid()` でランダムUUID v4 |
| `brands` (events/stockists) | `TEXT[]` | PostgreSQL配列型。空配列は `'{}'` |
| `event_date` (collaborations) | `DATE` | 時刻なし日付。Python側では文字列 "YYYY-MM-DD" として扱う |
| `status` (workshop_reservations) | `TEXT` | CHECK制約なし。アプリ層で 'pending'/'confirmed'/'cancelled' を保証 |
| `is_read` (contacts) | `BOOLEAN NOT NULL DEFAULT false` | NULL不可。デフォルト未読 |
| `display_order` (各テーブル) | `INTEGER NOT NULL DEFAULT 0` | INSERT時にアプリ層でcount+1を付与 |
