# DD-02 — クラス・型設計

## 1. TypeScript インターフェース (`frontend/src/lib/api.ts`)

### Event

```typescript
export interface Event {
  id: string               // UUID
  name: string             // イベント名
  start_date: string       // ISO 8601 date "YYYY-MM-DD"
  end_date: string | null  // 終了日（単日イベントはnull）
  time: string | null      // 開催時間文字列 e.g. "11:00〜17:00"
  location: string         // 会場名
  booth_number: string | null   // ブース番号
  address: string | null        // 会場住所
  official_url: string | null   // 公式サイトURL
  brands: string[]         // 出展ブランド配列 e.g. ["ei8ht plants", "Habitat Oides"]
  has_workshop: bool       // WS開催フラグ
  ws_requires_reservation: bool // WS予約必要フラグ
  is_past: bool            // 過去イベントフラグ
  display_order: number    // 表示順（昇順）
  images: {
    id: string
    url: string
    display_order: number
  }[]                      // 画像一覧（display_order昇順）
}
```

## 3. コンポーネント state 型

### AdminLayout.tsx

| state変数 | 型 | 初期値 | 説明 |
|---|---|---|---|
| `checking` | `boolean` | `true` | セッション確認中フラグ |
| `authed` | `boolean` | `false` | 認証済みフラグ |
| `email` | `string` | `''` | ログインフォーム: メール入力値 |
| `password` | `string` | `''` | ログインフォーム: パスワード入力値 |
| `error` | `string` | `''` | ログインエラーメッセージ |

### admin/Gallery.tsx

| state変数 | 型 | 初期値 | 説明 |
|---|---|---|---|
| `images` | `GalleryImage[]` | `[]` | 画像一覧 |
| `url` | `string` | `''` | フォーム: 画像URL |
| `alt` | `string` | `''` | フォーム: ALTテキスト |
| `brand` | `string` | `''` | フォーム: ブランド（空文字=null） |

### admin/Stockists.tsx

| state変数 | 型 | 初期値 | 説明 |
|---|---|---|---|
| `stockists` | `Stockist[]` | `[]` | 取扱店一覧 |
| `form` | `StockistBody` | `{name:'',area:null,...,brands:[]}` | 追加フォーム入力値 |
| `editing` | `Stockist \| null` | `null` | 編集中の取扱店（nullでモーダル非表示） |
| `editForm` | `StockistBody` | 編集対象のデータ | 編集モーダル入力値 |

### admin/Reservations.tsx

| state変数 | 型 | 初期値 | 説明 |
|---|---|---|---|
| `reservations` | `Reservation[]` | `[]` | 予約一覧 |
| `updating` | `string \| null` | `null` | 更新中の予約ID（重複更新防止） |

### admin/Collaborations.tsx

| state変数 | 型 | 初期値 | 説明 |
|---|---|---|---|
| `collabs` | `Collaboration[]` | `[]` | コラボ一覧 |
| `form` | `CollaborationPayload` | `{title:'', ...}` | 追加フォーム入力値 |

### admin/Contacts.tsx

| state変数 | 型 | 初期値 | 説明 |
|---|---|---|---|
| `contacts` | `ContactRecord[]` | `[]` | お問い合わせ一覧 |
| `expanded` | `string \| null` | `null` | 展開中のお問い合わせID |

### pages/Gallery.tsx

| state変数 | 型 | 初期値 | 説明 |
|---|---|---|---|
| `images` | `GalleryImage[]` | `[]` | 現在のフィルタ条件での画像一覧 |
| `activeBrand` | `string \| null` | `null` | 選択中ブランド（nullは全件） |
| `lightbox` | `GalleryImage \| null` | `null` | ライトボックス表示中の画像 |

### pages/Contact.tsx

| state変数 | 型 | 初期値 | 説明 |
|---|---|---|---|
| `form` | `{name:string, email:string, message:string}` | 空文字列x3 | フォーム入力値 |
| `status` | `'idle' \| 'loading' \| 'done' \| 'error'` | `'idle'` | 送信状態 |

### pages/Reserve.tsx

| state変数 | 型 | 初期値 | 説明 |
|---|---|---|---|
| `event` | `Event \| null` | `null` | URLパラメータで指定されたイベント |

| `status` | `'idle' \| 'loading' \| 'done' \| 'error'` | `'idle'` | 送信状態 |

### components/EventCard.tsx

|---|---|---|---|
| `imgIdx` | `number` | `0` | 現在表示中の画像インデックス |
