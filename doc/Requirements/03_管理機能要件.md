# 機能要件 — 管理機能（Admin）

## 認証

- Supabase Auth（メールアドレス + パスワード）によるログイン
- セッションを保持し、未認証時はログイン画面を表示
- ログアウト機能

### 管理者アカウント
| 項目 | 値 |
|---|---|
| ログインURL | `/admin` |
| 認証方式 | Supabase Auth（メール・パスワード） |

---

## Admin画面一覧

| パス | コンポーネント | 概要 |
|---|---|---|
| `/admin` | `Dashboard` | ダッシュボード（各機能へのナビゲーション） |
| `/admin/events` | `Events` | イベント一覧 |
| `/admin/events/new` | `EventForm` | イベント新規作成 |
| `/admin/events/:id/edit` | `EventForm` | イベント編集 |
| `/admin/gallery` | `Gallery` | ギャラリー管理 |
| `/admin/stockists` | `Stockists` | 取扱店管理 |
| `/admin/reservations` | `Reservations` | WS予約一覧 |
| `/admin/collaborations` | `Collaborations` | コラボレーション管理 |
| `/admin/contacts` | `Contacts` | お問い合わせ管理 |

---

## 各機能詳細

### イベント管理 (`/admin/events`)
**一覧**
- 全イベント（開催予定・過去）を一覧表示
- イベント追加・編集・削除

**フォーム項目**
| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| イベント名 | TEXT | ○ | |
| 開始日 | DATE | ○ | |
| 終了日 | DATE | - | 複数日の場合 |
| 時間 | TEXT | - | 例: 10:00〜17:00 |
| 開催場所 | TEXT | ○ | |
| ブース番号 | TEXT | - | |
| 住所 | TEXT | - | |
| 公式URL | TEXT | - | |
| 関連ブランド | TEXT[] | - | 複数選択（ei8ht plants / Habitat Oides / HUE） |
| WS有無 | BOOLEAN | ○ | ワークショップあり |
| 予約必要 | BOOLEAN | ○ | 予約制かどうか |
| 過去フラグ | BOOLEAN | ○ | 過去イベントとして扱う |
| 画像URL | TEXT[] | - | 複数枚対応 |

---

### ギャラリー管理 (`/admin/gallery`)
**機能**
- 画像一覧表示（グリッド）
- 画像追加：URL・ALTテキスト・ブランド（任意）
- 画像削除

**フィールド**
| フィールド | 型 | 説明 |
|---|---|---|
| 画像URL | TEXT | 必須 |
| ALTテキスト | TEXT | 任意 |
| ブランド | TEXT | 任意（ei8ht plants / Habitat Oides / HUE） |

---

### 取扱店管理 (`/admin/stockists`)
**機能**
- 取扱店一覧（ブランドチップ付き）
- 追加フォーム
- 編集モーダル（名前・エリア・住所・URL・ブランドを変更可能）
- 削除

**フィールド**
| フィールド | 型 | 説明 |
|---|---|---|
| 店舗名 | TEXT | 必須 |
| エリア | TEXT | 例: 東京 |
| 住所 | TEXT | 任意 |
| URL | TEXT | 任意 |
| 取扱ブランド | TEXT[] | チェックボックスで複数選択 |

---

### WS予約管理 (`/admin/reservations`)
**機能**
- 予約一覧（受付日・名前・メール・電話・人数・備考・ステータス）
- ステータスをインラインで変更

**ステータス種別**
| 値 | 表示 |
|---|---|
| `pending` | 未確認 |
| `confirmed` | 確認済み |
| `cancelled` | キャンセル |

---

### コラボレーション管理 (`/admin/collaborations`)
**機能**
- コラボレーション一覧（サムネイル・タイトル・相手・日付）
- 追加フォーム
- 削除

**フィールド**
| フィールド | 型 | 説明 |
|---|---|---|
| タイトル | TEXT | 必須 |
| コラボ相手 | TEXT | 任意 |
| 開催日 | DATE | 任意 |
| 動画URL | TEXT | 任意 |
| 画像URL | TEXT | 任意 |
| 説明文 | TEXT | 任意（改行対応） |

---

### お問い合わせ管理 (`/admin/contacts`)
**機能**
- お問い合わせ一覧（新着順）
- 未読バッジ表示（未読件数）
- アコーディオンで内容展開
- 既読/未読の切替
- 返信リンク（mailto: で起動）

**表示項目**
| 項目 | 説明 |
|---|---|
| 名前 | |
| メールアドレス | |
| 受信日時 | |
| メッセージ本文 | アコーディオン展開で表示 |
| 既読状態 | 未読はオレンジドット + 黄色背景 |

## API呼び出し一覧（Admin）

| 操作 | メソッド | パス |
|---|---|---|
| イベント一覧取得 | GET | `/api/events?past=true/false` |
| イベント作成 | POST | `/api/events` |
| イベント更新 | PUT | `/api/events/{id}` |
| イベント削除 | DELETE | `/api/events/{id}` |
| ギャラリー追加 | POST | `/api/gallery` |
| ギャラリー削除 | DELETE | `/api/gallery/{id}` |
| 取扱店追加 | POST | `/api/stockists` |
| 取扱店更新 | PATCH | `/api/stockists/{id}` |
| 取扱店削除 | DELETE | `/api/stockists/{id}` |
| 予約一覧取得 | GET | `/api/reserves` |
| 予約ステータス更新 | PATCH | `/api/reserves/{id}` |
| コラボレーション追加 | POST | `/api/collaborations` |
| コラボレーション削除 | DELETE | `/api/collaborations/{id}` |
| お問い合わせ一覧取得 | GET | `/api/contacts` |
| 既読更新 | PATCH | `/api/contacts/{id}` |
