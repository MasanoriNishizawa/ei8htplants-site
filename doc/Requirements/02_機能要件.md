## 各ページ機能詳細

### ホーム (`/`)
- ヒーロービジュアル表示
- 直近イベント（ next event card）表示
- 各ブランドへの導線

### イベント一覧 (`/events`)
- APIから取得したイベントをグリッド表示
- 開催日・場所・ブランド・ブース番号を表示
- ワークショップあり／予約要のバッジ表示
- イベント画像スライドショー
- 予約ボタン（`/reserve?event_id=` へ遷移）

### ギャラリー (`/gallery`)
- ブランド別フィルタータブ（All / ei8ht plants / Habitat Oides / HUE）
- 選択タブに応じてAPIにブランドパラメータを渡してフィルタリング
- クリックでライトボックス表示（Escキーで閉じる）

### コンセプト (`/concept`)
- フィロソフィーテキスト（育てることを大切にする姿勢）
- Specialized Lines：3ブランドの紹介カード（各ブランドページへのリンク付き）

### お問い合わせ (`/contact`)
- フォーム項目：名前（必須）・メールアドレス（必須）・メッセージ（必須）
- 送信時：バックエンド経由でResend APIにてメール送信 + DBに保存
- 送信完了メッセージ表示

### 取扱店一覧 (`/stockists`)
- エリア別グループ表示
- 店舗名（URLがある場合はリンク）・住所
- 取扱ブランドのカラーチップ表示（ei8ht plants/Habitat Oides/HUE）
- 卸問い合わせ案内

### コラボレーション (`/collaborations`)
- DBから取得したコラボレーション記事の一覧
- 画像 or 動画 + タイトル・相手先・日付・説明文
- Habitat Oides ブランドページからリンク

### ブランドページ（共通）
- サブナビゲーション（IntersectionObserverによるアクティブ状態）
- ヒーローセクション
- セクションスクロール

#### ei8ht plants (`/ei8htplants`)
- Concept：アガベ専門の説明
- Store：オンラインストア（Square）へのリンク

#### Habitat Oides (`/habitatoides`)
- Concept：ハビタットスタイルの説明
- Workshop：ワークショップ案内（詳細ページへのリンク）
- Collaboration：動画表示 + 「View all collaborations →」リンク

#### HabitatOides Workshop (`/habitatoides/workshop`)
- About：ワークショップ概要（画像 + テキスト2カラム）
- Contents：3つのコンテンツカード
- Flow：3ステップの流れ
- Reservation CTA → `/events` へ誘導

#### HUE (`/hue`)
- Concept：カラープランツの説明 + カラースウォッチ
- アニメーションするカラーブロブ背景

### ワークショップ予約 (`/reserve`)
- URLパラメータ `event_id` を取得してイベントに紐付け
- フォーム項目：名前（必須）・メール（必須）・電話（任意）・参加人数（必須）・備考（任意）
- 送信時：DBに予約データを保存、ステータス `pending` で登録

## API呼び出し一覧

| 操作 | メソッド | パス |
|---|---|---|
| イベント一覧取得 | GET | `/api/events?past=false` |
| イベント詳細取得 | GET | `/api/events/{id}` |
| ギャラリー一覧取得 | GET | `/api/gallery?brand=` |
| 取扱店一覧取得 | GET | `/api/stockists` |
| お問い合わせ送信 | POST | `/api/contact` |
| 予約作成 | POST | `/api/reserve` |
| コラボレーション一覧取得 | GET | `/api/collaborations` |
