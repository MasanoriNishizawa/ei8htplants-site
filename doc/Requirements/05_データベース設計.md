# データベース設計

## 使用DB

Supabase（PostgreSQL）

---

## テーブル一覧

| テーブル名 | 概要 |
|---|---|
| `events` | イベント情報 |
| `event_images` | イベントに紐付く画像 |
| `gallery_images` | ギャラリー画像 |
| `stockists` | 取扱店 |
| `workshop_reservations` | ワークショップ予約 |
| `collaborations` | コラボレーション記事 |
| `contacts` | お問い合わせ内容 |

## テーブル定義

### `events`

| カラム | 型 | NULL | デフォルト | 説明 |
|---|---|---|---|---|
| `id` | UUID | NOT NULL | `gen_random_uuid()` | PK |
| `name` | TEXT | NOT NULL | — | イベント名 |
| `start_date` | DATE | NOT NULL | — | 開始日 |
| `end_date` | DATE | NULL | — | 終了日（複数日の場合） |
| `time` | TEXT | NULL | — | 時間帯（例: 10:00〜17:00） |
| `location` | TEXT | NOT NULL | — | 開催場所名 |
| `booth_number` | TEXT | NULL | — | ブース番号 |
| `address` | TEXT | NULL | — | 住所 |
| `official_url` | TEXT | NULL | — | 公式サイトURL |
| `brands` | TEXT[] | NULL | `'{}'` | 関連ブランド |
| `has_workshop` | BOOLEAN | NOT NULL | `false` | WSあり |
| `ws_requires_reservation` | BOOLEAN | NOT NULL | `true` | 予約制 |
| `is_past` | BOOLEAN | NOT NULL | `false` | 過去イベント |
| `display_order` | INT | NOT NULL | `0` | 表示順 |
| `created_at` | TIMESTAMPTZ | NOT NULL | `now()` | 作成日時 |

## Row Level Security (RLS) ポリシー

| テーブル | ロール | 操作 | 条件 |
|---|---|---|---|
| `events` | anon | SELECT | 常時許可 |
| `events` | service_role | ALL | 常時許可 |
| `event_images` | anon | SELECT | 常時許可 |
| `event_images` | service_role | ALL | 常時許可 |
| `gallery_images` | anon | SELECT | 常時許可 |
| `gallery_images` | service_role | ALL | 常時許可 |
| `stockists` | anon | SELECT | 常時許可 |
| `stockists` | service_role | ALL | 常時許可 |
| `workshop_reservations` | anon | INSERT | 常時許可 |
| `workshop_reservations` | service_role | ALL | 常時許可 |
| `collaborations` | anon | SELECT | 常時許可 |
| `collaborations` | service_role | ALL | 常時許可 |
| `contacts` | anon | INSERT | 常時許可 |
| `contacts` | service_role | ALL | 常時許可 |

> **注意**: `anon` ロールによる書き込みが必要なテーブル（`workshop_reservations`・`contacts`）はフロントエンドから直接Supabaseを呼ばず、バックエンドの `admin_supabase`（service_role）経由で挿入する。
