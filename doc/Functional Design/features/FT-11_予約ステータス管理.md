# FT-11 — 予約ステータス管理

## 概要

ワークショップ予約一覧の表示と、ステータスのインライン変更機能。ステータスはカラーバッジで視覚化し、セレクトボックスからワンクリックで更新できる。

## 使用ページ

| ページID | ページ名 | 操作 |
|---|---|---|
| [PG-A05](../pages/admin/PG-A05_Reservations.md) | WS予約管理 | 一覧取得・ステータス更新 |

## 実装ファイル

- `frontend/src/pages/admin/Reservations.tsx`
- `backend/app/routes/reserve.py`

## API

| 操作 | メソッド | パス |
|---|---|---|
| 一覧取得 | GET | `/api/reserves` |
| ステータス更新 | PATCH | `/api/reserves/{id}` |

## ステータス定義

| 値 | 表示ラベル | バッジ背景 | バッジ文字色 |
|---|---|---|---|
| `pending` | 未確認 | `#fff3cd` | `#856404` |
| `confirmed` | 確認済み | `#d4edda` | `#155724` |
| `cancelled` | キャンセル | `#f8d7da` | `#721c24` |

## 更新フロー

```
セレクトボックス変更（onChange）
    │
    ▼
setUpdating(id) → セレクトを disabled に
    │
    ▼
api.reserve.updateStatus(id, status)    （PATCH /api/reserves/{id} { status }）
    │
    ▼
setRows: ローカル state を楽観的更新（再fetchなし）
setUpdating(null)
```

## 表示項目

| カラム | 説明 |
|---|---|
| 受付日 | `created_at` を ja-JP 日付フォーマット |
| お名前 | `name` |
| メール | `email`（`mailto:` リンク） |
| 電話 | `phone`（null の場合 `-`） |
| 人数 | `participants` |
| 備考 | `note`（null の場合 `-`） |
| ステータス | カラーバッジ + セレクトボックス |

## 取得フロー

```
コンポーネントマウント
    │
    ▼
api.reserve.list()    （GET /api/reserves）
    │
    ▼
setRows（created_at 降順）
setLoading(false)
```
