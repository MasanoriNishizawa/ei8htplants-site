# FT-04 — ギャラリー

## 概要

ギャラリー画像の表示機能。ブランド別フィルタータブ、グリッドレイアウト、ライトボックス（クリック拡大表示）で構成される。

## 使用ページ

| ページID | ページ名 | 用途 |
|---|---|---|
| [PG-01](../pages/public/PG-01_Home.md) | Home | ギャラリーマーキー（横スクロール自動アニメーション） |
| [PG-03](../pages/public/PG-03_Gallery.md) | Gallery | ブランドフィルター + グリッド + ライトボックス |
| [PG-A03](../pages/admin/PG-A03_Gallery.md) | ギャラリー管理（Admin） | 画像追加・削除（ブランド指定） |

## 実装ファイル

`frontend/src/pages/Gallery.tsx`

---

## ブランドフィルタータブ

### 表示タブ

| ラベル | brand パラメータ |
|---|---|
| All | （パラメータなし） |
| ei8ht plants | `ei8ht plants` |
| Habitat Oides | `Habitat Oides` |
| HUE | `HUE` |

### 動作

1. タブクリック → `activeBrand` state 更新
2. `useEffect([activeBrand])` が発火 → `api.gallery.list(brand?)` 呼び出し
3. `brand` が `null` の場合はパラメータなしで全件取得
4. バックエンドで `brand` クエリパラメータがある場合は `WHERE brand = ?` フィルタリング

---

## ギャラリーグリッド

- CSS クラス `.gallery-grid` / `.gallery-item`（`frontend/src/index.css`）
- `aspect-ratio: 1/1`、`object-fit: cover` で正方形トリミング
- `loading="lazy"` で遅延読み込み
- 各 `.gallery-item` をクリックで `setLightbox(url)` 呼び出し

---

## ライトボックス

### 動作フロー

```
画像クリック
    │
    ▼
setLightbox(url) → lightbox state に URL を設定
    │
    ▼
オーバーレイ表示（fixed, zIndex: 2000, 黒背景 rgba(0,0,0,0.95)）
    │
    ├─ 拡大画像表示（maxWidth: 90%, maxHeight: 85%, objectFit: contain）
    ├─ × ボタン（右上）
    ├─ オーバーレイ背景クリック → setLightbox(null)
    └─ Escキー → setLightbox(null)
```

### body overflow ロック

- `lightbox` が truthy の間 `document.body.style.overflow = 'hidden'`
- ライトボックスを閉じると `overflow = ''` に戻す（useEffect クリーンアップ）

---

## ホームのマーキー

- `api.gallery.list()` で全件取得（ブランドフィルターなし）
- 取得した配列を2倍に複製（`[...gallery, ...gallery]`）して無限ループを実現
- CSS `@keyframes marquee` で translateX アニメーション（80秒周期）
- 両端に linear-gradient マスクを適用してフェードアウト演出

---

## データ取得

- `api.gallery.list(brand?)` → GET `/api/gallery?brand=` （[FT-02](FT-02_APIクライアント.md)）
- フィルター変更のたびに再取得し `setLoading(true)` でローディング表示
