# FT-03 — イベント表示

## 概要

イベントカード（`EventCard` コンポーネント）のレンダリング機能。開催情報・ブランドバッジ・WS情報・画像スライドショー・予約ボタンを表示する。

## 使用ページ

| ページID | ページ名 | 用途 |
|---|---|---|
| [PG-01](../pages/public/PG-01_Home.md) | Home | 直近イベント1件（isHome / isNext prop付き） |
| [PG-02](../pages/public/PG-02_Events.md) | Events | 全イベント一覧グリッド |

## 実装ファイル

`frontend/src/components/EventCard.tsx`

## Props

| prop | 型 | 説明 |
|---|---|---|
| `event` | `Event` | 表示するイベントデータ |
| `isNext` | boolean | 直近イベント強調表示 |
| `isHome` | boolean | ホームページ用レイアウト（最大幅制限） |

## 表示項目

| 項目 | 条件 |
|---|---|
| イベント名 | 常時 |
| 開催日（start_date / end_date） | 常時、end_dateがある場合は〜で連結 |
| 開催時間 | time が存在する場合 |
| 会場名・住所 | 常時 |
| ブース番号 | booth_number が存在する場合 |
| 公式サイトリンク | official_url が存在する場合 |
| ブランドバッジ | brands[] 各要素 |
| WS開催バッジ | has_workshop = true の場合 |
| 予約必要バッジ | ws_requires_reservation = true の場合 |
| 予約ボタン | has_workshop && ws_requires_reservation の場合 |
| 画像スライドショー | images[] が1枚以上ある場合 |

## 画像スライドショー

- `images[]` を自動ループ（setInterval、4秒間隔）
- 画像が複数ある場合はドットインジケーター表示
- ドットクリックで任意のスライドへ移動

## 予約ボタン

- `Link to={/reserve?event_id=${event.id}}` で遷移
- [FT-06](FT-06_予約フォーム.md) の予約フォームに event_id を渡す

## データ取得

- `api.events.list(false)` — 開催予定イベント取得（[FT-02](FT-02_APIクライアント.md)）
- `api.events.list(true)` — 過去イベント取得（Admin側）
- Homeでは取得後に `start_date` 昇順でソートして先頭1件を使用
