# FT-09 — お問い合わせ管理

## 概要

管理者がお問い合わせ一覧を確認・既読管理する機能。未読件数バッジ、アコーディオン展開、既読/未読トグル、返信リンクを提供する。

## 使用ページ

| ページID | ページ名 | 操作 |
|---|---|---|
| [PG-A07](../pages/admin/PG-A07_Contacts.md) | お問い合わせ管理 | 一覧取得・既読更新 |

## 実装ファイル

- `frontend/src/pages/admin/Contacts.tsx`
- `backend/app/routes/contact.py`

## API

| 操作 | メソッド | パス |
|---|---|---|
| 一覧取得 | GET | `/api/contacts` |
| 既読更新 | PATCH | `/api/contacts/{id}` |

## データモデル

```ts
interface ContactRecord {
  id: string
  name: string
  email: string
  message: string
  is_read: boolean
  created_at: string
}
```

## 画面構成

### 未読バッジ

- ヘッダー横に未読件数をバッジ表示
- `contacts.filter(c => !c.is_read).length` で算出
- 0件の場合は非表示

### 一覧アイテム

| 要素 | 説明 |
|---|---|
| 未読ドット | `is_read=false` の場合、オレンジドット表示 |
| 背景色 | 未読: `#fef9f0`（薄黄）、既読: `#fffcf6`（通常） |
| 枠線色 | 未読: `#e8c870`（黄）、既読: `#ddd4c0`（通常） |
| 名前・メール | 常時表示 |
| 受信日時 | ja-JP フォーマット（年月日 時:分） |
| 展開アイコン | アコーディオン状態に応じて▼回転 |

### アコーディオン展開

- アイテムクリック → `expanded` state でIDを管理
- 展開時：メッセージ本文（`white-space: pre-wrap`）と返信リンク（`mailto:`）を表示
- 同じアイテムを再度クリックで閉じる（`expanded === id ? null : id`）

### 既読/未読トグル

```
「既読にする」ボタンクリック（未読の場合）
    │
    ▼
api.contact.markRead(id, true)    （PATCH /api/contacts/{id} { is_read: true }）
    │
    ▼
setContacts でローカル state を楽観的更新
（再fetchなし）
```

- ボタンラベル：未読 → 「既読にする」、既読 → 「未読に戻す」

## 取得フロー

```
コンポーネントマウント
    │
    ▼
api.contact.list()    （GET /api/contacts）
    │
    ▼
setContacts（新着順）
setLoading(false)
```
