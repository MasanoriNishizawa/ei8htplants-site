# PG-A02 — イベント管理（Admin）

## 概要

イベントの一覧表示・追加・編集・削除を行う管理画面。一覧と作成/編集フォームの2つのビューで構成される。

## URL / ルート

| ビュー | URL |
|---|---|
| 一覧 | `/admin/events` |
| 新規作成フォーム | `/admin/events/new` |
| 編集フォーム | `/admin/events/:id/edit` |

## 実装ファイル

- `frontend/src/pages/admin/Events.tsx`（一覧）
- `frontend/src/pages/admin/EventForm.tsx`（作成・編集フォーム）
