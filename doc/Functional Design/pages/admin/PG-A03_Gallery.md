# PG-A03 — ギャラリー管理（Admin）

## 概要

ギャラリー画像の追加・削除を行う管理画面。画像URL・ALTテキスト・ブランドを指定して登録できる。

## URL / ルート

`/admin/gallery`

## 実装ファイル

`frontend/src/pages/admin/Gallery.tsx`

## 使用機能（FT紐付け）

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-01](../../features/FT-01_認証.md) | 認証 | AdminLayout による認証ガード |
| [FT-02](../../features/FT-02_APIクライアント.md) | APIクライアント | `api.gallery.list()` 呼び出し |
| [FT-04](../../features/FT-04_ギャラリー.md) | ギャラリー | 画像グリッド表示・ブランド紐付け |

## 画面レイアウト

```

│ [画像URL         ] [ALT ] [ブランド▼] [追加] │

│ グリッド                             │
│  ┌─────┐┌─────┐┌─────┐             │

│  │ [×] ││ [×] ││ [×] │            │
│  │ブランドバッジ │                   │
│  └─────┘└─────┘└─────┘             │
└─────────────────────────────────────┘
```

## 追加フォーム

| フィールド | 説明 |
|---|---|
| 画像URL（必須） | `type="url"` |
| ALTテキスト（任意） | テキスト入力 |
| ブランド（任意） | セレクトボックス（All / ei8ht plants / Habitat Oides / HUE） |

## 追加・削除フロー

- **追加**: `POST /api/gallery { url, alt, brand }` → 一覧再取得
- **削除**: `×` ボタン → `DELETE /api/gallery/{id}` → 一覧再取得

## 画像グリッド

- `aspect-ratio: 1/1` 正方形
- 各画像に `brand` バッジ（左下、半透明黒背景）
- `×` ボタン（右上）で削除
