# PG-A06 — コラボレーション管理（Admin）

## 概要

コラボレーション記事の追加・削除を行う管理画面。

## URL / ルート

`/admin/collaborations`

## 実装ファイル

`frontend/src/pages/admin/Collaborations.tsx`

## 使用機能（FT紐付け）

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-01](../../features/FT-01_認証.md) | 認証 | AdminLayout による認証ガード |
| [FT-02](../../features/FT-02_APIクライアント.md) | APIクライアント | `api.collaborations.*` 呼び出し |
| [FT-08](../../features/FT-08_コラボレーションCRUD.md) | コラボレーションCRUD | 一覧・追加・削除 |

## 画面レイアウト

```
┌─────────────────────────────────────┐
│ コラボレーション管理                 │
├─────────────────────────────────────┤
│ 追加フォーム（2カラムグリッド）      │
│  [タイトル（必須）                 ] │
│  [コラボ相手  ] [開催日   ]         │
│  [動画URL     ] [画像URL  ]         │
│  [説明文（textarea）               ] │
│  [追加]                             │
├─────────────────────────────────────┤
│ ┌──────┬──────────────────────────┐  │
│ │サムネ│ タイトル                 │  │
│ │       │ コラボ相手 / 日付       │  │
│ │       │ 説明文（プレビュー）    │  │[削除]
│ └──────┴──────────────────────────┘  │
└─────────────────────────────────────┘
```
