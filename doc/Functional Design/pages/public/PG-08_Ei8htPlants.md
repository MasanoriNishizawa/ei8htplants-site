# PG-08 — ei8ht plants

## 概要

ei8ht plants ブランドページ。アガベ専門ラインのコンセプトとオンラインストアへの導線を提供する。

## URL / ルート

`/ei8htplants`

## 実装ファイル

`frontend/src/pages/brands/Ei8htPlants.tsx`

## 使用機能（FT紐付け）

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-07](../../features/FT-07_ブランドサブナビゲーション.md) | ブランドサブナビゲーション | concept / store セクション連動ナビ |

## セクション構成

| セクションID | ラベル | 内容 |
|---|---|---|
| `concept` | Concept | アガベ専門の説明文・ロゴ画像 |
| `store` | Store | オンラインストア（Square）CTA |

## 画面レイアウト

```
┌─────────────────────────────────┐
│ ヒーロー（.ep-hero）            │
│  ・サブナビ（concept / store）  │
│  ・"Agave Specialist" テキスト  │
│  ・ei8ht plants テキストロゴ    │
│  ・スクロールヒントライン       │
├─────────────────────────────────┤
│ Concept セクション              │
│  ┌──────────┬─────────────────┐ │
│  │ロゴ画像  │ "Agave          │ │
│  │          │ Specialist"     │ │
│  │          │ テキスト        │ │
│  └──────────┴─────────────────┘ │
├─────────────────────────────────┤
│ Store セクション（黒背景）      │
│  ・"Online Store" 見出し        │
│  ・"Shop now →" ボタン          │
│  ・Square オンラインストアへ    │
└─────────────────────────────────┘
```

## CSS クラス

- `.ep-hero`：白系背景画像ヒーロー
- `.brand-concept-grid`：2カラムグリッド（ロゴ + テキスト）

## 画面遷移

| 操作 | 遷移先 |
|---|---|
| Shop now → | Square オンラインストア（外部リンク） |
