# PG-11 — HUE

## 概要

HUE by ei8ht plants ブランドページ。カラープランツのコンセプトを、アニメーション付きカラーブロブで視覚的に表現する。

## URL / ルート

`/hue`

## 実装ファイル

`frontend/src/pages/brands/Hue.tsx`

## 使用機能（FT紐付け）

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-07](../../features/FT-07_ブランドサブナビゲーション.md) | ブランドサブナビゲーション | concept / follow セクション連動ナビ |

## セクション構成

| セクションID | ラベル | 内容 |
|---|---|---|
| `concept` | Concept | カラープランツ説明文・カラースウォッチ |
| `follow` | Follow | Instagram フォロー導線 |

## 画面レイアウト

```

│   （.hue-blob-1〜5、各固有色） │

├─────────────────────────────────┤

└─────────────────────────────────┘
```

## カラーブロブアニメーション

`index.css` に `@keyframes hueBlob1〜5` を定義。各ブロブが独立した動き（translate + scale + blur）で有機的に浮遊する。

| クラス | 色 | アニメーション |
|---|---|---|
| `.hue-blob-1` | `rgba(220,170,100,0.45)` | hueBlob1（16s） |
| `.hue-blob-2` | `rgba(160,210,130,0.35)` | hueBlob2（20s） |
| `.hue-blob-3` | `rgba(190,130,200,0.4)` | hueBlob3（18s） |
| `.hue-blob-4` | `rgba(240,190,90,0.35)` | hueBlob4（22s） |
| `.hue-blob-5` | `rgba(130,190,220,0.3)` | hueBlob5（14s） |

## カラースウォッチ

コンセプトセクションに `width: 40px; height: 40px; borderRadius: 50%` の円形スウォッチを6色表示。
