# PG-05 — Contact

## 概要

お問い合わせフォームページ。送信するとメール通知（Resend）とDB保存（contacts テーブル）が行われる。

## URL / ルート

`/contact`

## 実装ファイル

`frontend/src/pages/Contact.tsx`

## 使用機能（FT紐付け）

| 機能ID | 機能名 | 用途 |
|---|---|---|
| [FT-02](../../features/FT-02_APIクライアント.md) | APIクライアント | `api.contact.send(body)` 呼び出し |
| [FT-05](../../features/FT-05_お問い合わせフォーム.md) | お問い合わせフォーム | フォーム送信・状態管理・エラー処理 |

## 画面レイアウト

```
┌─────────────────────────────────┐
│ ページヘッダー                  │
│  ・ラベル「ei8ht plants」       │
│  ・見出し「Contact」            │
│  ・説明文                       │
├─────────────────────────────────┤
│ フォームカード（白背景・枠線）  │
│  ─ お客様情報 ──────────────── │
│  ・お名前（必須）               │
│  ・メールアドレス（必須）       │
│  ─ お問い合わせ内容 ─────────── │
│  ・メッセージ（必須）           │
│  ・エラーメッセージ（失敗時）   │
│  ・「送信する」ボタン           │
├─────────────────────────────────┤
│ 送信完了メッセージ（done時）    │
│  ・「お問い合わせを受け付けました。」│
└─────────────────────────────────┘
```

## フォームの状態遷移

```
idle → loading（送信中）→ done（成功）
                        → error（失敗）→ idle に戻らず再試行可
```
