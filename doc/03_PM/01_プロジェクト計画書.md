## 5. 開発環境セットアップ

```bash
# リポジトリクローン後

# フロントエンド
cd frontend
npm install
# frontend/.env を作る（項目は移行計画書の Step 2。.env.example は無い）
npm run dev           # http://localhost:5173 で起動（実 API に接続）
npm run mock          # http://localhost:5173 で起動（MSW モック使用、バックエンド不要）
npm test              # Vitest 単体テスト実行
npx tsc --noEmit -p tsconfig.app.json  # TypeScript 型チェック（tsconfig.app.json を指定しないと何も検査しない）

# バックエンド
cd ../backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
# プロジェクト直下に .env を作る（項目は移行計画書の Step 2。.env.example は無い）
uvicorn app.main:app --reload --port 8000
python -m pytest      # pytest 単体テスト実行
# テストの実行（結果は doc/04_TEST/08_テスト実行ログ.md に追加される）
# 流すのは変えたものに関連するテストだけ（選び方は CLAUDE.md の「どのテストを流すか」）
cd ..
python scripts/run_tests.py --note "何を変えたか" --vitest <関連するファイル> --e2e <関連するファイル> --pytest <関連するファイル>
# 全体に関わる変更（認証・ルーティング・ビルドの設定など）のときだけ、何も絞らずに全部
python scripts/run_tests.py --note "何を変えたか"
```
