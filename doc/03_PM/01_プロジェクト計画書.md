## 4. コミュニケーションルール

| 項目 | 方針 |
|---|---|
| 開発方針の記録 | Git コミットメッセージ + `doc/` の設計書で管理 |
| 課題・バグ管理 | `doc/PM/04_課題・リスク管理表.md` に記録 |

| 秘匿情報 | `.env` ファイルは Git 管理外。共有方法は別途取り決め |

## 5. 開発環境セットアップ

```bash
# リポジトリクローン後

# フロントエンド
cd frontend
npm install
cp .env.example .env  # 環境変数設定
npm run dev           # http://localhost:5173 で起動

# バックエンド
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # 環境変数設定
uvicorn app.main:app --reload --port 8000
```

## 6. ブランチ戦略

| ブランチ | 用途 |
|---|---|
| `main` | 本番対応コード。直接pushは原則禁止 |
| `feature/*` | 機能追加作業ブランチ（任意） |

現状: 小規模1人開発のため `main` への直接コミットも許容。  
規模拡大時はプルリクエストベースに移行推奨。
