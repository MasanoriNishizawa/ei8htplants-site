# PM-06 — プロジェクト全体リファクタリング計画

## 1. 目的と進め方

この計画は、既存機能の動作を保ちながら、テスト実行基盤と大きな責務を持つファイルを段階的に整理するためのものです。最初にテスト実行時の安全性と結果記録を整え、その後フロントエンド、バックエンドの順に進めます。

各段階は小さな変更に分け、変更対象に対応するテストを実行してから次へ進みます。予約・イベント・注文などデータ更新や外部サービス連携を含む処理は、失敗時の挙動を確認するテストが揃うまで分割に着手しません。画面/APIの仕様、URL、保存データ、SEO出力に意図しない変更がないことも確認します。
