## 1. フロントエンド 単体テスト

### UT-FE-01: formatDate 関数（EventCard.tsx）

| ケース | 入力 | 期待出力 |
|---|---|---|
| 正常: 通常日付 | `"2024-10-01"` | `"2024年10月1日"` |
| 正常: 月・日が1桁 | `"2024-01-05"` | `"2024年1月5日"` |
| 正常: 12月31日 | `"2024-12-31"` | `"2024年12月31日"` |

### UT-FE-02: EventCard 画像インデックス循環（EventCard.tsx）

| ケース | 操作 | 初期 imgIdx | 期待 imgIdx |
|---|---|---|---|
| 次へ（通常） | [>] クリック | 0 | 1 |
| 次へ（末尾循環） | [>] クリック（images.length=3, imgIdx=2） | 2 | 0 |
| 前へ（通常） | [<] クリック | 1 | 0 |
| 前へ（先頭循環） | [<] クリック（images.length=3, imgIdx=0） | 0 | 2 |

### UT-FE-03: api.ts request 関数

| ケース | HTTPレスポンス | 期待動作 |
|---|---|---|
| 正常: 200 OK | `{data: [...]}` | データを返す |
| 異常: 404 Not Found | ステータス404 | `Error("404 Not Found")` をスロー |
| 異常: 500 Error | ステータス500 | `Error("500 Internal Server Error")` をスロー |

### UT-FE-04: Contact フォーム statusマシン

| ケース | 操作 | 期待 status |
|---|---|---|
| 初期状態 | — | `'idle'` |
| 送信ボタンクリック | submit | `'loading'` |
| API成功 | `api.contact.send()` resolve | `'done'` |
| API失敗 | `api.contact.send()` reject | `'error'` |
| 成功後のフォームリセット | `status='done'` 時 | `form = {name:'', email:'', message:''}` |

### UT-FE-05: Gallery ブランドフィルタ

| ケース | activeBrand | 期待される API 呼び出し |
|---|---|---|
| 全件 | `null` | `GET /api/gallery`（brnadパラメータなし） |
| ei8ht plants | `'ei8ht plants'` | `GET /api/gallery?brand=ei8ht%20plants` |
| HUE | `'HUE'` | `GET /api/gallery?brand=HUE` |

## 2. バックエンド 単体テスト

### UT-BE-01: _attach_images 関数（events.py）

| ケース | 入力 | 期待出力 |
|---|---|---|
| 正常: 複数イベント | `events=[{id:A},{id:B}]` + `imgs=[{event_id:A,...},{event_id:B,...}]` | 各イベントに `images` 配列が付与される |
| 空イベント | `events=[]` | `[]` を返す（Supabase呼び出しなし） |
| 画像なし | `events=[{id:A}]`, `imgs=[]` | `events[0].images = []` |

### UT-BE-02: _save_images 関数（events.py）

| ケース | 入力 | 期待動作 |
|---|---|---|
| 画像あり | `urls=['url1','url2']` | `event_images` に2件INSERT（display_order: 0, 1） |
| 画像なし | `urls=[]` | INSERT しない（即リターン） |

### UT-BE-03: list_gallery 関数（gallery.py）

| ケース | クエリパラメータ | 期待SQLクエリ |
|---|---|---|
| 全件 | `brand=None` | `SELECT * WHERE （条件なし）` |
| ブランド指定 | `brand='HUE'` | `SELECT * WHERE brand='HUE'` |
| 空文字 | `brand=''` | `SELECT * WHERE （条件なし）`（falsy判定） |

### UT-BE-04: EmailStr バリデーション（contact.py / reserve.py）

| ケース | 入力 email | 期待動作 |
|---|---|---|
| 正常 | `"taro@example.com"` | バリデーション通過 |
| 異常: @なし | `"taroexample"` | 422 Unprocessable Entity |
| 異常: ドメインなし | `"taro@"` | 422 Unprocessable Entity |

## 3. 現状と自動化方針

本プロジェクトでは現時点で自動テストフレームワーク（Jest / pytest）は導入していない。  
上記テストケースは手動での動作確認または目視確認で実施する。

自動化の検討:
- フロントエンド: Vitest + React Testing Library（規模拡大時）
- バックエンド: pytest + FastAPI TestClient（規模拡大時）
