# TEST-03 — 結合テスト仕様書 (Integration Test Specification)

対応設計書: `doc/BD/`  
テスト粒度: フロントエンド ⇔ バックエンド API の実際の通信動作確認

前提: ローカル環境で Vite dev server（5173）+ uvicorn（8000）が起動していること

---

## 1. Events API 結合テスト

### IT-01: イベント一覧取得

| ケース | 手順 | 期待結果 |
|---|---|---|
| 開催予定一覧 | `GET /api/events?past=false` | `is_past=false` のイベント配列が返る。各要素に `images` 配列が含まれる |
| 過去一覧 | `GET /api/events?past=true` | `is_past=true` のイベント配列が返る |
| 単件取得 | `GET /api/events/<valid_uuid>` | 対象イベントが返る |
| 存在しないID | `GET /api/events/<invalid_uuid>` | `404 {"detail":"Not Found"}` |

### IT-02: イベント作成・更新・削除

| ケース | 手順 | 期待結果 |
|---|---|---|
| 作成（画像あり） | `POST /api/events` with `image_urls:["url1","url2"]` | `events` に1件、`event_images` に2件 INSERT。レスポンスに `images` 配列が含まれる |
| 更新（画像全置換） | `PUT /api/events/<id>` with `image_urls:["new_url"]` | 旧 `event_images` が削除され、新しい1件が INSERT される |
| 削除 | `DELETE /api/events/<id>` | イベントと紐付く `event_images` がカスケード削除される |

## 7. Admin API 認証テスト

### IT-09: Bearer トークン検証

| ケース | 手順 | 期待結果 |
|---|---|---|
| 認証なし — Admin POST | `POST /api/events` に `Authorization` ヘッダーなしでリクエスト | `401 {"detail":"Unauthorized"}` |
| 無効トークン — Admin POST | `Authorization: Bearer invalid_token` でリクエスト | `401 {"detail":"Unauthorized"}` |
| 有効トークン — Admin POST | ログイン後のセッショントークンを Bearer で送信 | `200` / `201` が返る |
| 認証なし — Admin GET | `GET /api/contacts` に `Authorization` ヘッダーなし | `401 {"detail":"Unauthorized"}` |
| 認証なし — 公開 GET | `GET /api/events` に `Authorization` ヘッダーなし | `200` が返る（公開エンドポイントは認証不要） |
| 認証なし — 予約 POST | `POST /api/reserve` に `Authorization` ヘッダーなし | `200` が返る（一般ユーザー向けエンドポイント） |
