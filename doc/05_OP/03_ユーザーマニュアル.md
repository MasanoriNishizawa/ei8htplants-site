# OP-03 — ユーザーマニュアル (User Manual)

対象者: ei8ht plants 管理者（サイトオーナー）  
前提: Google Chrome またはSafariの最新版を使用

---

## 1. 管理画面へのアクセス

1. ブラウザで `https://<サイトURL>/admin` を開く
2. メールアドレスとパスワードを入力して[ログイン]をクリック
3. サイドバーに管理メニューが表示されたらログイン完了

---

## 2. イベントを追加する

1. サイドバーの[イベント]をクリック
2. [+ 新規イベント]ボタンをクリック
3. フォームに入力する

   | 項目 | 入力内容 |
   |---|---|
   | イベント名 | 必須。例: 「GREEN EXPO 2024」 |
   | 開始日 | 必須。カレンダーから選択 |
   | 終了日 | 複数日の場合のみ入力 |
   | 時間 | 例: 「11:00〜17:00」 |
   | 開催場所 | 必須。例: 「東京ビッグサイト」 |
   | 住所 | 任意 |
   | ブランド | 出展するブランドにチェック |
   | ワークショップあり | WS開催の場合にチェック |
   | 画像URL | Google DriveやSNSの画像URLを入力。[+ 画像追加]で複数枚登録可能 |

4. [保存]をクリック
5. 公開ページの `/events` に反映されていることを確認

---

## 3. イベントを編集・削除する

**編集**:
1. [イベント]一覧で対象イベントの[編集]をクリック
2. 内容を変更して[保存]

**削除**:
1. 対象イベントの[削除]をクリック
2. 確認ダイアログで[OK]

---

## 4. ギャラリー画像を追加・削除する

**追加**:
1. サイドバーの[ギャラリー]をクリック
2. 上部フォームに画像URLを入力
3. ブランドを選択（任意）
4. [追加]をクリック

**削除**:
1. 削除したい画像の右上[×]をクリック

---

## 5. 取扱店を管理する

**追加**:
1. [取扱店]をクリック
2. フォームに店舗名・エリア・住所・URLを入力
3. 取扱ブランドにチェック
4. [追加]をクリック

**編集**:
1. 対象店舗の[編集]をクリック
2. モーダルで内容を変更
3. [保存]をクリック

**削除**:
1. 対象店舗の[削除]をクリック

---

## 6. ワークショップ予約を確認する

1. サイドバーの[WS予約]をクリック
2. 予約一覧が表示される
3. ステータスを変更する場合は、ステータス列のプルダウンから選択
   - **未確認**: 初期状態
   - **確認済**: 予約確認完了
   - **キャンセル**: キャンセル扱い

---

## 7. お問い合わせを確認・対応する

1. サイドバーの[お問い合わせ]をクリック
2. **未読件数**がヘッダーに表示される
3. 行をクリックするとメッセージ内容が展開される
4. [既読にする]をクリックして対応済みにマーク
5. [返信する (メール)] をクリックするとメールアプリが起動し、返信できる

---

## 8. コラボレーション記事を管理する

**追加**:
1. [コラボレーション]をクリック
2. フォームにタイトル・コラボ相手・日付・画像URL等を入力
3. [追加]をクリック

**削除**:
1. 対象記事の[削除]をクリック

---

## 9. 画像URLの取得方法（Google Drive）

1. Google Drive で画像ファイルを右クリック → [共有]
2. 「リンクを知っている全員」に変更して[リンクをコピー]
3. コピーされたURL（例: `https://drive.google.com/file/d/<ID>/view?usp=sharing`）を加工:
   ```
   https://drive.google.com/uc?export=view&id=<ID>
   ```
4. 加工したURLを管理画面のURL欄に入力

---

## 10. ログアウト

サイドバー下部の[ログアウト]ボタンをクリック。

---

## 11. 困ったときは

| 症状 | 対処 |
|---|---|
| ログインできない | メールアドレス・パスワードを確認。わからない場合は開発者に連絡 |
| 変更が公開ページに反映されない | ブラウザを強制リロード（Ctrl+Shift+R / Cmd+Shift+R） |
| 画像が表示されない | URLが正しいか確認。Google Driveの場合は共有設定を確認 |
| その他 | 開発者（masanorinishizawa）に連絡 |
