| 列名 | 型 | 説明 |

| 終了日 | 日付（YYYY-MM-DD） | イベント開催終了日。空欄時は開始日と同日として扱う |
| イベント名 | テキスト | 管理画面・予約フォームで使用するキー |

| 場所 | テキスト | 会場名 |
| ブース番号 | テキスト | ブース番号（任意） |

| 公式サイトURL | URL | イベントの外部サイト |

| WS予約URL | URL | （現在未使用。旧 GAS 連携の名残） |

**備考**:
- `_row` フィールドはシートには存在せず、コード内でシート行番号（1-indexed）として付与する
- `WSフラグ = TRUE` かつ `終了日 >= 今日` のイベントのみ予約フォームへのリンクが表示される

## 3. WS予約シート（`WS予約`）

初回予約時に自動作成。列が不足している場合は `_ensure_cancel_columns()` が自動追加する。

| 列 | 列名 | 型 | 説明 |
|---|---|---|---|
| A | タイムスタンプ | "YYYY-MM-DD HH:MM:SS"（JST） | 予約受付日時 |
| B | イベント名 | テキスト | イベントシートの「イベント名」と一致 |
| C | お名前 | テキスト | |
| D | メール | メールアドレス | 確認メール・キャンセルメールの送信先 |
| E | 希望日 | "YYYY-MM-DD" | |
| F | 希望時間帯 | "HH:MM-HH:MM" | 例: "11:00-12:00" |
| G | 参加人数 | 数値（文字列として保存） | 残席計算に使用 |
| H | お持ち込み | テキスト（カンマ区切り） | 例: "植木鉢, 植物" |
| I | 備考 | テキスト | 自由記入欄 |
| J | キャンセルトークン | UUID v4 | 予約時に生成。キャンセルリンクで使用 |
| K | キャンセル済み | "TRUE" / "" | キャンセル済みは "TRUE" |
| L | キャンセル理由 | テキスト | キャンセル時に任意入力 |
| M | キャンセル日時 | "YYYY-MM-DD HH:MM:SS"（JST） | |
| N | メモ | テキスト | 管理者が自由に記入するメモ |

**インデックス**:
- 残席計算: `col_values` で B列（イベント名）、E列（希望日）、F列（希望時間帯）、G列（参加人数）を参照
- キャンセル処理: J列でトークンを検索してから K・L・M 列を更新
- メモ更新: N列の `row_num` 行目を直接書き込む

## 7. データ整合性の注意点

| 項目 | 注意 |
|---|---|
| イベント名の一致 | WS予約のイベント名はイベントシートの「イベント名」と完全一致する必要がある。予約後にイベント名を変更すると関連付けが壊れる |
| 日付フォーマット | Sheets が自動で "YYYY/MM/DD" に変換することがある。`parse_date()` でハイフン・スラッシュ両対応 |
| 列の追加 | `_ensure_cancel_columns()` は既存列は変更しない。列を手動削除するとコードがクラッシュする可能性がある |
| タイムゾーン | `datetime.now(_JST)` で JST 記録。サーバーのシステム時刻に依存しない |
