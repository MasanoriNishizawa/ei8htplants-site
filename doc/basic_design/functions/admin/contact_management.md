# 機能設計：お問い合わせ管理

## 概要

管理画面からのお問い合わせ一覧の参照機能。  
閲覧のみ（削除・返信機能なし）。

---

## 処理フロー

```
GET /admin/contacts

get_all_contacts_for_admin()
  → ws.get_all_records()  ← お問い合わせシート全件
  → タイムスタンプ降順でソート

テンプレート admin_contacts.html に渡す
```
