# 画面設計：お問い合わせ

## 基本情報

| 項目 | 値 |
|---|---|
| URL | `/contact` / `/contact?sent=1` |
| テンプレート | `templates/contact.html` |
| 認証 | 不要 |

---

## レイアウト

```
┌─────────────────────────────────┐
│  CONTACT                        │
├─────────────────────────────────┤
│  [お名前]                       │
│  [メールアドレス]                 │
│  [件名]                         │
│  [メッセージ]                    │
│                                 │
│  [送信する]                      │
└─────────────────────────────────┘
```

送信後（`?sent=1`）:
```
┌─────────────────────────────────┐
│  お問い合わせを受け付けました      │
│  確認メールをお送りしました        │
└─────────────────────────────────┘
```

---

## フォーム項目

| 項目名 | タイプ | 必須 |
|---|---|---|
| name | テキスト | ○ |
| email | email | ○ |
| subject | テキスト | ○ |
| message | テキストエリア | ○ |

---

## 状態遷移

```
GET /contact → フォーム表示
POST /contact
  → Sheets 書き込み
  → 通知メール送信（バックグラウンド）
  → 確認メール送信（バックグラウンド）
  → 303 Redirect /contact?sent=1
```
