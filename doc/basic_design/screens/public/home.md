# 画面設計：ホーム

## 基本情報

| 項目 | 値 |
|---|---|
| URL | `/` |
| テンプレート | `templates/home.html` |
| 認証 | 不要 |

---

## レイアウト

```
┌─────────────────────────────┐
│  ナビゲーション               │
├─────────────────────────────┤
│  HERO / ブランドロゴ          │
├─────────────────────────────┤
│  NEXT EVENT                 │
│  ┌───────────────────────┐  │
│  │ イベント名              │  │
│  │ 日付  /  場所          │  │
│  │ [予約する] ← WSフラグ時 │  │
│  └───────────────────────┘  │
├─────────────────────────────┤
│  GALLERY（マーキー無限スクロール）│
├─────────────────────────────┤
│  フッター                    │
└─────────────────────────────┘
```

---

## 表示データ

| データ | 取得元 | 条件 |
|---|---|---|
| NEXT EVENT | イベントシート | 終了日 >= 今日 の最初の1件 |
| ギャラリー画像 | Google Drive | 全ブランドから最大8枚ずつランダム |

- イベントがない場合、NEXT EVENT セクションは非表示
- `WSフラグ = TRUE` のイベントのみ「予約する」ボタンを表示（`/reserve?row=N`）
