# 画面設計：WS予約フォーム

## 基本情報

| 項目 | 値 |
|---|---|
| URL | `/reserve?row=N` |
| テンプレート | `templates/reserve.html` |
| 認証 | 不要 |

---

## レイアウト

```
┌─────────────────────────────────┐
│  イベント名 / 日付 / 場所         │
├─────────────────────────────────┤
│  [希望日] セレクトボックス         │
│  [時間帯] セレクトボックス（連動）  │
│  [参加人数] セレクトボックス（連動）│
├─────────────────────────────────┤
│  [お名前]                       │
│  [メールアドレス]                 │
│  [お持ち込み] チェックボックス      │
│    □ 植木鉢  □ 植物             │
│  [備考] テキストエリア             │
├─────────────────────────────────┤
│  [予約を申し込む]                 │
│  ※ 送信後はスピナー表示・ボタン無効│
└─────────────────────────────────┘
```

---

## フォーム項目

| 項目名 | タイプ | 必須 | 備考 |
|---|---|---|---|
| 希望日 | セレクト | ○ | 開始日〜終了日の日付一覧 |
| 時間帯 | セレクト | ○ | 希望日に連動して変化 |
| 参加人数 | セレクト | ○ | 残席数に連動。残席0なら選択不可 |
| お名前 | テキスト | ○ | |
| メールアドレス | email | ○ | |
| お持ち込み | チェックボックス（複数） | - | 植木鉢 / 植物 |
| 備考 | テキストエリア | - | |
| row（隠し） | hidden | ○ | イベントの行番号 |
| event_name（隠し） | hidden | ○ | イベント名 |

---

## 予約完了モーダル

送信成功後、同ページに戻ったとき（セッションに `reserve_flash` あり）に表示する。

```
┌────────────────────────────────┐
│  予約を受け付けました            │
│  確認メールをお送りしました       │
│  [閉じる] → /events へ遷移     │
└────────────────────────────────┘
```

---

## 状態遷移

```
GET /reserve?row=N
  → （WSフラグ != TRUE）→ /events にリダイレクト
  → フォーム表示

POST /reserve
  → Sheets 書き込み
  → 303 Redirect GET /reserve?row=N
    → セッションの reserve_flash を読んでモーダル表示
```

---

## パラメータ

| パラメータ | 型 | 説明 |
|---|---|---|
| `row` | integer | イベントシートの行番号。省略時は /events にリダイレクト |
