# 画面設計：イベント一覧

## 基本情報

| 項目 | 値 |
|---|---|
| URL | `/events` / `/events?page=past` |
| テンプレート | `templates/events.html` |
| 認証 | 不要 |

---

## レイアウト

```
┌─────────────────────────────────┐
│  [開催予定] [過去のイベント] タブ  │
├─────────────────────────────────┤
│  PINNED EVENT（開催予定時のみ）   │
│  ┌─────────────────────────┐    │
│  │ 大きめカード（最新1件）    │    │
│  │ 画像 / 名前 / 日付 / 場所 │    │
│  │ [予約する] [詳細]        │    │
│  └─────────────────────────┘    │
├─────────────────────────────────┤
│  グリッド（残イベント / 過去全件）  │
│  [カード] [カード] [カード]       │
└─────────────────────────────────┘
```

---

## 表示ロジック

| モード | URL | 表示内容 |
|---|---|---|
| 開催予定 | `/events` | 終了日 >= 今日。先頭をピン留め表示、残りをグリッド |
| 過去 | `/events?page=past` | 終了日 < 今日。全件グリッド（ピン留めなし） |

- `WSフラグ = TRUE` のイベントのみ「予約する」ボタンを表示
- イベント0件時は「イベント情報はありません」などのメッセージ表示
