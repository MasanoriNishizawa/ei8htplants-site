# 画面設計：予約キャンセル

## 基本情報

| 項目 | 値 |
|---|---|
| URL | `/cancel?token=xxx` |
| テンプレート | `templates/cancel.html` |
| 認証 | 不要 |

---

## 表示状態（4パターン）

### 1. キャンセル完了（`done=1`）

```
┌────────────────────────────────┐
│  ✓ キャンセルが完了しました      │
│  ご予約のキャンセルを承りました   │
│  [イベント一覧へ]               │
└────────────────────────────────┘
```

### 2. 無効なリンク（`token` が見つからない）

```
┌────────────────────────────────┐
│  ✗ 無効なリンクです             │
│  リンクが無効または期限切れです   │
│  公式サイト CONTACT へお問い合わせ│
│  [イベント一覧へ]               │
└────────────────────────────────┘
```

### 3. すでにキャンセル済み

```
┌────────────────────────────────┐
│  ✓ キャンセル済みです           │
│  [イベント一覧へ]               │
└────────────────────────────────┘
```

### 4. キャンセルフォーム（通常）

```
┌────────────────────────────────┐
│  予約内容                       │
│  イベント / お名前 / 希望日       │
│  時間帯 / 参加人数               │
│                                │
│  [キャンセル理由（任意）]         │
│  [予約をキャンセルする]           │
│   ↑ confirm() + 二重送信防止   │
│                                │
│  ※ キャンセル後の取り消し不可    │
└────────────────────────────────┘
```

---

## パラメータ

| パラメータ | 型 | 説明 |
|---|---|---|
| `token` | UUID 文字列 | WS予約シートの「キャンセルトークン」列と照合 |
| `done` | `"1"` | キャンセル後のリダイレクト先（完了状態を表示） |

---

## 状態遷移

```
GET /cancel?token=xxx
  → get_reservation_by_token(token) で予約を検索
  → 結果に応じて上記4状態のいずれかを表示

POST /cancel
  → cancel_reservation(token, reason)
  → メール送信（バックグラウンド）
  → 303 Redirect /cancel?token=xxx&done=1
```
