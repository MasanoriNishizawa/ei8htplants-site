| 項目 | 値 |
|---|---|
| URL | `/admin/reservations/schedule?event=xxx` |
| テンプレート | `templates/admin/admin_reservation_schedule.html` |

## 表示ロジック

- キャンセル済み（`キャンセル済み = TRUE`）の予約は除外
- 時間帯で `defaultdict` によりグループ化
- 時間帯ごとに昇順ソート（文字列ソート）
- 各ブロックに小計、ページ全体は合計なし

---

## PDF ダウンロード

- `window.print()` を呼び出す
- `@media print` CSS でナビゲーション・ボタンを非表示
- ブラウザの「PDFとして保存」でダウンロード
- デフォルトファイル名: `{イベント名}WS予約表`（ページタイトルがそのまま使われる）
