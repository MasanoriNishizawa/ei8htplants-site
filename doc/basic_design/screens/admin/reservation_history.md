# 画面設計：参加履歴

## 基本情報

| 項目 | 値 |
|---|---|
| URL | `/admin/reservations/history?email=xxx` |
| テンプレート | `templates/admin/admin_reservation_history.html` |
| 認証 | 必須 |
| 遷移元 | WS予約一覧のお名前リンク |

---

## レイアウト

```
┌──────────────────────────────────────────┐
│  [← 一覧に戻る]                          │
│  参加履歴                                │
│  xxx@gmail.com                          │
├──────────────────────────────────────────┤
│  ● イベント名A                           │
│    山田 様 / 2026-06-15 / 11:00-12:00 / 2名│
│    ┌────────────────────────────────┐   │
│    │ メモ内容（あれば）               │   │
│    └────────────────────────────────┘   │
│  ○ イベント名B（キャンセル済み - 薄表示） │
│    [キャンセル済] バッジ                 │
└──────────────────────────────────────────┘
```

---

## 表示ロジック

- 指定メールアドレスで全予約をフィルタ
- 表示順: `get_all_ws_reservations_for_admin()` の順序（タイムスタンプ降順）
- キャンセル済みは opacity 0.45 で薄く表示し、[キャンセル済] バッジを付与
- メモが入力されている場合は左ボーダー付きで表示

---

## クエリパラメータ

| パラメータ | 必須 | 説明 |
|---|---|---|
| `email` | ○ | 検索するメールアドレス |
