# 画面設計：イベント管理

## 基本情報

| 項目 | 値 |
|---|---|
| URL | `/admin/events` / `/admin/events/new` / `/admin/events/{row}` |
| テンプレート | `admin_events.html` / `admin_event_form.html` |
| 認証 | 必須 |

---

## イベント一覧（`/admin/events`）

```
┌──────────────────────────────────────────┐
│  topbar: [Events*] [WS予約] [お問い合わせ] │
├──────────────────────────────────────────┤
│  [+ 新規イベント追加]                     │
│  フラッシュメッセージ（操作後1回のみ表示）  │
├──────────────────────────────────────────┤
│  表: 開始日 / イベント名 / ブランド / WSフラグ / [編集] [削除]
└──────────────────────────────────────────┘
```

- 開始日の降順（新しい順）で表示
- 削除は `confirm()` 確認ダイアログあり

## イベント編集（`/admin/events/{row}`）

共通テンプレート `admin_event_form.html` を使用。

```
┌─────────────────────────────────────────┐
│  [開始日] [終了日]                       │
│  [イベント名]                            │
│  [販売ブランド] チェックボックス（複数可）  │
│    □ ei8ht plants  □ Habitat Oides  □ HUE
│  [開催時間]                             │
│  [場所] [ブース番号] [住所]              │
│  [公式サイトURL]                        │
│  [□ WS受付を有効にする]                 │
│  [画像 Drive URL]                       │
│                                         │
│  [保存]  ※編集時は [削除] も表示       │
└─────────────────────────────────────────┘
```

---

## フォーム項目の特殊処理

| 項目 | 処理 |
|---|---|
| 販売ブランド | `form.getlist()` で複数値取得 → カンマ区切り文字列に結合 |
| WSフラグ | チェックなし時は POST データに含まれないため明示的に `"FALSE"` を設定 |
